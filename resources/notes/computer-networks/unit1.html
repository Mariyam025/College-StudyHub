Computer Networks - Unit 1

1. Introduction to Computer Network

A computer network is a collection of two or more computers and other devices that are connected together to share data, resources and services.

A network allows computers to communicate with each other using communication media and networking protocols.

Example: Computers connected in a college computer laboratory can share files, printers and an Internet connection.

2. Objectives of Computer Networks

  • Sharing of data
  • Sharing of hardware resources
  • Sharing of software
  • Communication between users
  • Internet access
  • Remote access
  • Improved reliability
  • Centralized management

3. Advantages of Computer Networks

  • Fast communication
  • Resource sharing
  • File sharing
  • Cost reduction
  • Centralized data management
  • Easy access to information
  • Improved collaboration

4. Disadvantages of Computer Networks

  • Security problems
  • Network failure can affect many users
  • Maintenance cost
  • Virus and malware can spread quickly
  • Requires technical knowledge

5. Components of Computer Network

A computer network generally contains the following components:

  • Sender
  • Receiver
  • Transmission medium
  • Network devices
  • Protocols
  • Network software

6. Data Communication

Data communication is the process of transferring data from one device to another through a communication medium.

Basic Elements of Data Communication

  1. Message
  2. Sender
  3. Receiver
  4. Transmission medium
  5. Protocol

7. Characteristics of Data Communication

  • Delivery: Data must reach the correct destination.
  • Accuracy: Data should be received without errors.
  • Timeliness: Data should arrive at the required time.
  • Jitter: Variation in the arrival time of data packets.

8. Types of Computer Networks

LAN - Local Area Network

LAN covers a small geographical area such as a room, building, school or college.

Example: College computer laboratory network.

MAN - Metropolitan Area Network

MAN covers a larger geographical area such as a city.

WAN - Wide Area Network

WAN covers a large geographical area such as countries or continents.

Example: The Internet.

PAN - Personal Area Network

PAN is a small network used around an individual person.

Example: Mobile phone connected to Bluetooth earphones.

9. LAN vs MAN vs WAN

Feature LAN MAN WAN
Full Form Local Area Network Metropolitan Area Network Wide Area Network
Area Small City Very large
Speed Generally high Medium to high Generally lower than LAN
Example College lab City network Internet

10. Network Topology

Network topology describes the physical or logical arrangement of devices in a computer network.

Types of Topology

  • Bus topology
  • Star topology
  • Ring topology
  • Mesh topology
  • Tree topology
  • Hybrid topology

11. Bus Topology

In bus topology, all devices are connected to a single main communication cable called the backbone.

Advantages

  • Simple design
  • Low installation cost
  • Requires less cable

Disadvantages

  • Failure of backbone can affect the entire network
  • Difficult troubleshooting
  • Performance decreases with heavy traffic

12. Star Topology

In star topology, every device is connected to a central device such as a switch or hub.

Advantages

  • Easy to install
  • Easy troubleshooting
  • Failure of one cable normally affects only one device
  • Easy to add new devices

Disadvantage

Failure of the central device can affect the network.

13. Ring Topology

In ring topology, each device is connected to two other devices, forming a ring.

14. Mesh Topology

In mesh topology, devices are connected through multiple links. In a full mesh, every device has a direct connection to every other device.

Advantages

  • High reliability
  • Multiple paths for data
  • Good fault tolerance

Disadvantages

  • Expensive
  • Requires large amount of cabling
  • Complex installation

15. Network Devices

Hub

A hub connects multiple devices and broadcasts incoming data to connected ports.

Switch

A switch connects devices in a network and forwards frames toward the appropriate destination.

Router

A router connects different networks and forwards packets between them.

Repeater

A repeater regenerates or strengthens signals so that they can travel longer distances.

Bridge

A bridge connects network segments and helps control traffic between them.

Gateway

A gateway connects networks that may use different communication protocols.

16. Transmission Media

Transmission media is the path through which data travels from sender to receiver.

Guided Media

  • Twisted pair cable
  • Coaxial cable
  • Fiber optic cable

Unguided Media

  • Radio waves
  • Microwaves
  • Infrared
  • Satellite communication

17. Twisted Pair Cable

Twisted pair cable contains pairs of insulated copper wires twisted together.

Common types are:

  • UTP - Unshielded Twisted Pair
  • STP - Shielded Twisted Pair

18. Coaxial Cable

Coaxial cable consists of a central conductor, insulation, metallic shield and outer covering.

19. Optical Fiber

Optical fiber transmits data using light signals through thin strands of glass or plastic.

Advantages

  • Very high bandwidth
  • Low signal loss
  • Less affected by electromagnetic interference
  • Suitable for long-distance communication

20. Wireless Transmission

Wireless communication transfers data without a physical cable.

Examples include Wi-Fi, Bluetooth, microwave and satellite communication.

21. Network Protocol

A protocol is a set of rules that controls communication between devices on a network.

Examples: HTTP, HTTPS, FTP, TCP, UDP, IP, SMTP and DNS.

22. Simplex, Half-Duplex and Full-Duplex

Mode Description Example
Simplex Communication in one direction only Keyboard to computer
Half-Duplex Both directions, but not simultaneously Walkie-talkie
Full-Duplex Both directions simultaneously Telephone call

23. Important Terms

  • Bandwidth: Capacity of a communication channel.
  • Latency: Time taken for data to travel from source to destination.
  • Throughput: Actual rate of successful data transfer.
  • Packet: Small unit of data transmitted over a network.
  • Node: Any device connected to a network.
