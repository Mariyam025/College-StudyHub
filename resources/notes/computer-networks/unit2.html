Computer Networks - Unit 2

1. Network Models

Network models provide a standard way to understand how communication takes place between computers and network devices.

Two important networking models are:

  • OSI Model
  • TCP/IP Model

2. OSI Model

OSI stands for Open Systems Interconnection. It is a reference model developed to standardize network communication.

The OSI model has seven layers.

3. Seven Layers of OSI Model

Layer Name Main Function
7 Application Provides network services to applications
6 Presentation Translation, encryption and compression
5 Session Establishes and manages sessions
4 Transport End-to-end delivery and reliability
3 Network Routing and logical addressing
2 Data Link Framing and error detection
1 Physical Transmission of raw bits

4. Physical Layer

The physical layer is the first layer of the OSI model. It is responsible for transmitting raw bits over a physical medium.

Functions

  • Bit transmission
  • Transmission rate
  • Physical topology
  • Encoding
  • Transmission media

5. Data Link Layer

The data link layer provides reliable communication between directly connected nodes.

Functions

  • Framing
  • Physical addressing
  • Error detection
  • Flow control
  • Access control

6. Network Layer

The network layer is responsible for logical addressing and routing packets from source to destination across different networks.

Functions

  • Logical addressing
  • Routing
  • Packet forwarding
  • Internetworking
Important: IP works at the Network Layer of the OSI model.

7. Transport Layer

The transport layer provides end-to-end communication between processes running on different devices.

Functions

  • Segmentation
  • Reassembly
  • Flow control
  • Error control
  • Reliable delivery

Important transport layer protocols include TCP and UDP.

8. Session Layer

The session layer establishes, manages and terminates communication sessions between applications.

9. Presentation Layer

The presentation layer is responsible for the format and representation of data.

Functions

  • Data translation
  • Encryption
  • Decryption
  • Compression

10. Application Layer

The application layer provides network services directly to user applications.

Examples

  • HTTP
  • HTTPS
  • FTP
  • SMTP
  • DNS

11. Easy Trick to Remember OSI Layers

Top to Bottom:
All People Seem To Need Data Processing

A = Application
P = Presentation
S = Session
T = Transport
N = Network
D = Data Link
P = Physical

12. Encapsulation

Encapsulation is the process of adding protocol information such as headers to data as it moves down through the network layers.

At the receiving side, the process is reversed and is called decapsulation.

13. TCP/IP Model

TCP/IP stands for Transmission Control Protocol/Internet Protocol. It is the protocol architecture used for communication over the Internet.

14. Layers of TCP/IP Model

TCP/IP Layer Main Function
Application Network services for applications
Transport End-to-end communication
Internet Logical addressing and routing
Network Access Physical transmission and link communication

15. OSI vs TCP/IP

Feature OSI TCP/IP
Number of Layers 7 4 commonly described layers
Nature Reference model Protocol suite/model
Development ISO Internet protocol development community
Use Conceptual/reference framework Widely used for Internet communication

16. IP Address

An IP address is a logical address assigned to a device/interface on an IP network.

17. IPv4

IPv4 uses a 32-bit address.

Example:

192.168.1.10

IPv4 addresses are generally written as four decimal numbers separated by dots.

18. IPv6

IPv6 uses a 128-bit address and was developed to provide a much larger address space than IPv4.

Example:

2001:db8::1

19. IPv4 vs IPv6

Feature IPv4 IPv6
Address Size 32-bit 128-bit
Notation Decimal Hexadecimal
Example 192.168.1.1 2001:db8::1
Address Space Smaller Much larger

20. MAC Address

A MAC address is a hardware/link-layer address associated with a network interface.

It is commonly represented as a sequence of hexadecimal values.

21. Port Number

A port number identifies a logical communication endpoint associated with a network service or process.

Examples of commonly used ports include:

Service Common Port
HTTP 80
HTTPS 443
FTP Control 21
DNS 53
SMTP 25

22. TCP

TCP stands for Transmission Control Protocol. It is a connection-oriented transport protocol that provides reliable, ordered delivery of data.

Features of TCP

  • Connection-oriented
  • Reliable delivery
  • Ordered data delivery
  • Error detection
  • Flow control
  • Congestion control

23. UDP

UDP stands for User Datagram Protocol. It is a connectionless transport protocol that provides a lightweight method of sending datagrams without TCP-style delivery guarantees.

Features of UDP

  • Connectionless
  • Low protocol overhead
  • No guaranteed delivery
  • No guaranteed ordering
  • Useful for time-sensitive applications

24. TCP vs UDP

Feature TCP UDP
Connection Connection-oriented Connectionless
Reliability Reliable delivery mechanisms No delivery guarantee
Ordering Ordered No ordering guarantee
Overhead Higher Lower
Common Uses Web, file transfer, email Streaming, DNS, real-time applications

25. Common Network Protocols

HTTP

HTTP is used for communication between web clients and web servers.

HTTPS

HTTPS is HTTP protected using TLS to provide encrypted communication.

FTP

FTP is used for transferring files between systems.

SMTP

SMTP is used for sending email between mail systems.

DNS

DNS translates domain names into IP addresses and supports other name-resolution functions.

26. Client-Server Model

In the client-server model, a client requests a service and a server provides that service.

Example: A web browser acts as a client and requests a web page from a web server.

27. Peer-to-Peer Network

In a peer-to-peer network, devices can communicate directly and may act as both clients and servers.

28. Client-Server vs Peer-to-Peer

Feature Client-Server Peer-to-Peer
Architecture Centralized Distributed
Server Dedicated server generally exists No dedicated server is required
Management Centralized More distributed

29. Network Security Basics

Network security protects network devices, communication and data from unauthorized access and attacks.

Common Security Threats

  • Malware
  • Phishing
  • Unauthorized access
  • Denial-of-Service attacks
  • Data interception

Basic Security Measures

  • Strong passwords
  • Encryption
  • Firewalls
  • Authentication
  • Regular software updates
  • Antivirus/endpoint protection
