1. Proposition

Definition: A proposition is a declarative statement that is either true or false, but not both.

Example: "2 + 2 = 4" is a proposition.

4. Well Formed Formula

A well formed formula is a logically correct expression constructed according to the rules of propositional logic.

5. Tautology

A statement that is always true is called a tautology.

Example: P ∨ ¬P

6. Contradiction

A statement that is always false is called a contradiction.

Example: P ∧ ¬P

7. Algebra of Proposition

Logical expressions can be simplified using logical laws such as identity, complement and distributive laws.

8. Normal Forms

  • Conjunctive Normal Form (CNF)
  • Disjunctive Normal Form (DNF)

9. Modus Ponens

If P → Q is true and P is true, then Q is true.

10. Modus Tollens

If P → Q is true and Q is false, then P is false.

11. Predicate Logic

Predicate logic extends propositional logic by using variables and predicates.

12. First Order Predicate Logic

It uses predicates, variables and quantifiers to express statements.

13. Quantifiers

  • Universal (∀): For all
  • Existential (∃): There exists

14. Inference Theory

Inference is the process of deriving a logical conclusion from given premises.

15. Proof by Implication

To prove P → Q, assume P is true and show that Q follows.

16. Converse and Inverse

For P → Q:

  • Converse: Q → P
  • Inverse: ¬P → ¬Q
  • Contrapositive: ¬Q → ¬P

17. Proof Methods

  • Direct Proof
  • Proof by Truth Table
  • Proof by Counter Example
  • Proof by Contradiction

Important Points

  • Proposition has a truth value.
  • Tautology is always true.
  • Contradiction is always false.
  • ∀ means for all.
  • ∃ means there exists.
