Discrete Mathematical Structures - Unit 4

Paper: NBCA-204

1. Algebraic Structures

An algebraic structure consists of a set together with one or more operations defined on it.

2. Binary Composition

A binary operation combines two elements of a set and produces an element according to defined rules.

3. Properties of Binary Composition

  • Closure
  • Associativity
  • Commutativity
  • Identity
  • Inverse

4. Semigroup

A semigroup is a set with a binary operation that satisfies closure and associativity.

5. Monoid

A monoid is a semigroup that also contains an identity element.

6. Group

A group is a set with a binary operation satisfying closure, associativity, identity and inverse properties.

7. Abelian Group

A group is called Abelian if its operation is commutative.

Example: Integers under addition form an Abelian group.

8. Properties of Groups

  • Closure
  • Associativity
  • Identity element
  • Inverse element

9. Permutation Group

A permutation group is a group whose elements are permutations and whose operation is composition.

10. Subgroup

A subgroup is a subset of a group that itself forms a group under the same operation.

11. Cyclic Group

A cyclic group is a group generated by a single element.

12. Rings

A ring is an algebraic structure with two operations, usually addition and multiplication, satisfying specific properties.

13. Fields

A field is a ring in which non-zero elements have multiplicative inverses.

14. Integers Modulo n

Integers modulo n consist of the remainders obtained when integers are divided by n.

Example for modulo 5: {0,1,2,3,4}

Important Points

  • Semigroup has closure and associativity.
  • Monoid additionally has identity.
  • Group also has inverse.
  • Abelian group is commutative.
  • Cyclic group has one generator.
  • Modulo n uses remainders from division by n.
