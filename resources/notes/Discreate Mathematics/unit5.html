Discrete Mathematical Structures - Unit 5

Paper: NBCA-204

1. Coding Theory

Definition: Coding theory deals with representing information using codes so that data can be transmitted and stored reliably.

2. Error

An error occurs when received data differs from the original transmitted data.

3. Error Detecting Code

An error detecting code helps detect errors in transmitted or stored data.

4. Error Correcting Code

An error correcting code can detect and correct certain errors in data.

5. Hamming Code

Hamming code is an error-detecting and error-correcting coding technique.

6. Distance

The distance between two codewords is the number of positions in which they differ.

7. Group (Linear) Codes

Linear codes are codes having algebraic properties that make encoding and decoding easier.

8. Decoding Methods

  • Parity Check
  • Generator Matrix
  • Parity Check Matrix
  • Coset Decoding

9. Parity Check

A parity bit is added to data to help detect errors.

Example: For even parity, the total number of 1s should be even.

10. Generator Matrix

A generator matrix is used to generate codewords from message bits in linear coding.

11. Parity Check Matrix

A parity check matrix is used to check whether a received codeword is valid.

12. Coset Decoding

Coset decoding is a method used for decoding received words in linear codes.

13. Hamming Codes

Hamming codes add parity bits at specific positions to detect and correct single-bit errors.

14. Single Error Correction

Hamming code can be designed to locate and correct a single-bit error.

15. SEC Code

SEC means Single Error Correction. It corrects one-bit errors.

16. SEC-DED

SEC-DED means Single Error Correction - Double Error Detection.

CodePurpose
SECCorrects one-bit error
SEC-DEDCorrects one-bit error and detects two-bit errors

Important Points

  • Coding theory improves reliable communication.
  • Error detection identifies errors.
  • Error correction identifies and corrects certain errors.
  • Parity bits help detect errors.
  • Hamming code is used for error correction.
  • SEC corrects one error.
  • SEC-DED corrects one error and detects double errors.
