Discrete Mathematical Structures - Unit 1

Paper: NBCA-204

1. Set Theory

Definition: A set is a well-defined collection of distinct objects.

Example: A = {1,2,3,4}

2. Combination of Sets

Sets can be combined using operations such as union and intersection.

Union

A ∪ B contains elements present in A or B.

Example: {1,2} ∪ {2,3} = {1,2,3}

Intersection

A ∩ B contains common elements.

Example: {1,2} ∩ {2,3} = {2}

3. Multisets

A multiset is a collection in which an element can occur more than once.

Example: {a,a,b,c,c}

4. Ordered Pairs

An ordered pair is written as (a,b), where order is important.

Example: (1,2) ≠ (2,1)

5. Set Identities

  • Identity: A ∪ ∅ = A
  • Identity: A ∩ U = A
  • Idempotent: A ∪ A = A
  • Idempotent: A ∩ A = A
  • Complement: A ∪ A' = U

6. Relations

Definition: A relation describes a connection between elements of two sets.

Operations on Relations

  • Union
  • Intersection
  • Difference
  • Composition

7. Properties of Relations

  • Reflexive
  • Symmetric
  • Antisymmetric
  • Transitive

8. Composite Relations

Composition combines two relations to form a new relation.

9. Equality of Relations

Two relations are equal when they contain exactly the same ordered pairs.

10. Order of Relations

The order of a relation refers to the number of elements in its relation structure/domain and range.

11. Functions

Definition: A function is a relation in which every element of the domain is associated with exactly one element of the codomain.

12. Classification of Functions

  • One-One Function
  • Many-One Function
  • Onto Function
  • Into Function
  • Bijective Function

13. Operations on Functions

  • Addition
  • Subtraction
  • Multiplication
  • Composition

14. Recursively Defined Functions

A recursive function is defined using one or more base cases and a rule that refers to previous values.

Example: f(n) = f(n-1) + 1, with f(0)=0

Important Points

  • Set contains distinct elements.
  • Relation represents a connection.
  • Function maps every domain element to exactly one codomain element.
  • Union combines elements.
  • Intersection gives common elements.
