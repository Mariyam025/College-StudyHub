Discrete Mathematical Structures - Unit 3

Paper: NBCA-204

1. Combinatorics

Definition: Combinatorics is the branch of mathematics concerned with counting, arrangement and selection of objects.

2. Mathematical Induction

Mathematical induction is a proof technique used to prove statements for all positive integers.

Steps

  • Base Case
  • Induction Hypothesis
  • Induction Step

3. Basics of Counting

Counting principles are used to find the number of possible outcomes.

4. Pigeonhole Principle

If more objects are placed into fewer boxes, at least one box must contain more than one object.

Example: Among 6 people, at least two people must have the same birth month.

5. Permutations

Permutation means arrangement of objects where order matters.

Formula: nPr = n! / (n-r)!

Example: Arranging 3 students from 5 students.

6. Combinations

Combination means selecting objects where order does not matter.

Formula: nCr = n! / (r!(n-r)!)

Example: Selecting 2 students from 5 students.

7. Inclusion-Exclusion Principle

It is used to count elements in overlapping sets.

n(A ∪ B) = n(A) + n(B) - n(A ∩ B)

8. Recurrence Relations

A recurrence relation defines a sequence using previous terms.

Example: F(n) = F(n-1) + F(n-2)

9. Generating Function

A generating function represents a sequence as coefficients of a power series.

10. Homogeneous Recurrence Relation

A recurrence relation in which the right side contains only previous terms of the sequence.

11. Inhomogeneous Recurrence Relation

A recurrence relation that contains an additional non-zero function or term.

12. Generating Function Properties

  • Represents sequences.
  • Helps solve recurrence relations.
  • Can provide a closed-form expression.

Important Points

  • Permutation → order matters.
  • Combination → order does not matter.
  • Induction uses base case and induction step.
  • Pigeonhole principle is used in counting problems.
  • Recurrence relations use previous terms.
