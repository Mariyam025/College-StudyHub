Fundamentals of Computer

Unit IV – Computer Software & Programming Languages

1. Computer Software

Software is a collection of programs and instructions that tells a computer what to do.

Example: Windows, MS Word, Chrome and VLC are examples of software.

2. System Software

System software controls and manages computer hardware and provides a platform for running application software.

Examples

  • Operating System
  • Device Drivers
  • Utility Programs

3. Application Software

Application software is designed to perform specific tasks for the user.

Examples: MS Word for document preparation, MS Excel for calculations and Chrome for web browsing.

System Software vs Application Software

System Software Application Software
Manages computer system Performs user-specific tasks
Works mainly in background Used directly by users
Example: Operating System Example: MS Word

4. Operating System

An Operating System (OS) is system software that manages computer hardware, software resources and provides an interface between the user and computer.

Examples

  • Windows
  • Linux
  • macOS
  • Android

Main Functions of Operating System

  • Process management
  • Memory management
  • File management
  • Device management
  • Security
  • User interface

5. Algorithm

An algorithm is a step-by-step procedure used to solve a problem or perform a task.

Example: Algorithm to add two numbers
  1. Start
  2. Input two numbers A and B
  3. Add A and B
  4. Display the result
  5. Stop

6. Flowchart

A flowchart is a graphical representation of an algorithm. It uses different symbols to represent different steps.

Symbol Purpose
Oval Start / Stop
Rectangle Process
Parallelogram Input / Output
Diamond Decision
Arrow Flow direction

7. Types of Computer Languages

Computer languages are used to communicate instructions to a computer.

1. Machine Language

Machine language consists of binary instructions using 0 and 1. It is directly understood by the computer.

Example: 10110100

2. Assembly Language

Assembly language uses symbolic instructions or mnemonics instead of binary codes.

Example: ADD, MOV, SUB

3. High-Level Language

High-level languages use instructions that are easier for humans to read and understand.

Examples: C, C++, Java, Python

8. Assembler

An assembler is a system program that converts an assembly language program into machine language.

Assembly Language → Assembler → Machine Language

9. Compiler

A compiler translates a high-level language program into machine language or equivalent machine-level code.

Example: A C compiler converts C source code into machine-level/object code.

10. Interpreter

An interpreter translates and executes a program statement by statement.

Example: Python commonly uses an interpreter-based execution approach.

Compiler vs Interpreter

Compiler Interpreter
Translates the program as a whole Translates statement by statement
Produces object/executable code Usually executes during translation
Compilation is done before execution Translation and execution occur together

11. Linker

A linker combines object files and required library files to create a final executable program.

Object Files + Libraries → Linker → Executable File

12. Loader

A loader loads the executable program into the main memory so that the CPU can execute it.

Executable Program → Loader → Main Memory → Execution

Quick Revision

  • Software = collection of programs and instructions.
  • System software manages computer resources.
  • Application software performs specific user tasks.
  • Operating System manages hardware and software resources.
  • Algorithm = step-by-step solution.
  • Flowchart = graphical representation of an algorithm.
  • Assembler converts assembly language into machine language.
  • Compiler translates high-level language program.
  • Interpreter translates and executes statement by statement.
  • Linker combines object files and libraries.
  • Loader loads the executable program into memory.
