Fundamentals of Computer

Unit V – Office Automation

1. Office Automation

Office Automation means using computers and software to perform office-related tasks quickly and efficiently.

Examples: Creating documents, preparing spreadsheets, making presentations and managing databases.

2. MS Word

MS Word is a word-processing application used to create, edit, format, save and print documents.

Creating a Document

  1. Open MS Word.
  2. Create a new document.
  3. Type the required content.
  4. Format the document.
  5. Save the document.

Saving a Document

The Save option is used to store a document for future use.

Preview and Print

Print Preview allows the user to see how the document will appear on paper before printing.

Editing Documents

Editing includes adding, deleting, copying, cutting and moving text.

Proofreading

Proofreading means checking a document for spelling, grammar and other mistakes.

Formatting

  • Changing font style
  • Changing font size
  • Bold, Italic and Underline
  • Text alignment
  • Paragraph formatting
  • Changing text appearance

Data Presentation in Tables, Graphs and Charts

MS Word can present information using tables, graphs and charts.

Example: A student's marks can be presented in a table or chart.

Form Letters

A form letter is a standard letter prepared for sending similar information to multiple people.

Email Message

MS Word can be used to prepare and format content that can be used in email communication.

Labels

Labels are used to print information such as names and addresses on envelopes or other materials.

Mail Merge

Mail Merge is used to create multiple personalized documents from one main document and a data source.

Example: Sending the same invitation letter to 100 students with different names.

3. MS Excel

MS Excel is a spreadsheet application used to store, organize, calculate and present data.

Creating a Workbook

A workbook contains worksheets where data can be entered into rows and columns.

Saving and Editing

Excel allows users to save, modify and update spreadsheet data.

Printing

Excel provides options to print worksheets and selected data.

Formatting Data

  • Font formatting
  • Cell alignment
  • Number formatting
  • Cell borders
  • Changing cell appearance

Managing and Hiding Workbook Data

Excel allows users to organize workbook data and hide rows, columns or worksheets when required.

Charts and Graphs

Charts and graphs provide a visual representation of data.

Example: Monthly sales data can be represented using a column or line chart.

Formulas

A formula is an expression used to perform calculations in Excel. A formula normally begins with the = sign.

Example:
=A1+B1

Functions

Functions are predefined formulas used to perform common calculations.

Function Purpose
SUM() Adds values
AVERAGE() Finds average
MAX() Finds largest value
MIN() Finds smallest value
Example:
=SUM(A1:A5)

4. MS PowerPoint

MS PowerPoint is presentation software used to create and display information through slides.

Creating a Presentation

  1. Open PowerPoint.
  2. Create a new presentation.
  3. Add slides.
  4. Enter information.
  5. Format the slides.
  6. Save the presentation.

Editing Presentation

PowerPoint allows users to add, remove and modify text, images and other objects on slides.

Tables

Tables can be inserted into slides to present information in rows and columns.

Graphics

Graphics and images make presentations more understandable and attractive.

Charts

Charts are used to present numerical data visually.

Sound

Audio can be added to a presentation when required.

Animation

Animation effects can be applied to objects or text on slides to control how they appear during a presentation.

5. MS Access

MS Access is a database management application used to create and manage databases.

Introduction to Database

A database is an organized collection of related data.

Example: A college database may contain student names, roll numbers, courses and marks.

Data Types

Data types specify the kind of data that can be stored in a field.

Data Type Example
Text Student Name
Number 100
Date/Time 15/09/2026
Currency ₹5000

Database Creation

  1. Open MS Access.
  2. Create a new database.
  3. Create a table.
  4. Add fields.
  5. Enter records.
  6. Save the database.

Basic Query

A query is used to retrieve specific information from a database.

Example: Finding all students whose marks are greater than 70.

Report Generation

A report presents database information in an organized and printable format.

  • Formulas are used for calculations in Excel.

  • PowerPoint is used to create presentations.

  • MS Access is used for database management.

  • Reports present database information in an organized format.
