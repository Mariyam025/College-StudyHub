Fundamentals of Computer - Unit 2

Paper: NBCA-101 – Fundamentals of Computer and its Applications

1. Processor

Definition: A processor is the main processing unit of a computer. It executes instructions and performs calculations and logical operations.

Main functions of a Processor

  • Executes instructions.
  • Performs arithmetic and logical operations.
  • Controls the processing of data.
  • Works with memory and other components of the computer.

Types / Examples of Processors

  • Intel: A major processor manufacturer.
  • Pentium: A well-known Intel processor family.
  • AMD: Another major processor manufacturer.

Processor Specifications

Important specifications used to describe a processor include:

  • Clock Speed: Indicates how quickly the processor works, commonly measured in GHz.
  • Number of Cores: Shows how many processing cores are available.
  • Cache: Fast memory used by the processor to access frequently required data.

2. Motherboard

Definition: A motherboard is the main circuit board of a computer. It connects the processor, memory, storage, expansion cards and other hardware components.

Components of Motherboard

  • Processor socket
  • Memory/RAM slots
  • Expansion slots
  • Storage connectors
  • Power connectors
  • BIOS/firmware chip
  • Input/output ports

Types of Motherboard

Motherboards can be designed in different sizes and layouts according to their form factor and intended use.

Form Factor

Definition: Form factor refers to the physical size, shape and layout standard of a motherboard.

Examples: ATX, Micro-ATX and Mini-ITX.

3. BIOS

Definition: BIOS stands for Basic Input/Output System. It is firmware that helps initialize hardware and start the computer's boot process.

When a computer is switched on, BIOS performs initial hardware checking and helps the system begin loading the operating system.

Example: BIOS can detect installed memory and storage devices during startup.

4. CMOS

Definition: CMOS stands for Complementary Metal-Oxide Semiconductor. In traditional PC systems, CMOS memory stores certain system configuration information.

The CMOS settings can include information such as date, time and hardware configuration.

5. RAM

Definition: RAM (Random Access Memory) is the main temporary memory used by a computer to store data and programs that are currently being used.
  • It is generally volatile memory.
  • Data is lost when power is switched off.
  • More RAM can help a computer handle multiple programs more smoothly.

Example: When you open a browser, the programs and data being actively used are loaded into RAM.

6. ROM

Definition: ROM (Read Only Memory) is non-volatile memory that retains stored information even when the power is turned off.
  • It retains information without continuous power.
  • It is used for firmware and other permanent or semi-permanent instructions.

7. SRAM

Definition: SRAM stands for Static Random Access Memory. It is a fast type of RAM that does not need periodic refreshing like DRAM.

Common use: Processor cache memory.

8. DRAM

Definition: DRAM stands for Dynamic Random Access Memory. It stores each bit using a memory cell that needs periodic refreshing.

Common use: Main memory (RAM) in computers.

Memory Main Feature Common Use
RAM Temporary and volatile Running programs
ROM Non-volatile Firmware/instructions
SRAM Fast, no periodic refresh Cache memory
DRAM Requires periodic refresh Main memory

9. Buses

Definition: A bus is a communication pathway used to transfer data, addresses and control signals between different computer components.

Types of Buses

Bus Function
Data Bus Carries data between components.
Address Bus Carries addresses that identify memory or I/O locations.
Control Bus Carries control and timing signals.

Utility of Buses

  • Connect different hardware components.
  • Transfer data and instructions.
  • Carry addresses and control signals.

10. Add-on Cards

Definition: An add-on card is an expansion circuit board inserted into an expansion slot to provide additional features or capabilities to a computer.

Examples

  • Graphics Card: Improves graphics and video processing.
  • Sound Card: Provides or improves audio processing.
  • Network Card: Provides network connectivity.

Quick Revision

  • Processor executes instructions and processes data.
  • Motherboard connects major computer components.
  • BIOS helps initialize hardware and start the boot process.
  • RAM is temporary/volatile memory.
  • ROM is non-volatile memory.
  • SRAM is fast and commonly used for cache.
  • DRAM requires periodic refreshing and is commonly used as main memory.
  • Data, Address and Control are the main types of system buses.
  • Add-on cards provide additional computer capabilities.
