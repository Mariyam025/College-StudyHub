Fundamentals of Computer and Its Applications

Unit 3 - Input, Output and Storage Devices

1. Input Devices

Input devices are hardware devices used to enter data and instructions into a computer system.

Keyboard

A keyboard is the most commonly used input device. It is used to enter text, numbers and commands into a computer.

Example: Typing a document in MS Word using a keyboard.

Mouse

A mouse is a pointing device used to move the pointer on the screen, select objects and perform different operations.

Main Mouse Operations:

  • Click
  • Double Click
  • Right Click
  • Drag and Drop
  • Scrolling

Digitizing Tablet

A digitizing tablet is an input device used to draw images or write directly into the computer with the help of a stylus.

Example: Used by graphic designers and digital artists.

Scanner

A scanner converts printed documents, photographs or images into digital form.

Example: Scanning an identity card and saving it as an image or PDF.

Bar-Code Reader

A barcode reader reads barcodes printed on products and converts them into digital information.

Example: Barcode scanners used at supermarket billing counters.

Light Pen

A light pen is a pointing input device that allows the user to directly select or draw objects on a display screen.

Touch Screen

A touch screen accepts input when a user touches the display using a finger or stylus.

Example: Smartphones, ATMs and self-service kiosks.

2. Output Devices

Output devices are hardware devices that display or produce the result of data processed by the computer.

Monitor

A monitor is a visual output device used to display text, images, videos and other information.

Characteristics of Monitor

Characteristic Description
Digital Displays information using digital signals.
Analog Uses continuous signals for displaying information.
Size Measured diagonally in inches.
Resolution Number of pixels displayed on the screen.
Refresh Rate Number of times the screen refreshes per second.
Video Standard Standard that determines the display quality and resolution.
Example: 1920 × 1080 is a common Full HD resolution.

3. Printers

A printer is an output device used to produce a hard copy of documents, images and other information.

Types of Printers

1. Impact Printers

Impact printers print by physically striking an ink ribbon against the paper.

Example: Dot Matrix Printer.

2. Non-Impact Printers

Non-impact printers print without physically striking the paper.

Examples:

  • Inkjet Printer
  • Laser Printer

4. Plotter

A plotter is an output device used to print large and highly accurate drawings, maps and designs.

Example: Architects and engineers use plotters for building designs.

5. Sound Card

A sound card is a hardware component that allows a computer to process and produce audio signals.

6. Speakers

Speakers are output devices used to produce sound from a computer.

Example: Listening to music, videos and online lectures.

7. Storage Devices

Storage devices are used to store data, programs and information for future use.

Primary Storage

Primary storage is directly accessed by the CPU and is mainly used while the computer is working.

Examples:

  • RAM
  • ROM

Secondary Storage

Secondary storage is used for permanent storage of large amounts of data.

Examples:

  • Hard Disk
  • Optical Disk
  • Magnetic Tape

Primary Storage vs Secondary Storage

Primary Storage Secondary Storage
Directly accessed by CPU Not directly accessed by CPU
Faster Slower than primary memory
Smaller capacity Larger capacity
Example: RAM Example: Hard Disk

8. Magnetic Tape

Magnetic tape is a storage medium in which data is stored on a magnetic strip.

It is generally used for backups and storing large amounts of data.

9. Magnetic Disk

A magnetic disk stores data using magnetic technology.

Example: Hard Disk and Floppy Disk.

10. Cartridge Tape

Cartridge tape is a type of magnetic tape enclosed inside a protective cartridge. It is commonly used for data backup.

11. Data Drives

Data drives are storage devices used for storing and retrieving digital information.

12. Hard Disk Drive

A Hard Disk Drive or HDD is a secondary storage device used to store operating systems, software, files and other data.

Example: A computer may contain a 500 GB or 1 TB hard disk.

13. Floppy Disk

A floppy disk is an older magnetic storage device used for storing small amounts of data.

A commonly used floppy disk had a storage capacity of approximately 1.44 MB.

14. Optical Disk

Optical disks use laser technology for reading and writing data.

Examples:

  • CD
  • DVD
  • Blu-ray Disc
Important Points:
  • Keyboard and mouse are common input devices.
  • Monitor, printer and speakers are output devices.
  • Resolution is measured in pixels.
  • Refresh rate is measured in Hertz (Hz).
  • Primary storage is faster than secondary storage.
  • Hard Disk is a secondary storage device.
  • CD and DVD are examples of optical disks.

Quick Revision

  • Input devices enter data into the computer.
  • Output devices display processed information.
  • Keyboard, mouse and scanner are input devices.
  • Monitor, printer, plotter and speaker are output devices.
  • Storage devices store data for future use.
  • Primary storage includes RAM and ROM.
  • Secondary storage includes hard disk, magnetic tape and optical disk.
