Advanced Java Technology - Unit 1

1. Introduction to Advanced Java

Advanced Java is used for developing database-based, web-based and enterprise applications. It provides technologies such as JDBC, Servlets, JSP and JavaBeans.

Core Java: Mainly used for basic Java programming and desktop applications.

Advanced Java: Mainly used for database connectivity and web/enterprise applications.

2. J2EE / Java Enterprise Platform

Enterprise Java technologies provide tools for developing large and distributed applications. Important technologies include Servlets, JSP, JDBC, JavaBeans and other enterprise APIs.

Application Architecture

  • Two-Tier Architecture
  • Three-Tier Architecture
  • N-Tier Architecture

In a three-tier application, presentation, business logic and database layers are separated.

3. JDBC

JDBC stands for Java Database Connectivity. It allows a Java program to communicate with a database.

Uses of JDBC

  • Connect Java application with database
  • Insert data
  • Update data
  • Delete data
  • Retrieve data

4. JDBC Architecture

The main components of JDBC are:

  • Java Application
  • JDBC API
  • JDBC Driver Manager
  • JDBC Driver
  • Database

Basic flow:

Java Application
       ↓
    JDBC API
       ↓
Driver Manager
       ↓
  JDBC Driver
       ↓
   Database

5. Types of JDBC Drivers

  1. Type 1 - JDBC-ODBC Bridge Driver
  2. Type 2 - Native API Driver
  3. Type 3 - Network Protocol Driver
  4. Type 4 - Thin Driver

Type 4 drivers are commonly used because they communicate directly with the database.

6. Steps of JDBC

  1. Load/Register the driver
  2. Create database connection
  3. Create Statement or PreparedStatement
  4. Execute SQL query
  5. Process ResultSet
  6. Close connection
Connection con = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/studentdb",
    "root",
    "password"
);

7. Statement

Statement is used to execute SQL statements. 

Statement st = con.createStatement();

ResultSet rs = st.executeQuery(
    "SELECT * FROM students"
);

8. PreparedStatement

PreparedStatement is used for parameterized SQL queries. It is generally preferred when values are supplied dynamically. 

PreparedStatement ps =
    con.prepareStatement(
        "INSERT INTO students VALUES (?, ?)"
    );

ps.setInt(1, 101);
ps.setString(2, "Rahul");

ps.executeUpdate();

9. CallableStatement

CallableStatement is used to call stored procedures from Java. 

CallableStatement cs =
    con.prepareCall("{call getStudents()}");

cs.execute();

10. ResultSet

ResultSet stores the data returned by a SELECT query. 

ResultSet rs = st.executeQuery(
    "SELECT * FROM students"
);

while(rs.next()) {
    System.out.println(rs.getString("name"));
}
