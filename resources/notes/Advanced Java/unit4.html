1. JavaBeans

JavaBean is a reusable Java class that follows certain conventions. It is commonly used to store and transfer data in Java web applications.

Main Features

  • Private properties
  • Public getter and setter methods
  • Usually has a no-argument constructor
  • Reusable component

2. JavaBean Example

public class Student {

    private int id;
    private String name;

    public Student() {
    }

    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

3. MVC Architecture

MVC stands for Model View Controller. It separates an application into three parts.

  • Model: Handles data and business logic
  • View: Displays information to the user
  • Controller: Handles requests and controls application flow

4. Filters

A Filter is used to process a request or response before or after it reaches a servlet.

Common uses:

  • Authentication
  • Logging
  • Security checks
  • Request processing

5. Listeners

Listeners are used to respond to events occurring in a web application.

Examples:

  • Application start/stop events
  • Session creation/destruction
  • Attribute changes

6. RequestDispatcher

RequestDispatcher is used to forward a request from one resource to another. 

RequestDispatcher rd =
    request.getRequestDispatcher(
        "home.jsp"
    );

rd.forward(request, response);

7. sendRedirect()

sendRedirect() sends the client to another URL. 

response.sendRedirect("login.jsp");

It is different from forward because redirect involves a new client request.

8. Session Management

Session management allows a web application to remember information about a user.

  • Cookies
  • HttpSession
  • URL Rewriting
  • Hidden Form Fields

9. Web Application Security Basics

  • Use authentication for protected pages.
  • Validate user input.
  • Use PreparedStatement for database queries.
  • Do not store passwords as plain text.
  • Manage sessions properly.

10. JSP Custom Tags

Custom tags allow developers to create reusable tags for JSP pages. They can reduce repeated presentation code.
