Advanced Java Technology - Unit 3

1. Introduction to JSP

JSP stands for JavaServer Pages. It is a technology used to create dynamic web pages using Java.

JSP pages normally have the .jsp extension.

2. JSP Architecture

Browser
   ↓
Web Server / Tomcat
   ↓
JSP Page
   ↓
Servlet
   ↓
Database / Business Logic
   ↓
Response
   ↓
Browser

3. JSP Life Cycle

  • Translation
  • Compilation
  • Class Loading
  • Instantiation
  • Initialization
  • Request Processing
  • Destruction

4. JSP Directives

Directives provide instructions to the JSP container.

Main directives:

  • page directive
  • include directive
  • taglib directive
<%@ page language="java" %>

<%@ include file="header.jsp" %>

5. JSP Declaration

Declaration is used to declare variables and methods. 

<%! 
int count = 0;

void display() {
    System.out.println("Hello");
}
%>

6. JSP Scriptlet

Scriptlet contains Java code executed when the JSP page is processed. 

<%
String name = "Rahul";
out.println(name);
%>

7. JSP Expression

Expression is used to directly print a value. 

<%= "Hello Student" %>

8. JSP Implicit Objects

JSP provides some predefined objects called implicit objects.

  • request
  • response
  • out
  • session
  • application
  • config
  • pageContext
  • page
  • exception

9. JSP Action Tags

Common action tags include:

  • <jsp:include>
  • <jsp:forward>
  • <jsp:param>
  • <jsp:useBean>

10. JSP Expression Language

Expression Language (EL) provides a simple way to access data in JSP. 

${username}

11. JSP and Servlet Difference

Servlet JSP
Java class Web page containing JSP elements
Mainly handles request processing Mainly used for presentation
HTML inside Java can be difficult HTML is easier to write

12. Session in JSP

<%
session.setAttribute(
    "username", "Rahul"
);
%>

The session object can store information for a particular user.
