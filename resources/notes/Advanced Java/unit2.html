Advanced Java Technology - Unit 2

1. Introduction to Servlet

A Servlet is a Java program that runs on a web server and handles client requests. Servlets are commonly used for creating dynamic web applications.

Apache Tomcat is commonly used as a Servlet/JSP container.

2. Servlet Architecture

Client / Browser
       ↓
HTTP Request
       ↓
Web Server / Tomcat
       ↓
Servlet
       ↓
Business Logic
       ↓
Database
       ↓
HTTP Response
       ↓
Browser

3. Servlet Life Cycle

The main lifecycle methods are:

  • init() - called when servlet is initialized
  • service() - processes requests
  • destroy() - called before servlet is removed
init()
  ↓
service()
  ↓
destroy()

4. HttpServlet

HttpServlet is used for handling HTTP requests. Common methods are:

  • doGet()
  • doPost()
protected void doGet(
    HttpServletRequest request,
    HttpServletResponse response)
{
    // code
}

5. GET and POST

GET POST
Data is generally sent in URL Data is sent in request body
Suitable for retrieving data Suitable for submitting data
Less suitable for sensitive form data Better suited for form submission

6. Request and Response

HttpServletRequest is used to read information sent by the client.

HttpServletResponse is used to send information back to the client. 

String name = request.getParameter("name");

response.setContentType("text/html");

PrintWriter out = response.getWriter();

out.println("Hello " + name);

7. ServletConfig

ServletConfig stores configuration information specific to a servlet.

8. ServletContext

ServletContext provides information shared across the web application.

It can be used to share application-level data.

9. Session Tracking

HTTP is stateless, so session tracking is used to remember users between requests.

  • Cookies
  • URL Rewriting
  • Hidden Form Fields
  • HttpSession

10. Cookies

A cookie is a small piece of information stored by the browser. 

Cookie c = new Cookie("username", "Rahul");

response.addCookie(c);

11. HttpSession

HttpSession session =
    request.getSession();

session.setAttribute(
    "username", "Rahul"
);

Session is commonly used for login systems and user-specific information.

12. Servlet with JDBC

A servlet can receive form data, use JDBC to communicate with a database, and send the result back to the browser.
