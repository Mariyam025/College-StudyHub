2. CRUD Web Application

CRUD stands for:

  • Create - Insert new record
  • Read - Display records
  • Update - Modify record
  • Delete - Remove record

A typical Java web application can implement CRUD using JSP, Servlet and JDBC.

4. DAO Pattern

DAO stands for Data Access Object. It separates database-related code from other application code.

For example, a StudentDAO class can contain methods such as:

  • addStudent()
  • getStudents()
  • updateStudent()
  • deleteStudent()

5. Database Transactions

A transaction is a group of database operations treated as one unit.

Important operations:

  • commit()
  • rollback()
con.setAutoCommit(false);

try {

    // database operations

    con.commit();

} catch(Exception e) {

    con.rollback();
}

6. Connection Pooling

Connection pooling means keeping a group of database connections available for reuse instead of creating a new connection for every request.

It can improve application performance and resource management.

7. Deployment on Apache Tomcat

Apache Tomcat can be used to run Java web applications containing Servlets and JSP.

Basic Steps

  1. Create Dynamic Web Project in Eclipse.
  2. Add Servlet/JSP files.
  3. Configure Apache Tomcat.
  4. Run the project on server.
  5. Open the application in browser.

8. web.xml

web.xml is called the deployment descriptor. It can contain configuration information for a web application.

Modern Servlet applications can also use annotations for configuration. 

@WebServlet("/LoginServlet")
public class LoginServlet
    extends HttpServlet {

}
