Data Structure - Unit 2

1. Stack

Definition: Stack is a linear data structure that follows LIFO (Last In First Out).

Basic Operations

  • Push: Adds an element to the stack.
  • Pop: Removes the top element.

Array Implementation of Stack in C

#include <stdio.h>

#define MAX 5

int stack[MAX];
int top = -1;

void push(int value)
{
    if(top == MAX-1)
        printf("Stack Overflow");
    else
        stack[++top] = value;
}

void pop()
{
    if(top == -1)
        printf("Stack Underflow");
    else
        printf("Popped: %d", stack[top--]);
}

int main()
{
    push(10);
    push(20);
    pop();

    return 0;
}

Output: Popped: 20

2. Applications of Stack

  • Expression conversion
  • Expression evaluation
  • Function calls
  • Undo operations

3. Prefix and Postfix Expressions

Prefix: Operator comes before operands.

Example: +AB

Postfix: Operator comes after operands.

Example: AB+

Infix: A + B

Postfix: AB+

Prefix: +AB

4. Evaluation of Postfix Expression

Postfix expression is evaluated using a stack. Operands are pushed into the stack and operators perform operations on the top elements.

Example: 23+5*
(2 + 3) × 5 = 25

5. Queue

Definition: Queue is a linear data structure that follows FIFO (First In First Out).

Basic Operations

  • Create: Creates a queue.
  • Add: Inserts an element.
  • Delete: Removes an element.

6. Circular Queue

A circular queue connects the last position with the first position. It helps in reusing empty spaces.

Array Implementation of Queue in C

#include <stdio.h>

#define MAX 5

int queue[MAX];
int front = 0;
int rear = -1;

void add(int value)
{
    if(rear == MAX-1)
        printf("Queue Full");
    else
        queue[++rear] = value;
}

void delete()
{
    if(front > rear)
        printf("Queue Empty");
    else
        printf("Deleted: %d", queue[front++]);
}

int main()
{
    add(10);
    add(20);
    delete();

    return 0;
}

Output: Deleted: 10

Quick Revision:
  • Stack → LIFO
  • Push → Insert into stack
  • Pop → Delete from stack
  • Queue → FIFO
  • Add → Insert into queue
  • Delete → Remove from queue
  • Circular queue → Reuses empty positions
