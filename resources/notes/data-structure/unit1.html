Data Structure

Paper: NBCA-201 – Data Structure

Unit 1

1. Introduction

Definition: A data structure is a way of organizing and storing data so that it can be accessed and processed efficiently.

Basic Terminology

  • Data: Raw facts or values.
  • Data Item: A single unit of data.
  • Record: A collection of related data items.
  • File: A collection of related records.
  • Node: A basic element used in linked data structures.

Elementary Data Organization

Data can be organized as individual items, records and collections. Common data structures include arrays, linked lists, stacks, queues, trees and graphs.

Built-in Data Types

Common built-in data types in C include int, char, float, double and void.

Abstract Data Type (ADT)

Definition: An Abstract Data Type describes what operations can be performed on data without specifying how those operations are implemented.

Example: A Stack ADT supports operations such as Push and Pop. It can be implemented using an array or linked list.

2. Arrays

Definition: An array is a collection of elements of the same data type stored in contiguous memory locations.

1D Array

A one-dimensional array stores elements in a single sequence.

Example:

int marks[5] = {70, 80, 65, 90, 75};

Index Formula for 1D Array

Address of A[i] = Base Address + (i − Lower Bound) × Size of each element

2D Array

A two-dimensional array stores data in rows and columns. It is commonly used for representing matrices and tables.

Example:

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Index Formula for 2D Array

For row-major order:

Address of A[i][j] = Base + [(i × Number of Columns) + j] × Size

3D and nD Arrays

Higher-dimensional arrays use additional index values. The indices are converted into a memory offset to locate an element.

Applications of Arrays

  • Storing marks and scores
  • Storing tables
  • Representing matrices
  • Searching data
  • Sorting data

3. Singly Linked List

Definition: A singly linked list consists of nodes where each node contains data and a pointer to the next node.

Node Structure

struct Node {
    int data;
    struct Node *next;
};

Basic Operations

  • Create
  • Traverse
  • Insert
  • Delete

Each node points to the next node. The last node points to NULL.

4. Doubly Linked List

Definition: A doubly linked list contains nodes with data, a pointer to the previous node and a pointer to the next node.

Node Structure

struct Node {
    int data;
    struct Node *prev;
    struct Node *next;
};

Singly vs Doubly Linked List

Singly Linked List Doubly Linked List
Contains one link Contains two links
Points to next node Points to previous and next node
Forward traversal Forward and backward traversal
Uses less memory Uses more memory
Quick Revision:
  • Data structure = organization of data.
  • Array = contiguous memory locations.
  • ADT = defines operations, not implementation.
  • Singly linked list = data + next pointer.
  • Doubly linked list = data + previous + next pointers.
