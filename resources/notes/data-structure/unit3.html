Data Structure - Unit 3

1. Trees

Definition: A tree is a non-linear data structure consisting of nodes connected by edges in a hierarchical manner.

Basic Terminology

  • Root: Topmost node.
  • Parent: Node having child nodes.
  • Child: Node below a parent.
  • Leaf: Node having no child.
  • Edge: Connection between two nodes.
  • Degree: Number of children of a node.

2. Binary Tree

A binary tree is a tree in which every node has at most two children, called left child and right child.

3. Binary Tree Representation

Array Representation

Nodes can be stored in an array using index relationships.

Pointer / Linked List Representation

struct Node
{
    int data;
    struct Node *left;
    struct Node *right;
};

4. Binary Search Tree

Definition: In a Binary Search Tree, smaller values are stored in the left subtree and larger values are stored in the right subtree.

Example: Insert 50, 30 and 70.

30 → Left of 50

70 → Right of 50

5. Strictly Binary Tree

A strictly binary tree is a binary tree in which every node has either exactly two children or no children.

6. Complete Binary Tree

A complete binary tree has all levels completely filled except possibly the last level. The last level is filled from left to right.

7. Extended Binary Tree

An extended binary tree represents missing children using external nodes. Each internal node has two children.

8. Tree Traversals

Traversal Order
In-order Left → Root → Right
Pre-order Root → Left → Right
Post-order Left → Right → Root

In-order Traversal Program

void inorder(struct Node *root)
{
    if(root != NULL)
    {
        inorder(root->left);
        printf("%d ", root->data);
        inorder(root->right);
    }
}

9. Constructing Binary Tree from Traversals

A binary tree can be constructed using suitable traversal sequences. For example, inorder with preorder or inorder with postorder can be used to construct a binary tree.

10. Insertion in BST

To insert a value, compare it with the current node. If it is smaller, move left. If it is larger, move right until an empty position is found.

Quick Revision:
  • Binary Tree → Maximum two children
  • BST → Ordered binary tree
  • In-order → Left, Root, Right
  • Pre-order → Root, Left, Right
  • Post-order → Left, Right, Root
