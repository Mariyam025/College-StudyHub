Data Structure - Unit 5

1. Graphs

Definition: A graph is a non-linear data structure consisting of vertices and edges connecting them.

Basic Terminology

  • Vertex: A node of a graph.
  • Edge: Connection between two vertices.
  • Degree: Number of edges connected to a vertex.
  • Path: Sequence of connected vertices.
  • Connected Graph: A graph where vertices are connected through paths.

2. Graph Representation

Adjacency Matrix

An adjacency matrix represents a graph using a two-dimensional array. The values indicate whether an edge exists between vertices.

Adjacency List

An adjacency list stores a list of neighbouring vertices for each vertex.

Adjacency Matrix Adjacency List
Uses 2D matrix Uses lists
Easy edge checking Useful for sparse graphs

3. Graph Traversal

Depth First Search (DFS)

DFS explores one path deeply before returning and exploring another path. It can use recursion or a stack. 

DFS(v)
{
    Visit v;

    for each unvisited neighbour u
        DFS(u);
}

Breadth First Search (BFS)

BFS visits vertices level by level. It commonly uses a queue. 

BFS(start)
{
    Insert start into queue;

    while(queue is not empty)
    {
        Remove a vertex;
        Visit its unvisited neighbours;
    }
}
DFS BFS
Depth-wise traversal Level-wise traversal
Uses stack/recursion Uses queue

4. Connected Component

A connected component is a group of vertices in which the vertices are reachable from one another within that component.

5. Spanning Tree

A spanning tree is a tree that contains all the vertices of a connected graph.

6. Minimum Cost Spanning Tree

A minimum cost spanning tree is a spanning tree whose total edge cost is minimum.

7. Prim's Algorithm

Prim's algorithm starts with a vertex and repeatedly selects the minimum-cost edge connecting a selected vertex to an unselected vertex.

Basic Steps

  1. Select a starting vertex.
  2. Choose the minimum-cost connecting edge.
  3. Add the new vertex.
  4. Repeat until all vertices are included.

8. Kruskal's Algorithm

Kruskal's algorithm sorts edges according to their cost and selects the smallest suitable edges without creating a cycle.

Basic Steps

  1. Sort all edges by increasing cost.
  2. Select the smallest edge.
  3. Check that it does not create a cycle.
  4. Add it to the spanning tree.
  5. Repeat until the tree is complete.
Example: If edge costs are 1, 2, 4 and 5, Kruskal considers them from smallest to largest and selects suitable edges without forming a cycle.
Quick Revision:
  • Graph = Vertices + Edges
  • Adjacency Matrix = 2D representation
  • Adjacency List = List of neighbours
  • DFS = Depth-first traversal
  • BFS = Breadth-first traversal
  • Spanning Tree = Contains all vertices
  • Prim and Kruskal = Minimum Cost Spanning Tree algorithms
