Data Structure - Unit 4

1. Searching

Definition: Searching is the process of finding a particular element in a collection of data.

Sequential Search

Sequential search checks elements one by one until the required element is found. 

int key = 30;
int found = 0;

for(int i = 0; i < 5; i++)
{
    if(a[i] == key)
    {
        found = 1;
        break;
    }
}

if(found)
    printf("Found");
else
    printf("Not Found");

Binary Search

Binary search works on sorted data. It repeatedly divides the search range into two halves. 

int low = 0;
int high = 4;
int key = 30;

while(low <= high)
{
    int mid = (low + high) / 2;

    if(a[mid] == key)
    {
        printf("Found");
        break;
    }
    else if(key < a[mid])
        high = mid - 1;
    else
        low = mid + 1;
}

2. Sorting

Definition: Sorting means arranging data in a particular order, such as ascending or descending order.

Insertion Sort

Insertion sort takes one element at a time and inserts it into its correct position in the sorted part. 

for(int i = 1; i < n; i++)
{
    int key = a[i];
    int j = i - 1;

    while(j >= 0 && a[j] > key)
    {
        a[j+1] = a[j];
        j--;
    }

    a[j+1] = key;
}

Selection Sort

Selection sort finds the smallest element from the unsorted part and places it at the correct position.

Bubble Sort

Bubble sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Quick Sort

Quick sort selects a pivot and partitions the data into smaller parts, then sorts those parts.

Radix Sort

Radix sort sorts numbers digit by digit, generally starting from the least significant digit.

Sorting Method Main Idea
Insertion Sort Insert element into sorted part
Selection Sort Select minimum element
Bubble Sort Swap adjacent elements
Quick Sort Partition around pivot
Radix Sort Sort digit by digit
Quick Revision:
  • Sequential Search → Checks elements one by one.
  • Binary Search → Works on sorted data.
  • Insertion Sort → Inserts element at correct position.
  • Selection Sort → Selects minimum element.
  • Bubble Sort → Swaps adjacent elements.
  • Quick Sort → Uses pivot and partition.
  • Radix Sort → Processes digits.
