Paper: NBCA-205

1. Logic Gates

Logic gates are electronic circuits that perform logical operations on binary inputs.
GateOperation
ANDOutput 1 only when all inputs are 1
OROutput 1 when any input is 1
NOTInverts the input
XOROutput 1 when inputs are different
XNOROutput 1 when inputs are same
NANDNOT of AND
NORNOT of OR

3. NAND and NOR as Universal Gates

NAND and NOR gates are called universal gates because basic gates can be implemented using them.

4. Combinational Logic

A combinational circuit produces output based only on the present inputs.

5. Adders

Half Adder

Adds two binary bits and produces Sum and Carry.

Full Adder

Adds three bits including carry input.

6. Subtractor

A subtractor performs binary subtraction.

  • Half Subtractor
  • Full Subtractor

7. Decoder

A decoder converts coded input into a corresponding output line.

8. Encoder

An encoder converts active input into a coded output.

9. Multiplexer

A multiplexer selects one input from many inputs and sends it to a single output.

10. Demultiplexer

A demultiplexer takes one input and sends it to one of several outputs.

Important Points

  • AND, OR and NOT are basic gates.
  • NAND and NOR are universal gates.
  • Half adder adds two bits.
  • Full adder includes carry input.
  • Multiplexer = many inputs to one output.
  • Demultiplexer = one input to many outputs.
