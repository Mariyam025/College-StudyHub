Digital Electronics and Computer Organization - Unit 1

Paper: NBCA-205

1. Number System

A number system is a method of representing numbers using a set of symbols and rules.
Number SystemBase
Decimal10
Binary2
Octal8
Hexadecimal16

2. Decimal Number System

Uses digits 0 to 9.

Example: 24510

3. Binary Number System

Uses only 0 and 1.

Example: 10112

4. Octal Number System

Uses digits 0 to 7.

Example: 7258

5. Hexadecimal Number System

Uses 0-9 and A-F.

Example: 2AF16

6. Number System Conversion

Numbers can be converted from decimal to binary, octal or hexadecimal and vice versa.

Example: Decimal 10 = Binary 1010

7. Arithmetic of Number Systems

  • Binary Addition
  • Binary Subtraction
  • Binary Multiplication
  • Binary Division

8. Coding System

A coding system represents information using a specific pattern of bits.

Examples: BCD, ASCII, EBCDIC, Gray Code.

9. Character Codes

Character codes represent letters, numbers and symbols in digital form.

  • ASCII
  • EBCDIC
  • Unicode

10. Error Detecting and Correcting Codes

Error detecting codes identify errors in data.

Error correcting codes identify and correct certain errors.

Examples: Parity Code and Hamming Code.

11. Boolean Algebra

Boolean algebra is a mathematical system used to represent and simplify logical operations.

12. Basic Boolean Operations

  • AND
  • OR
  • NOT

13. Boolean Functions

A Boolean function is an expression formed using Boolean variables and logical operators.

Example: F = A + B

14. Canonical and Standard Forms

  • Sum of Products (SOP)
  • Product of Sums (POS)

15. K-Map

Karnaugh Map is a graphical method used to simplify Boolean expressions.

It can be used for functions of up to five variables according to the syllabus.

16. Don't Care Conditions

Don't-care conditions are input combinations for which the output can be either 0 or 1.

Important Points

  • Binary has base 2.
  • Decimal has base 10.
  • Octal has base 8.
  • Hexadecimal has base 16.
  • Boolean algebra is used in digital circuits.
  • K-Map simplifies Boolean expressions.
