Digital Electronics - Unit 3

Paper: NBCA-205

1. Sequential Logic

A sequential circuit is a circuit whose output depends on present inputs as well as previous state.

2. Latch

A latch is a basic memory circuit used to store one bit of information.

3. Flip-Flop

A flip-flop is a digital circuit capable of storing one bit.

4. Types of Flip-Flops

  • RS Flip-Flop
  • Clocked RS Flip-Flop
  • JK Flip-Flop
  • D Flip-Flop
  • T Flip-Flop

5. RS Flip-Flop

It has Set (S) and Reset (R) inputs.

SRAction
00No Change
01Reset
10Set
11Invalid

6. JK Flip-Flop

JK flip-flop removes the invalid state of the basic RS flip-flop.

7. D Flip-Flop

D flip-flop is commonly used for storing a single bit of data.

8. T Flip-Flop

T flip-flop toggles its output when T = 1.

9. Master-Slave Flip-Flop

It consists of two stages: master and slave. It helps avoid unwanted changes during clock operation.

10. Edge and Level Triggering

  • Edge Triggering: Changes occur at a clock edge.
  • Level Triggering: Changes occur during a particular clock level.

11. Registers

A register is a group of flip-flops used to store multiple bits.

12. Shift Registers

Shift registers move stored bits from one position to another.

13. Counters

A counter is a sequential circuit used to count clock pulses.

14. Ripple Counter

A ripple counter is an asynchronous counter in which flip-flops are triggered one after another.

15. Ring Counter

A ring counter circulates a bit pattern through a series of flip-flops.

16. Johnson Counter

A Johnson counter is a modified ring counter in which the inverted output is fed back.

17. Synchronous Circuit

All flip-flops operate according to a common clock.

18. Asynchronous Circuit

Flip-flops do not necessarily operate from a common clock.

Important Points

  • Sequential circuits have memory.
  • Flip-flop stores one bit.
  • Registers store multiple bits.
  • Counters count clock pulses.
  • Ring and Johnson counters are important counter types.
