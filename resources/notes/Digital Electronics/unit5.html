Digital Electronics and Computer Organization - Unit 5

Paper: NBCA-205

1. Control Unit

The Control Unit controls and coordinates the activities of different components of the computer.

2. Instruction Types

Instructions tell the processor what operation needs to be performed.

3. Instruction Format

An instruction format defines the arrangement of different fields in an instruction.

Common fields include:

  • Opcode
  • Operand
  • Address field

4. Instruction Cycle

The instruction cycle is the sequence of operations performed by CPU to execute an instruction.

Fetch → Decode → Execute

5. Instruction Sub-Cycles

  • Fetch cycle
  • Decode cycle
  • Execute cycle

6. Micro-Operations

Micro-operations are small operations performed on data stored in registers.

Examples:

  • Register transfer
  • Arithmetic operation
  • Logic operation
  • Shift operation

7. Execution of Complete Instruction

The CPU fetches the instruction, decodes it and performs the required operation.

8. Memory

Memory stores programs, instructions and data required by the computer.

9. Semiconductor RAM

RAM is a volatile memory that allows data to be read and written.

10. ROM

ROM is non-volatile memory mainly used to store permanent instructions.

11. Cache Memory

Cache is a small and very fast memory located close to or inside the processor. It stores frequently used data and instructions.

12. Input/Output

I/O allows communication between the computer and external devices.

13. Peripheral Devices

Peripheral devices are external devices connected to a computer.

Examples: Keyboard, mouse, printer, scanner.

14. I/O Interface

An I/O interface provides communication between CPU and peripheral devices.

15. I/O Ports

An I/O port is an interface through which a device communicates with the computer.

16. Interrupts

An interrupt is a signal that temporarily requests the CPU to stop its current execution and handle an important event.

17. Interrupt Hardware

Interrupt hardware detects interrupt signals and transfers control to the appropriate service routine.

18. Types of Interrupts

  • Hardware Interrupt
  • Software Interrupt
  • Maskable Interrupt
  • Non-Maskable Interrupt

19. Standard Communication Interfaces

Communication interfaces allow computers and peripheral devices to exchange data.

Examples: USB, Serial interface.

Important Points

  • Control Unit controls CPU operations.
  • Instruction cycle includes fetch, decode and execute.
  • RAM is volatile.
  • ROM is non-volatile.
  • Cache is faster than main memory.
  • Interrupts notify CPU about important events.
