Digital Electronics and Computer Organization - Unit 4

Paper: NBCA-205

1. Computer Organization

Computer organization describes how the internal components of a computer are connected and operate together.

2. Bus Architecture

A bus is a communication pathway used to transfer data, addresses and control signals.

  • Data Bus
  • Address Bus
  • Control Bus

3. Bus and Memory Transfer

Data and instructions are transferred between processor and memory through buses.

4. Processor Organization

The processor contains registers, ALU and control unit to execute instructions.

5. General Register Organization

Registers are small, fast storage locations inside the processor.

6. Stack Organization

A stack is a memory organization that follows LIFO (Last In First Out).

Operations: PUSH and POP.

7. Addressing Modes

Addressing modes specify how the operand of an instruction is located.

  • Immediate
  • Direct
  • Indirect
  • Register
  • Register Indirect

8. Arithmetic and Logic Unit

ALU performs arithmetic and logical operations.

9. Fixed Point Representation

In fixed-point representation, the position of the decimal/binary point remains fixed.

10. Floating Point Representation

Floating-point representation represents very large or very small numbers using sign, exponent and mantissa/significand.

11. IEEE Floating Point Standard

IEEE 754 is a standard for representing floating-point numbers.

Floating Point Number = Sign + Exponent + Fraction

12. Signed Operand Multiplication

Signed multiplication performs multiplication of positive and negative binary numbers using their signed representations.

13. Booth's Algorithm

Booth's algorithm is an efficient algorithm used for multiplication of signed binary numbers.

Important Points

  • Bus transfers information between computer components.
  • ALU performs arithmetic and logical operations.
  • Stack follows LIFO.
  • Addressing mode identifies operand location.
  • IEEE 754 represents floating-point numbers.
  • Booth's algorithm is used for signed multiplication.
