Computer Graphics - Unit 1

1. Introduction to Computer Graphics

Computer Graphics is the field of computer science concerned with creating, displaying, manipulating and storing graphical images using computers.

It is used to create both two-dimensional and three-dimensional visual content.

2. Applications of Computer Graphics

  • Computer-Aided Design (CAD)
  • Computer games
  • Animation
  • Education
  • Medical imaging
  • Scientific visualization
  • Data visualization
  • Movies and entertainment
  • Virtual reality
  • Simulation

3. Graphics System

A graphics system consists of hardware and software used to create and display graphical information.

4. Pixels

A pixel is the smallest addressable element of a digital image or display.

A screen contains many pixels arranged in rows and columns.

5. Resolution

Resolution refers to the number of pixels that can be displayed horizontally and vertically.

Example:

1920 × 1080

Higher resolution generally provides more image detail.

6. Raster Scan Display

In a raster scan display, the screen is refreshed line by line from top to bottom.

It is widely used in modern display systems.

7. Random Scan Display

A random scan display draws only the required lines and curves rather than scanning the complete screen line by line.

It is also called a vector display.

8. CRT

CRT stands for Cathode Ray Tube. It uses an electron beam to create images on a phosphor-coated screen.

Main Parts

  • Electron gun
  • Focusing system
  • Deflection system
  • Phosphor screen

9. Flat Panel Displays

Flat panel displays are thin display devices.

Examples:

  • LCD
  • LED
  • OLED

10. Input Devices

  • Keyboard
  • Mouse
  • Joystick
  • Trackball
  • Light pen
  • Touch screen
  • Graphics tablet
  • Scanner

11. Hard Copy Devices

Hard copy devices produce a physical output of graphical information.

  • Printers
  • Plotters

12. Graphics Software

Graphics software provides tools for creating and editing images, drawings, animations and graphical models.

Examples include:

  • Adobe Photoshop
  • Blender
  • AutoCAD
  • Other graphics and CAD tools
