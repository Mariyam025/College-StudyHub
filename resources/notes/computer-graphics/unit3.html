Computer Graphics - Unit 3

1. 2D Geometric Transformations

Geometric transformations are used to change the position, size or orientation of graphical objects.

Main transformations:

  • Translation
  • Rotation
  • Scaling
  • Reflection
  • Shearing

2. Translation

Translation moves an object from one position to another without changing its size or shape. 

x' = x + Tx
y' = y + Ty

Tx and Ty are translation distances.

3. Scaling

Scaling changes the size of an object. 

x' = x × Sx
y' = y × Sy

Sx and Sy are scaling factors.

4. Rotation

Rotation turns an object around a fixed point.

For rotation by angle θ about the origin:

x' = x cosθ - y sinθ

y' = x sinθ + y cosθ

5. Reflection

Reflection produces a mirror image of an object.

Common types:

  • Reflection about X-axis
  • Reflection about Y-axis
  • Reflection about origin

6. Shearing

Shearing changes the shape of an object by shifting its coordinates in a particular direction.

X-Shear

x' = x + Shx × y
y' = y

Y-Shear

x' = x
y' = y + Shy × x

7. Homogeneous Coordinates

Homogeneous coordinates allow geometric transformations to be represented using matrix operations.

A 2D point can be represented as:

(x, y, 1)

8. Transformation Matrix

For a 2D point:

| x' |   | a b c | | x |
| y' | = | d e f | | y |
| 1  |   | 0 0 1 | | 1 |

9. Composite Transformation

When two or more transformations are applied one after another, the process is called composite transformation.

Example:

Translation
     ↓
Rotation
     ↓
Scaling

10. 3D Transformation

Three-dimensional transformations operate on x, y and z coordinates.

Common 3D transformations:

  • 3D Translation
  • 3D Rotation
  • 3D Scaling
  • 3D Reflection
  • 3D Shearing

11. Window and Viewport

A window defines the selected area of the world coordinate system. A viewport defines the area on the display where the selected scene is shown. 

World Coordinates
       ↓
     Window
       ↓
Transformation
       ↓
    Viewport
       ↓
Screen
