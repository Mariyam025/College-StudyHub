Computer Graphics - Unit 2

1. Graphics Primitives

Graphics primitives are basic shapes used to construct graphical objects.

  • Point
  • Line
  • Circle
  • Ellipse
  • Polygon

2. Line Drawing

Line drawing algorithms are used to determine which pixels should be displayed to represent a line.

Important algorithms:

  • DDA Algorithm
  • Bresenham's Line Algorithm

3. DDA Algorithm

DDA stands for Digital Differential Analyzer. It is an incremental line drawing algorithm.

Steps

  1. Calculate dx and dy.
  2. Find the number of steps.
  3. Calculate x increment.
  4. Calculate y increment.
  5. Plot the points.
dx = x2 - x1
dy = y2 - y1

steps = max(|dx|, |dy|)

xIncrement = dx / steps
yIncrement = dy / steps

4. Bresenham's Line Algorithm

Bresenham's algorithm uses integer calculations to draw a line efficiently on a raster display.

It is generally more efficient than DDA because it avoids floating-point calculations in the basic algorithm.

5. Circle Drawing

Circle drawing algorithms determine the pixels needed to represent a circle.

Important algorithm:

  • Midpoint Circle Algorithm

6. Midpoint Circle Algorithm

The midpoint circle algorithm uses a decision parameter to determine which pixel should be selected while drawing a circle.

It uses the symmetry of a circle to reduce calculations.

7. Ellipse Drawing

An ellipse is a closed curve having two different radii: major radius and minor radius.

Midpoint methods can also be used for ellipse generation.

8. Polygon

A polygon is a closed graphical object made up of connected line segments.

Examples:

  • Triangle
  • Rectangle
  • Pentagon
  • Hexagon

9. Polygon Filling

Polygon filling means filling the interior region of a polygon with a color or pattern.

Common methods:

  • Scan Line Fill
  • Boundary Fill
  • Flood Fill

10. Boundary Fill

Boundary Fill fills an area until a specified boundary color is encountered.

11. Flood Fill

Flood Fill replaces a connected region having the same old color with a new color.

It is commonly used in paint applications.

12. Scan Line Fill

Scan Line Fill processes horizontal lines across a polygon and fills the pixels lying between polygon intersections.
