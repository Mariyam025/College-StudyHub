Computer Graphics - Unit 4

1. 2D Viewing

Viewing determines which portion of a graphical scene will be displayed on the screen.

The viewing process converts objects from world coordinates into screen coordinates.

2. Viewing Pipeline

World Coordinates
       ↓
Viewing Transformation
       ↓
Clipping
       ↓
Window to Viewport
       ↓
Screen Coordinates

3. Clipping

Clipping removes portions of graphical objects that lie outside the selected viewing region.

It improves efficiency because only visible portions need to be displayed.

4. Point Clipping

A point is displayed if it lies inside the clipping window. Otherwise, it is rejected.

5. Line Clipping

Line clipping determines which portion of a line lies inside the viewing window.

Important algorithms:

  • Cohen-Sutherland Algorithm
  • Cyrus-Beck Algorithm
  • Midpoint Subdivision Algorithm

6. Cohen-Sutherland Algorithm

The Cohen-Sutherland algorithm uses region codes to determine whether a line is completely inside, completely outside, or partially inside the clipping window.

The window is divided into regions and each endpoint is assigned a code. 

        TOP
         |
LEFT ----+---- RIGHT
         |
       BOTTOM

7. Cyrus-Beck Algorithm

Cyrus-Beck is a parametric line clipping algorithm. It can be used with convex clipping regions.

It calculates the entering and leaving points of a line with respect to the clipping boundaries.

8. Polygon Clipping

Polygon clipping removes the portions of a polygon outside the clipping window.

An important algorithm is the Sutherland-Hodgman polygon clipping algorithm.

9. Sutherland-Hodgman Algorithm

The Sutherland-Hodgman algorithm clips a polygon against the boundaries of a clipping window one boundary at a time. 

Polygon
   ↓
Left Boundary
   ↓
Right Boundary
   ↓
Bottom Boundary
   ↓
Top Boundary
   ↓
Clipped Polygon

10. Curve Clipping

Curve clipping removes the portions of curves that lie outside the clipping region.

11. Text Clipping

Text clipping determines which portions of text should be displayed inside the viewing area.

Common approaches include:

  • All-or-none string clipping
  • All-or-none character clipping
  • Individual character clipping

12. Viewing Transformation

Viewing transformation converts coordinates from the world coordinate system into a suitable display coordinate system.
