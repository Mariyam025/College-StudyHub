Computer Graphics - Unit 5

1. Computer Animation

Computer animation is the process of creating the illusion of motion by displaying a sequence of images or frames.

2. Animation Sequence

An animation sequence consists of multiple frames displayed in a particular order. 

Frame 1 → Frame 2 → Frame 3 → Frame 4
                  ↓
               Motion

3. Types of Animation

  • 2D Animation
  • 3D Animation
  • Traditional Animation
  • Computer Animation
  • Interactive Animation

4. Key Frame Animation

In key frame animation, important positions of an object are specified as key frames.

Intermediate frames are generated between the key frames. 

Key Frame
    ↓
Intermediate Frames
    ↓
Key Frame

5. Tweening

Tweening is the process of generating intermediate frames between two key frames.

It creates smoother movement in animation.

6. Raster Animation

Raster animation displays and updates images represented as pixels on a raster display.

7. Animation Functions

Common animation operations include:

  • Translation
  • Rotation
  • Scaling
  • Object movement
  • Color changes
  • Shape changes

8. Animation Languages

Animation systems may provide languages or scripting mechanisms for controlling objects, movement and timing.

9. Interactive Graphics

Interactive graphics allow the user to interact with graphical objects using input devices.

Examples:

  • Computer games
  • CAD systems
  • Simulation software
  • Virtual reality applications

10. 3D Graphics

3D graphics represent objects using three dimensions:

  • X-axis
  • Y-axis
  • Z-axis

3D graphics are widely used in games, movies, engineering and simulation.

11. Multimedia and Graphics

Multimedia combines multiple forms of digital content.

  • Text
  • Images
  • Audio
  • Video
  • Animation

12. Applications of Computer Animation

  • Movies
  • Games
  • Advertisements
  • Education
  • Training simulations
  • Scientific visualization
  • Virtual reality

13. Advantages of Computer Graphics

  • Easy visualization of complex information
  • Interactive presentation
  • Realistic simulations
  • Better presentation of data
  • Useful for design and modelling
  • Supports animation and multimedia
