Web Design Concepts - Unit 4

1. Introduction to JavaScript

JavaScript is a programming language commonly used to add interactivity and dynamic behavior to web pages.

It can respond to user actions and modify webpage content.

2. Adding JavaScript to HTML

Internal JavaScript

<script>

alert("Hello");

</script>

External JavaScript

<script src="script.js">
</script>

3. Variables

JavaScript commonly uses let, const and var for variables. 

let name = "Rahul";

const age = 20;

var city = "Lucknow";

4. Data Types

  • String
  • Number
  • Boolean
  • Undefined
  • Null
  • Object
  • Array

5. Operators

  • Arithmetic operators
  • Assignment operators
  • Comparison operators
  • Logical operators
  • Increment and decrement operators
let a = 10;
let b = 5;

let sum = a + b;

6. Conditional Statements

let age = 20;

if(age >= 18) {
    console.log("Adult");
}
else {
    console.log("Minor");
}

7. Loops

For Loop

for(let i = 1; i <= 5; i++) {
    console.log(i);
}

While Loop

let i = 1;

while(i <= 5) {
    console.log(i);
    i++;
}

8. Functions

function add(a, b) {
    return a + b;
}

let result = add(10, 20);

9. Arrays

let students = [
    "Rahul",
    "Priya",
    "Aman"
];

console.log(students[0]);

Common methods:

  • push()
  • pop()
  • shift()
  • unshift()
  • forEach()

10. JavaScript Events

Events occur when the user or browser performs an action.

  • click
  • mouseover
  • keydown
  • submit
  • change
  • load
button.addEventListener(
    "click",
    function() {
        alert("Button clicked");
    }
);

11. DOM

DOM stands for Document Object Model. It represents an HTML document as a structure of objects. 

document.getElementById("title");

JavaScript can use the DOM to read and modify HTML elements.

12. Form Validation

JavaScript can check user input before a form is submitted. 

function validate() {

    let name =
        document.getElementById("name").value;

    if(name == "") {
        alert("Name is required");
        return false;
    }

    return true;
}
