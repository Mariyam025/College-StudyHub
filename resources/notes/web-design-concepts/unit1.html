Web Design Concepts - Unit 1

1. Introduction to Internet

The Internet is a worldwide network of interconnected computers and devices. It allows users to communicate and share information.

Common Internet Services

  • World Wide Web
  • Email
  • File Transfer
  • Online communication
  • Video conferencing
  • Online shopping

2. World Wide Web

The World Wide Web (WWW) is a collection of interconnected web pages and resources accessed through the Internet.

Web pages are commonly accessed using web browsers.

3. Web Browser

A web browser is software used to access and display web pages.

Examples:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

4. Web Server

A web server is a computer or software that receives requests from clients and provides web resources in response.

Examples of web server software include Apache HTTP Server and Nginx.

5. Client-Server Model

Client / Browser
       ↓
     Request
       ↓
    Web Server
       ↓
    Processing
       ↓
    Response
       ↓
Client / Browser

The client requests a resource and the server responds with the requested resource or result.

6. HTTP

HTTP stands for HyperText Transfer Protocol. It is used for communication between web clients and servers.

HTTPS is the secure version of HTTP and uses encryption to protect communication.

7. URL

URL stands for Uniform Resource Locator. It identifies the location of a resource on the web. 

https://www.example.com/about.html

A URL can contain:

  • Protocol
  • Domain name
  • Path
  • Query parameters

8. Domain Name

A domain name is a human-readable name used to identify a website.

Example:

example.com

DNS translates domain names into IP addresses.

9. Static Website

A static website generally displays fixed content. Its pages are usually created using HTML and CSS.

Example: Portfolio or simple informational website.

10. Dynamic Website

A dynamic website can generate or change content based on user interaction, data or server-side processing.

Example: Online shopping or banking website.

11. Frontend and Backend

  • Frontend: The part users see and interact with.
  • Backend: Handles server-side logic, databases and application processing.

HTML, CSS and JavaScript are commonly used for frontend development.
