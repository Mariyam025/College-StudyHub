Web Design Concepts - Unit 3

1. Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML elements.

CSS can control:

  • Colors
  • Fonts
  • Spacing
  • Borders
  • Layout
  • Responsive design

2. CSS Syntax

selector {
    property: value;
}

Example:

p {
    color: blue;
    font-size: 18px;
}

3. Types of CSS

Inline CSS

<p style="color:red;">
Hello
</p>

Internal CSS

<style>

p {
    color: red;
}

</style>

External CSS

<link rel="stylesheet"
      href="style.css">

4. CSS Selectors

Element Selector

p {
    color: red;
}

Class Selector

.card {
    padding: 20px;
}

ID Selector

#header {
    background: white;
}

5. Colors and Background

body {
    background-color: #f4fafa;
}

h1 {
    color: #00838f;
}

6. CSS Fonts and Text

p {
    font-family: Arial;
    font-size: 18px;
    text-align: center;
    font-weight: bold;
}

7. CSS Box Model

Every HTML element can be understood using the CSS box model. 

Content
   ↓
Padding
   ↓
Border
   ↓
Margin
  • Content: Actual content
  • Padding: Space inside the border
  • Border: Boundary around the element
  • Margin: Space outside the border

8. Width and Height

.card {
    width: 300px;
    height: 200px;
}

9. Display Property

Common values:

  • block
  • inline
  • inline-block
  • none
.menu {
    display: flex;
}

10. Flexbox

Flexbox is a CSS layout system used to arrange elements in rows or columns. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}

11. Responsive Web Design

Responsive design makes a website adapt to different screen sizes such as mobile, tablet and desktop. 

@media (max-width: 600px) {

    .container {
        width: 100%;
    }

}

12. CSS Pseudo Classes

Pseudo-classes define a special state of an element. 

button:hover {
    background: black;
}

Examples:

  • :hover
  • :focus
  • :active
  • :first-child
