Web Design Concepts - Unit 2

1. Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

HTML uses elements and tags to define the content of a webpage.

2. Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Page</title>
</head>

<body>
    <h1>Hello</h1>
    <p>Welcome to my website.</p>
</body>

</html>

3. HTML Headings

HTML provides six heading levels from h1 to h6. 

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Another Heading</h3>

4. Paragraph and Text Formatting

<p>This is a paragraph.</p>

<b>Bold</b>
<i>Italic</i>
<u>Underline</u>
<strong>Important</strong>
<em>Emphasized</em>

5. Lists

Unordered List

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Ordered List

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

6. Hyperlinks

The anchor tag is used to create links. 

<a href="about.html">About Us</a>

7. Images

<img src="photo.jpg"
     alt="Student Photo"
     width="300">

The alt attribute provides alternative text for the image.

8. Tables

<table border="1">

<tr>
    <th>Name</th>
    <th>Course</th>
</tr>

<tr>
    <td>Rahul</td>
    <td>BCA</td>
</tr>

</table>

9. HTML Forms

Forms are used to collect information from users. 

<form>

    <label>Name:</label>

    <input type="text"
           name="name">

    <input type="submit"
           value="Submit">

</form>

10. Form Controls

  • Text box
  • Password field
  • Radio button
  • Checkbox
  • Dropdown
  • Textarea
  • Submit button

11. HTML5 Semantic Elements

  • <header>
  • <nav>
  • <main>
  • <section>
  • <article>
  • <aside>
  • <footer>

Semantic elements make the structure of a webpage clearer.
