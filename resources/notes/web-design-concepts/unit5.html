Web Design Concepts - Unit 5

1. Web Hosting

Web hosting is a service that provides storage and resources required to make a website accessible through the Internet.

2. Types of Web Hosting

  • Shared Hosting
  • VPS Hosting
  • Dedicated Hosting
  • Cloud Hosting

3. Domain Registration

A domain name is registered through a domain registrar. The domain provides a human-readable address for a website.

Example:

www.mystudyhub.com

4. DNS

DNS stands for Domain Name System. It translates domain names into IP addresses so that computers can locate the required server.

5. FTP

FTP stands for File Transfer Protocol. It can be used to transfer files between a computer and a server.

FTP clients can be used to upload and manage website files.

6. Website Deployment

  1. Create the website.
  2. Test all pages.
  3. Purchase/register domain if required.
  4. Select hosting.
  5. Upload website files.
  6. Configure domain and DNS.
  7. Test the live website.

7. Website Maintenance

Website maintenance means regularly updating and managing a website.

  • Update content
  • Fix broken links
  • Improve security
  • Take backups
  • Check performance
  • Update software

8. Introduction to SEO

SEO stands for Search Engine Optimization. It involves practices that help search engines understand and discover website content.

9. On-Page SEO

On-page SEO involves improvements made directly on webpages.

  • Useful page titles
  • Clear headings
  • Descriptive content
  • Good URL structure
  • Image alt text
  • Internal links
  • Mobile-friendly design

10. Meta Tags

Meta tags provide information about a webpage to browsers and search engines. 

<meta name="description"
      content="College StudyHub Notes">

11. Responsive Website

A responsive website adjusts its layout according to the screen size. 

Desktop
   ↓
Tablet
   ↓
Mobile

Responsive design improves usability across different devices.

12. Important Web Design Principles

  • Simple navigation
  • Readable text
  • Consistent design
  • Fast loading
  • Mobile responsiveness
  • Accessibility
  • Clear content hierarchy

13. Web Accessibility

Web accessibility means designing websites so that people with different abilities can use them effectively.

  • Use meaningful alt text.
  • Use proper headings.
  • Provide labels for forms.
  • Ensure sufficient text readability.
  • Make navigation keyboard-friendly.
