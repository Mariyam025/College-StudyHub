Data Analytics - Unit 2

1. Data Exploration

Data Exploration is the process of examining a dataset to understand its structure, characteristics, patterns, relationships and problems before performing detailed analysis.

Data exploration helps an analyst understand what the data contains and whether it is suitable for analysis.

2. Data Profiling

Data Profiling is the process of examining data to understand its structure, content, quality, completeness and relationships.

Objectives of Data Profiling

  • Understand the structure of data.
  • Find missing values.
  • Find duplicate records.
  • Identify incorrect values.
  • Find unusual values.
  • Understand data distributions.
  • Check data quality.

Types of Data Profiling

  • Structure Discovery: Understand columns, data types and formats.
  • Content Discovery: Examine actual values and their distributions.
  • Relationship Discovery: Identify relationships between fields or tables.

3. Analysing Target Data

Target Data refers to the data or target variable that an analysis or predictive model is mainly trying to explain or predict.
Example:
If we want to predict whether a student will pass or fail, then Pass/Fail can be the target variable.

Steps for Analysing Target Data

  1. Identify the target variable.
  2. Check its data type.
  3. Check missing values.
  4. Check unusual values.
  5. Study its distribution.
  6. Study relationships with other variables.

4. Statistics

Statistics is the science of collecting, organizing, analyzing, interpreting and presenting data.

5. Population and Sample

Population

Population means the complete group of individuals or observations being studied.

Example: All students of a college.

Sample

A sample is a smaller part selected from the population.

Example: 100 students selected from the college.
Population Sample
Entire group Part of the group
Usually larger Usually smaller
More difficult to study Easy and less expensive to study

6. Random Sample

A random sample is selected in such a way that each member of the population has a known chance of being selected.

Example: Randomly selecting 50 students from a list of 500 students.

7. Mean

Mean is the arithmetic average of a set of values.
Mean = Sum of all values / Number of values
Data: 10, 20, 30
Mean = (10 + 20 + 30) / 3 = 20

8. Median

Median is the middle value when data is arranged in ascending or descending order.

Data: 10, 20, 30, 40, 50
Median = 30

For an even number of observations, median is the average of the two middle values.

Data: 10, 20, 30, 40
Median = (20 + 30) / 2 = 25

9. Mode

Mode is the value that occurs most frequently in a dataset.

Data: 2, 3, 3, 4, 5
Mode = 3

10. Range

Range represents the difference between the maximum and minimum values.

Range = Maximum Value - Minimum Value
Data: 10, 20, 40, 50
Range = 50 - 10 = 40

11. Variance

Variance measures how far the values in a dataset are spread from the mean.

Population Variance = Σ(x - μ)² / N

Where:

  • x = individual value
  • μ = population mean
  • N = number of observations

12. Standard Deviation

Standard deviation measures the amount of variation or dispersion in a dataset. It is the square root of variance.

Standard Deviation = √Variance

A small standard deviation means values are close to the mean. A large standard deviation means values are more spread out.

13. Probability

Probability is a measure of how likely an event is to occur.

Probability lies between 0 and 1.

  • 0 = Impossible event
  • 1 = Certain event
  • Between 0 and 1 = Possible event
P(E) = Number of favourable outcomes / Total number of possible outcomes

14. Experiment

An experiment is a process that produces an outcome.

Example: Tossing a coin.

15. Sample Space

Sample space is the set of all possible outcomes of an experiment.

Tossing a coin:
S = {Head, Tail}

16. Event

An event is a particular outcome or group of outcomes from the sample space.

Rolling a die and getting an even number:
E = {2, 4, 6}

17. Types of Events

  • Simple Event: Contains one outcome.
  • Compound Event: Contains more than one outcome.
  • Independent Events: One event does not affect another.
  • Dependent Events: One event affects another.
  • Mutually Exclusive Events: Events cannot happen together.

18. Conditional Probability

Conditional probability is the probability of an event occurring when another event is already known to have occurred.
P(A | B) = P(A ∩ B) / P(B)

Here, P(A | B) means probability of A given B.

Example: If we know that a randomly selected student is a girl, what is the probability that she is from BCA?

19. Bayes' Theorem

Bayes' theorem is used to calculate the probability of an event based on previous knowledge or evidence.

P(A | B) = [P(B | A) × P(A)] / P(B)

Where:

  • P(A) = Prior probability
  • P(B | A) = Likelihood
  • P(A | B) = Posterior probability
  • P(B) = Evidence

Applications of Bayes' Theorem

  • Medical diagnosis
  • Spam email detection
  • Fraud detection
  • Machine learning
  • Risk analysis

20. Discrete Distribution

A discrete probability distribution deals with countable values.

Examples: Number of students, number of calls, number of defective products.

21. Continuous Distribution

A continuous probability distribution deals with measurable values that can take any value within a range.

Examples: Height, weight, temperature and time.
Discrete Continuous
Countable values Measurable values
Number of students Student height
Number of calls Call duration

22. Normal Distribution

Normal distribution is a continuous probability distribution with a characteristic bell-shaped curve.

Characteristics

  • Bell-shaped curve.
  • Symmetrical distribution.
  • Mean, median and mode are equal.
  • Total area under the curve is 1.
  • Most observations are near the mean.

23. 68-95-99.7 Rule

For a normal distribution:

  • Approximately 68% values lie within 1 standard deviation.
  • Approximately 95% values lie within 2 standard deviations.
  • Approximately 99.7% values lie within 3 standard deviations.
Easy Trick:
1 SD → 68%
2 SD → 95%
3 SD → 99.7%

24. Covariance

Covariance indicates whether two variables tend to increase or decrease together.

  • Positive covariance → variables generally move in the same direction.
  • Negative covariance → variables generally move in opposite directions.
  • Near-zero covariance → weak linear relationship.

25. Correlation

Correlation measures the strength and direction of the relationship between two variables.

The correlation coefficient generally ranges from -1 to +1.

Value Meaning
+1 Perfect positive correlation
0 No linear correlation
-1 Perfect negative correlation
Important: Correlation does not automatically mean causation.

26. Descriptive and Inferential Statistics

Descriptive Statistics

Descriptive statistics summarizes and describes the available data.

Examples: Mean, median, mode, range and standard deviation.

Inferential Statistics

Inferential statistics uses sample data to make conclusions about a larger population.

Example: Surveying 500 voters and using the results to understand the larger population.

27. Importance of Statistics in Data Analytics

  • Summarizes large datasets.
  • Helps identify patterns.
  • Supports decision-making.
  • Helps compare datasets.
  • Supports prediction.
  • Helps measure uncertainty.
  • Supports model evaluation.
