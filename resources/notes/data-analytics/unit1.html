Data Analytics - Unit 1

1. Introduction to Data

Data: Data is a collection of raw facts, figures, observations or values that can be processed to obtain useful information.

Examples of data include student marks, names, ages, sales records, temperature readings, images, videos and social media posts.

Example:
75, 82, 68, 91, 80 are raw marks. After calculating their average, we obtain useful information about the student's performance.

2. Data vs Information vs Knowledge

Term Meaning Example
Data Raw facts and values 80, 70, 90
Information Processed and meaningful data Average marks = 80
Knowledge Understanding obtained from information Student is performing well

3. Sources of Data

Data can come from many different sources.

Internal Sources

  • Company databases
  • Sales records
  • Employee records
  • Customer records
  • Transaction records

External Sources

  • Government websites
  • Social media
  • Public datasets
  • Research reports
  • Websites
  • Third-party organizations

Primary Data

Primary data is collected directly by the researcher or organization for a specific purpose.

Example: A college conducts a survey to know students' satisfaction with online classes.

Secondary Data

Secondary data is data that has already been collected by someone else.

Example: Using government population statistics for analysis.

4. Nature of Data

Qualitative Data

Qualitative data describes qualities or categories and is generally non-numerical.

Examples: Gender, colour, city, type of product, feedback.

Quantitative Data

Quantitative data is numerical and can be measured or counted.

Examples: Age, salary, marks, height, weight.

Qualitative Quantitative
Colour Height
Gender Age
City Salary

5. Classification of Data by Structure

Structured Data

Structured data is organized in a fixed format, usually rows and columns.

Example: Student database containing Roll No, Name, Course and Marks.

Semi-Structured Data

Semi-structured data does not follow a strict table structure but contains some organizational elements such as tags or keys.

Examples: JSON, XML, HTML.

Unstructured Data

Unstructured data does not have a predefined tabular structure.

Examples: Images, videos, audio, emails and social media posts.

6. Cross-Sectional and Time-Series Data

Cross-Sectional Data

Data collected from different subjects at one particular point of time.

Example: Income of 100 employees in January 2026.

Time-Series Data

Data collected over different points of time.

Example: Daily temperature recorded for one year.

7. Batch and Real-Time Data

Batch Data

Data is collected and processed in groups at a particular time.

Example: Monthly electricity bill processing.

Real-Time Data

Data is processed almost immediately after it is generated.

Example: Live stock prices or online payment transactions.

8. What is Data Analytics?

Data Analytics is the process of collecting, cleaning, transforming, analyzing and interpreting data to discover useful information and support decision-making.

9. Need for Data Analytics

  • Helps organizations make better decisions.
  • Identifies trends and patterns.
  • Helps understand customers.
  • Improves business performance.
  • Helps detect fraud.
  • Reduces unnecessary costs.
  • Supports prediction and planning.
  • Helps solve real-world problems.

10. Types of Data Analytics

1. Descriptive Analytics

Descriptive analytics answers: "What happened?"

Example: A company sold 10,000 products last month.

2. Diagnostic Analytics

Diagnostic analytics answers: "Why did it happen?"

Example: Sales decreased because the product price increased.

3. Predictive Analytics

Predictive analytics answers: "What is likely to happen?"

Example: Predicting next month's sales.

4. Prescriptive Analytics

Prescriptive analytics answers: "What should we do?"

Example: Suggesting the best discount to increase sales.
Type Main Question
Descriptive What happened?
Diagnostic Why did it happen?
Predictive What may happen?
Prescriptive What should we do?

11. Data Analytics Lifecycle

The Data Analytics Lifecycle is a sequence of phases followed to complete a data analytics project.

Phase 1: Discovery

Understand the business problem, objectives, available resources and data.

Phase 2: Data Preparation

Collect, clean, integrate and prepare the required data.

Phase 3: Model Planning

Select suitable analytical methods, variables and techniques.

Phase 4: Model Building

Build and test analytical models using prepared data.

Phase 5: Communicating Results

Present findings using reports, charts, dashboards or presentations.

Phase 6: Operationalization

Put the analytical solution into practical use and monitor its performance.

Remember:
Discovery → Data Preparation → Model Planning → Model Building → Communicating Results → Operationalization

13. Big Data

Big Data refers to very large, complex and rapidly generated datasets that require specialized technologies and methods for storage and analysis.

5 Vs of Big Data

  • Volume: Huge amount of data.
  • Velocity: Speed at which data is generated.
  • Variety: Different forms of data.
  • Veracity: Reliability and quality of data.
  • Value: Useful information obtained from data.
