1. Input/Output Organization

Input/Output organization deals with communication between the computer system and external devices.

2. I/O Devices

Input Devices

  • Keyboard
  • Mouse
  • Scanner
  • Microphone

Output Devices

  • Monitor
  • Printer
  • Speaker
  • Projector

3. I/O Interface

An I/O interface provides communication between the CPU/memory system and peripheral devices.

4. Programmed I/O

In programmed I/O, the CPU actively checks the status of an I/O device and performs the transfer.

The CPU remains involved in controlling the transfer.

5. Interrupt-Driven I/O

In interrupt-driven I/O, an I/O device signals the CPU when it needs attention or when an operation is ready.

6. Direct Memory Access

DMA allows data to be transferred between an I/O device and main memory with limited CPU involvement during the actual transfer.

DMA is useful for high-speed data transfers.

7. Interrupt

An interrupt is a signal that temporarily requests the processor's attention so that it can handle an event.

Types:

  • Hardware Interrupt
  • Software Interrupt

8. Parallel Processing

Parallel processing is the use of multiple processing elements to perform tasks concurrently.

Benefits:

  • Higher performance
  • Reduced execution time for suitable workloads
  • Better utilization of computing resources

9. Multiprocessor System

A multiprocessor system contains two or more processors that work together within a computer system.

10. Multicore Processor

A multicore processor contains multiple processing cores on a single processor chip.

Examples include dual-core, quad-core and octa-core processors.

11. Flynn's Classification

Flynn's taxonomy classifies computer architectures based on the number of instruction streams and data streams.

  • SISD – Single Instruction Single Data
  • SIMD – Single Instruction Multiple Data
  • MISD – Multiple Instruction Single Data
  • MIMD – Multiple Instruction Multiple Data

12. SISD

SISD represents a system with a single instruction stream operating on a single data stream.

13. SIMD

SIMD performs the same instruction on multiple data elements simultaneously.

It is useful for tasks such as image and multimedia processing.

14. MIMD

MIMD systems allow multiple processors or processing units to execute different instructions on different data.
