1. CPU Organization

CPU organization describes the internal arrangement and operation of the processor components.

2. Register Organization

Registers are high-speed storage elements used to hold data, instructions and addresses during CPU operations.

  • General Purpose Registers
  • Accumulator
  • Program Counter
  • Instruction Register
  • Stack Pointer

3. Program Counter

The Program Counter (PC) stores the address of the next instruction to be fetched from memory.

4. Instruction Register

The Instruction Register (IR) holds the instruction currently being decoded or executed.

5. Stack Pointer

The Stack Pointer stores information used to identify the current top of the stack.

6. Instruction Format

An instruction generally contains an operation code and information about operands.

Part Purpose
Opcode Specifies the operation.
Operand Specifies data or its location.

7. Instruction Types

  • Data Transfer Instructions
  • Arithmetic Instructions
  • Logical Instructions
  • Control Transfer Instructions
  • Input/Output Instructions

8. Addressing Modes

Addressing mode specifies how the operand of an instruction is located.

  • Immediate Addressing
  • Direct Addressing
  • Indirect Addressing
  • Register Addressing
  • Indexed Addressing

9. Immediate Addressing

The operand value is directly included in the instruction.

Example: MOV R1, #10

10. Direct Addressing

The instruction contains the memory address of the operand.

11. Indirect Addressing

The instruction specifies a location that contains the address of the actual operand.

12. RISC

RISC stands for Reduced Instruction Set Computer. It uses a relatively small and simple instruction set.

  • Simple instructions
  • Fast execution
  • Load/store architecture is common

13. CISC

CISC stands for Complex Instruction Set Computer. It supports a large and relatively complex instruction set.

14. RISC vs CISC

RISC CISC
Smaller instruction set Larger instruction set
Instructions are generally simpler Instructions can be more complex
Often emphasizes simple, fast instructions May provide complex operations in fewer instructions
