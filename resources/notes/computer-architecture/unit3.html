1. Memory Organization

Memory organization describes how different types of memory are arranged and used in a computer system.

2. Memory Hierarchy

Memory hierarchy arranges storage according to speed, cost and capacity.

  1. Registers
  2. Cache Memory
  3. Main Memory
  4. Secondary Storage
Higher levels are generally faster and more expensive per bit, while lower levels generally provide larger capacity.

3. Primary Memory

Primary memory is directly accessible by the CPU and is used during program execution.

  • RAM
  • ROM

4. RAM

RAM is a volatile memory used to store programs and data currently being processed.

Types:

  • SRAM
  • DRAM

5. ROM

ROM is non-volatile memory that stores information which normally needs to be retained when power is removed.

Types:

  • PROM
  • EPROM
  • EEPROM

6. Cache Memory

Cache is a small, high-speed memory located close to or integrated with the CPU. It stores frequently used data and instructions.

7. Cache Levels

LevelDescription
L1Small and very fast cache
L2Larger than L1
L3Generally larger and shared in many processors

8. Secondary Memory

Secondary memory provides long-term storage for programs and data.

  • Hard Disk
  • SSD
  • USB Drive
  • Memory Card

9. Virtual Memory

Virtual memory is a memory management technique that uses secondary storage to extend the apparent memory available to programs.

10. Memory Access Time

Memory access time is the time required to read data from or write data to a memory location.

11. Associative Memory

Associative memory, also called Content Addressable Memory (CAM), searches data based on its content rather than only a numeric address.
