1. Number Systems

A number system is a method of representing numbers using specific symbols and rules.

  • Binary
  • Decimal
  • Octal
  • Hexadecimal

2. Binary Number System

Binary uses only two digits: 0 and 1. It is the basic number system used by digital computers.

Example: 1011₂

3. Decimal Number System

Decimal uses ten digits from 0 to 9. It is the number system commonly used by people.

4. Octal Number System

Octal uses eight digits from 0 to 7.

5. Hexadecimal Number System

Hexadecimal uses sixteen symbols: 0–9 and A–F.

Example: 2F₁₆

7. Complements

Complements are used in digital computers for representing negative numbers and performing arithmetic operations.

  • 1's Complement
  • 2's Complement

8. 1's Complement

1's complement is obtained by changing every 0 to 1 and every 1 to 0.

Example:

Binary: 1010

1's Complement: 0101

9. 2's Complement

2's complement is obtained by adding 1 to the 1's complement.

Example: 1010 → 0101 → 0110

10. Signed Number Representation

Signed number representation is used to represent both positive and negative numbers.

  • Sign-Magnitude
  • 1's Complement
  • 2's Complement

11. Floating Point Representation

Floating point representation is used to represent real numbers. It generally contains a sign, exponent and mantissa/significand.

12. Character Representation

Computers represent characters using numerical codes.

  • ASCII
  • Unicode

13. Arithmetic Logic Unit

The ALU performs arithmetic and logical operations on data.

  • Addition
  • Subtraction
  • AND
  • OR
  • Comparison
