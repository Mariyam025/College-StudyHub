Computer Architecture

Unit 1 – Basic Computer Organization

1. Computer Architecture

Computer architecture describes the functional organization and design of a computer system, including its processor, memory and input/output components.

2. Computer Organization

Computer organization describes how the hardware components of a computer are connected and how they operate together.

3. Basic Functional Units

  • Input Unit
  • Memory Unit
  • Arithmetic Logic Unit (ALU)
  • Control Unit
  • Output Unit
CPU mainly consists of the ALU, Control Unit and registers.

4. Central Processing Unit

The CPU is the main processing unit of a computer. It executes instructions and controls other components.

Main components:

  • ALU
  • Control Unit
  • Registers

5. Arithmetic Logic Unit

ALU performs arithmetic and logical operations.

Arithmetic operations:

  • Addition
  • Subtraction
  • Multiplication
  • Division

Logical operations:

  • AND
  • OR
  • NOT
  • Comparison

6. Control Unit

The Control Unit directs and coordinates the operations of the computer by generating control signals.

7. Registers

Registers are small, high-speed storage locations inside the CPU.

Examples:

  • Accumulator
  • Program Counter
  • Instruction Register
  • Memory Address Register
  • Memory Data Register

8. Memory Unit

Memory stores instructions, data and intermediate results required during program execution.

Types:

  • Primary Memory
  • Secondary Memory

9. Input and Output Units

The input unit accepts data and instructions from the user. The output unit presents processed information to the user.

Examples:

  • Keyboard
  • Mouse
  • Monitor
  • Printer

10. Instruction Cycle

The instruction cycle is the sequence of steps performed by the CPU to execute an instruction.

  1. Fetch
  2. Decode
  3. Execute
  4. Store

11. Fetch Cycle

During the fetch cycle, the CPU obtains the next instruction from memory.

12. Decode Cycle

During decoding, the control unit interprets the fetched instruction and determines the required operation.

13. Execute Cycle

During execution, the CPU performs the operation specified by the instruction.

14. System Bus

A bus is a communication pathway used to transfer data and control information between computer components.

BusPurpose
Data BusTransfers data
Address BusCarries addresses
Control BusCarries control signals
