1. List

A list is an ordered and mutable collection of elements.

numbers = [10,20,30,40]
print(numbers)

2. List Operations

a = [1,2,3]

a.append(4)
a.insert(1,10)
a.remove(2)

print(a)

3. List Slicing

numbers = [10,20,30,40,50]

print(numbers[1:4])

4. Nested List

students = [
    ["Aman",20],
    ["Riya",21]
]

print(students[0])

5. Tuple

A tuple is an ordered and immutable collection.

data = (10,20,30)
print(data)

6. Tuple Operations

t = (10,20,30,20)

print(t.count(20))
print(t.index(30))

7. Set

A set is an unordered collection of unique elements.

numbers = {1,2,3,3}
print(numbers)

8. Set Operations

a = {1,2,3}
b = {3,4,5}

print(a | b)
print(a & b)
print(a - b)

9. Dictionary

A dictionary stores data in key-value pairs.

student = {
    "name":"Riya",
    "age":20,
    "course":"BCA"
}

print(student["name"])

10. Dictionary Methods

student = {"name":"Riya","age":20}

print(student.keys())
print(student.values())
print(student.items())

11. Stack Using List

stack = []

stack.append(10)
stack.append(20)
stack.append(30)

print(stack.pop())

12. Queue Using List

queue = []

queue.append(10)
queue.append(20)

print(queue.pop(0))
