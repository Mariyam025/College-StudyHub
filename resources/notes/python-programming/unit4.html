1. File Handling

File handling allows Python programs to create, read, write and modify files.

2. Opening a File

file = open("data.txt","r")

3. File Modes

  • r – Read
  • w – Write
  • a – Append
  • x – Create
  • b – Binary
  • t – Text

4. Reading a File

file = open("data.txt","r")

data = file.read()

print(data)

file.close()

5. Writing to a File

file = open("data.txt","w")

file.write("Hello Python")

file.close()

6. Append Mode

file = open("data.txt","a")

file.write("\nNew Line")

file.close()

7. with Statement

with open("data.txt","r") as file:
    print(file.read())

The with statement automatically handles closing the file.

8. Errors

An error is a problem that prevents a program from working correctly.

  • Syntax Error
  • Runtime Error
  • Logical Error

9. Exception

An exception is an event that occurs during program execution and can interrupt normal program flow.

10. try-except

try:
    a = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")

11. finally

try:
    print("Hello")
except:
    print("Error")
finally:
    print("Program completed")

12. Multiple Exceptions

try:
    num = int(input("Enter number: "))
    result = 10 / num
except ValueError:
    print("Invalid input")
except ZeroDivisionError:
    print("Cannot divide by zero")

13. raise Statement

age = 15

if age < 18:
    raise Exception("Not eligible")
