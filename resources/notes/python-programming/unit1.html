1. What is Python?

Python is a high-level, interpreted and general-purpose programming language. It is widely used for web development, data analysis, artificial intelligence, automation and software development.

2. Features of Python

  • Easy to learn
  • Simple syntax
  • Interpreted language
  • Object-oriented
  • Portable
  • Open source
  • Large standard library
  • Dynamically typed

3. Applications of Python

  • Web Development
  • Artificial Intelligence
  • Machine Learning
  • Data Science
  • Automation
  • Game Development
  • Desktop Applications

4. Python Program

print("Hello World")

The print() function displays output on the screen.

5. Variables

A variable is a name used to store a value.

name = "Mariyam"
age = 19
marks = 85.5

6. Data Types

  • int
  • float
  • complex
  • str
  • list
  • tuple
  • set
  • dictionary
  • boolean

7. Identifiers

Identifiers are names given to variables, functions, classes and other program elements.

Example: student_name

8. Keywords

Keywords are reserved words having special meaning in Python.

Examples: if, else, for, while, class, def, return, import

9. Comments

# This is a comment
print("Hello")

10. Input and Output

name = input("Enter your name: ")
print("Hello", name)

11. Type Conversion

age = int(input("Enter age: "))
price = float("25.5")
number = str(100)

12. Operators

  • Arithmetic: + - * / %
  • Relational: > < == !=
  • Logical: and, or, not
  • Assignment: =, +=, -=
  • Membership: in, not in
  • Identity: is, is not
