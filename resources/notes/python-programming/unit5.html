1. Object-Oriented Programming

Object-Oriented Programming is a programming approach based on classes and objects.

  • Class
  • Object
  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

2. Class

A class is a blueprint for creating objects.

class Student:
    name = "Riya"

3. Object

An object is an instance of a class.

class Student:
    name = "Riya"

s1 = Student()
print(s1.name)

4. Constructor

In Python, __init__() is commonly used to initialize an object's attributes.

class Student:
    def __init__(self,name):
        self.name = name

s = Student("Riya")
print(s.name)

5. self

The self parameter refers to the current object of the class.

6. Inheritance

Inheritance allows one class to acquire properties and methods of another class.

class Animal:
    def sound(self):
        print("Animal sound")

class Dog(Animal):
    pass

d = Dog()
d.sound()

7. Polymorphism

Polymorphism means the same interface or method name can behave differently for different objects.

class Dog:
    def sound(self):
        print("Bark")

class Cat:
    def sound(self):
        print("Meow")

for animal in [Dog(), Cat()]:
    animal.sound()

8. Encapsulation

Encapsulation means combining data and methods within a class and controlling access to internal details.

9. Modules

A module is a Python file containing functions, classes or variables that can be reused.

import math

print(math.sqrt(25))

10. Packages

A package is a collection of related Python modules organized in a directory.

11. Useful Built-in Modules

  • math
  • random
  • datetime
  • os

12. Importing a Module

import math

print(math.pi)

13. Advantages of OOP

  • Code reusability
  • Easy maintenance
  • Modularity
  • Data organization
  • Supports inheritance and polymorphism
