1. if Statement

age = 18

if age >= 18:
    print("Eligible")

2. if-else

num = 10

if num > 0:
    print("Positive")
else:
    print("Negative")

3. if-elif-else

marks = 75

if marks >= 80:
    print("A")
elif marks >= 60:
    print("B")
else:
    print("C")

4. for Loop

for i in range(1,6):
    print(i)

5. while Loop

i = 1

while i <= 5:
    print(i)
    i += 1

6. break

The break statement terminates a loop.

for i in range(1,10):
    if i == 5:
        break
    print(i)

7. continue

The continue statement skips the current iteration.

for i in range(1,6):
    if i == 3:
        continue
    print(i)

8. pass

The pass statement performs no operation and is used as a placeholder.

if True:
    pass

9. Functions

A function is a reusable block of code.

def greet():
    print("Hello")

greet()

10. Function with Arguments

def add(a,b):
    return a+b

print(add(10,20))

11. Default Arguments

def greet(name="Student"):
    print("Hello",name)

greet()

12. Lambda Function

square = lambda x: x*x
print(square(5))

13. Recursion

Recursion occurs when a function calls itself.

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n-1)

print(factorial(5))

14. Strings

name = "Python"

print(name[0])
print(name[1:4])
print(name.upper())
