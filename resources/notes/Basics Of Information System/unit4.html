1. E-mail

E-mail stands for Electronic Mail. It is a method of sending and receiving electronic messages through a computer network or the Internet.

Example: Sending a message or document from one Gmail account to another.

2. Structure of an Email

An email mainly contains the following parts:

Part Meaning
Email Address Address of the sender or receiver
Email Header Contains information such as To, From and Subject
Body Main message of the email
Attachment File sent along with an email
Example:
To: student@gmail.com
From: teacher@gmail.com
Subject: Assignment
Body: Please submit your assignment.
Attachment: assignment.pdf

3. Email Clients

An email client is software used to send, receive and manage email messages.

Netscape Mail Client

Netscape Mail was an email client used for sending, receiving and managing email messages.

Outlook Express

Outlook Express was an email client used for managing email messages.

Web-Based E-mail

Web-based email allows users to access email through a web browser.

Example: Gmail accessed through a web browser.

4. Email Encryption

Email encryption is the process of converting email information into a protected form so that unauthorized people cannot easily read it.

Purpose: To protect the confidentiality and security of email messages.

5. Address Book

An address book stores contact information such as names and email addresses.

Example: Saving a teacher's email address in the email address book.

6. Signature File

A signature file contains information automatically added at the end of an email message.

Example:
Regards,
Mariyam
BCA Student

7. Email Networks and Servers

Email networks and servers are used to send, receive, store and manage email messages.

An email server stores messages and handles communication between email users.

8. Email Protocols

Protocol Full Form Purpose
SMTP Simple Mail Transfer Protocol Used for sending email
POP3 Post Office Protocol Version 3 Used for receiving email
IMAP4 Internet Message Access Protocol Version 4 Used for accessing and managing email on a server
MIME6 Multipurpose Internet Mail Extensions Supports different types of email content and attachments

9. Telnet

Telnet is a network protocol that allows a user to access and work with a remote computer through a network.

Example: Accessing a remote computer using a terminal-based connection.

10. FTP

FTP stands for File Transfer Protocol. It is used to transfer files between computers over a network.

Example: Uploading website files to a web server.

11. IRC

IRC stands for Internet Relay Chat. It is a protocol used for real-time text communication over the Internet.

12. Search Engine

A search engine is an Internet service used to find information and web pages on the Internet.

Example: Searching for "BCA notes" on a search engine.

13. ISDN

ISDN stands for Integrated Services Digital Network. It is a digital communication technology used for transmitting voice, data and other information over telephone networks.

14. Protocol Options

Shell

Shell access provides a command-line interface through which a user can interact with a remote system.

SLIP

SLIP stands for Serial Line Internet Protocol. It is a protocol used to transmit Internet packets over serial communication lines.

PPP

PPP stands for Point-to-Point Protocol. It is used to establish communication between two network points over a serial connection.

15. Service Options

Service options are the different Internet services provided to users according to their requirements.

  • Email services
  • File transfer services
  • Web services
  • Remote access services
  • Online communication services
