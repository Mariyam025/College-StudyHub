1. System

A system is a set of interconnected components that work together to achieve a common objective.

Example:

A college management system contains students, teachers, courses, fees and examination information. These components work together to manage college activities.

2. System Components

Component Meaning
Input Data or resources entered into the system
Processing Work performed on the input
Output Result produced by the system
Feedback Information used to improve the system

3. Data

Data means raw facts and figures that have not yet been processed.

Examples of Data:

85, 90, 76
Mariyam
BCA
2026

4. Information

Information is processed and organized data that is meaningful and useful for decision-making.

Data → Processing → Information
Example:

Data: 80, 70, 90

After processing:
Average Marks = 80

The average is useful information.

5. Data vs Information

Data Information
Raw facts Processed data
May not have meaning Meaningful and useful
Input Output
Used for processing Used for decision-making

6. Features and Qualities of Information

Good information should have the following qualities:

  • Accuracy: Information should be correct.
  • Relevance: It should be related to the requirement.
  • Timeliness: It should be available when required.
  • Completeness: Important information should not be missing.
  • Reliability: Information should be trustworthy.
  • Clarity: It should be easy to understand.
  • Accessibility: It should be available to authorized users.

7. Types of Information

Type Meaning
Strategic Information Used for long-term planning
Tactical Information Used for middle-level management decisions
Operational Information Used for daily activities
Internal Information Generated inside an organization
External Information Obtained from outside the organization

8. Process of Generating Information

Data Collection → Data Processing → Information → Distribution → Decision Making
Example:

Student marks are collected → marks are processed → result is generated → result is provided to students and teachers.

9. Value of Information

The value of information means the usefulness or benefit obtained from information.

Example:

A sales report can help a company decide which product should be produced more.

10. Cost of Information

Cost of information is the amount spent to collect, process, store and distribute information.

Examples:
  • Computer and hardware cost
  • Software cost
  • Data storage cost
  • Internet/network cost
  • Employee cost

11. Information as a Corporate Resource

Information is an important resource for an organization because it helps management in planning, controlling and decision-making.

Example:

A company uses customer information, sales information and financial information to make business decisions.

12. Information Needs at Different Management Levels

Management Level Information Required
Top Management Strategic and long-term information
Middle Management Tactical information
Lower Management Operational and day-to-day information

13. Factors Influencing Information Needs

  • Level of management
  • Type of organization
  • Nature of business
  • Decision being taken
  • Availability of technology
  • Time available for decision-making
  • Cost of obtaining information
