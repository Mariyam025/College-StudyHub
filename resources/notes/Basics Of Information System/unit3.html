1. Internet

The Internet is a worldwide network of interconnected computers and devices that communicate with each other using standard communication protocols.

Example: Using the Internet to browse websites, send emails, watch videos and access online services.

2. Internet Terminology

Term Meaning
Internet Worldwide network of connected computers
Website A collection of related web pages
Web Page A single page available on the Web
Browser Software used to access websites
URL Address of a resource on the Internet
ISP Internet Service Provider
IP Address Address used to identify a device on a network
Download Receiving data from the Internet
Upload Sending data to the Internet

3. World Wide Web (WWW)

The World Wide Web is a collection of interconnected web pages and resources that can be accessed through the Internet using a web browser.

Example: Opening a website such as a college website using a browser.

4. Intranet

An Intranet is a private network used within an organization to share information and resources among authorized users.

Example: A college's internal portal used by teachers and students.

5. Extranet

An Extranet is a private network that allows authorized external users such as customers, suppliers or partners to access selected organizational information.

Example: A company providing suppliers access to its order system.

6. Internet Applications

The Internet is used for many applications:

  • Email
  • Online education
  • Online banking
  • E-commerce
  • Social networking
  • Video conferencing
  • Entertainment
  • Online booking
  • Cloud services

7. Internet Ethics

Internet ethics refers to the responsible and proper behavior while using the Internet.

  • Respect other users
  • Do not share someone's private information without permission
  • Do not spread false information
  • Respect copyright
  • Do not perform illegal activities
  • Use strong passwords
  • Do not access accounts without permission

8. Connectivity Types

Connectivity refers to the method through which a computer or device connects to a network or the Internet.

Level One Connectivity

Level One connectivity provides basic connection to the Internet for simple communication and information access.

Level Two Connectivity

Level Two connectivity provides broader Internet access and supports more Internet-based services.

Level Three Connectivity

Level Three connectivity provides advanced connectivity for more complex communication and online services.

9. Setting Up an Internet Connection

The following requirements are needed to establish an Internet connection:

Hardware Requirements

  • Computer or mobile device
  • Modem or suitable network device
  • Communication line or network connection

Software Requirements

  • Operating system
  • Web browser
  • Required network software

10. Modem

A modem is a communication device used to establish communication between a computer and a network.

The word modem comes from: Modulator + Demodulator.

Modem Configuration

Modem configuration means setting the modem with the required communication and network settings so that it can connect to the Internet.

11. Internet Service Provider (ISP)

An Internet Service Provider (ISP) is an organization that provides Internet access to users.

Example: A user purchases an Internet connection from an ISP and uses it to access websites and online services.

12. Internet Accounts by ISP

An ISP may provide different options for Internet access.

Telephone Line Options

  • Dial-up connection through telephone system
  • Dedicated connection through telephone system

Protocol Options

Protocol options specify the communication method used for establishing network communication.

Service Options

Service options refer to the Internet services provided by the ISP according to the user's requirements.

13. Dial-up Connection

A dial-up connection uses a telephone system to establish an Internet connection.

Example: A modem connects to the Internet by dialing a telephone number provided for Internet access.

14. Dedicated Connection

A dedicated connection provides a continuous connection through a dedicated communication line.

Example: A business using a dedicated Internet connection for continuous online operations.

Intranet vs Extranet vs Internet

Feature Internet Intranet Extranet
Access Public Authorized organization users Authorized internal and external users
