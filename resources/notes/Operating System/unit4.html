Operating System - Unit 4

Paper: NBCA-203 – Operating System

1. Memory Management

Definition: Memory management is the function of an operating system that manages main memory and allocates it to processes.

2. Logical Address Space

The set of addresses generated by the CPU for a program is called logical address space.

3. Physical Address Space

The actual addresses available in main memory are called physical addresses.

4. Logical vs Physical Address

Logical AddressPhysical Address
Generated by CPUActual location in memory
Used by programUsed by memory hardware

5. Swapping

Swapping is a memory-management technique in which a process is temporarily moved from main memory to secondary storage and later brought back.

Main Memory ↔ Secondary Storage

6. Contiguous Allocation

In contiguous allocation, each process occupies a continuous block of memory.

Types

  • Fixed Partitioning
  • Variable Partitioning

7. Paging

Paging divides logical memory into fixed-size pages and physical memory into fixed-size frames.

Page → Frame

Paging helps avoid external fragmentation.

8. Virtual Memory

Definition: Virtual memory allows a program to execute even when the complete program is not present in main memory.

9. Demand Paging

In demand paging, a page is loaded into memory only when it is required.

10. Page Replacement

When memory is full and a required page is not present, the OS replaces an existing page.

Page Replacement Algorithms

  • FIFO – First In First Out
  • Optimal Page Replacement
  • LRU – Least Recently Used

11. Allocation of Frames

Frame allocation determines how many memory frames are assigned to each process.

  • Equal Allocation
  • Proportional Allocation

12. Thrashing

Definition: Thrashing occurs when the system spends excessive time swapping pages rather than executing processes.

Effect: CPU utilization and system performance decrease.

Quick Revision

Logical address is generated by CPU.
Physical address refers to actual memory location.
Paging uses pages and frames.
Virtual memory allows execution of programs larger than physical memory.
FIFO, Optimal and LRU are page replacement algorithms.
Thrashing reduces system performance.
