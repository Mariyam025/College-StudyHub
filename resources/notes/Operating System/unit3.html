Operating System - Unit 3

Paper: NBCA-203 – Operating System

1. Process Synchronization

Definition: Process synchronization is the coordination of processes so that shared data remains correct and consistent.

2. Critical Section Problem

A critical section is the part of a program where shared data or resources are accessed.

A solution should satisfy:

  • Mutual Exclusion
  • Progress
  • Bounded Waiting

3. Synchronization Hardware

Hardware instructions can help processes safely access shared resources.

Examples: Test-and-Set and Compare-and-Swap.

4. Semaphores

Definition: A semaphore is a synchronization variable used to control access to shared resources.

Types

  • Binary Semaphore
  • Counting Semaphore

Basic Operations

  • wait(): Decreases semaphore value.
  • signal(): Increases semaphore value.

5. Classical Problems of Synchronization

  • Producer-Consumer Problem
  • Readers-Writers Problem
  • Dining Philosophers Problem

6. Critical Regions

A critical region is a synchronization construct that controls access to shared data.

7. Deadlock

Definition: Deadlock is a situation where a group of processes waits indefinitely because each process is waiting for a resource held by another process.

8. Deadlock System Model

A process may request, use and release resources.

Request → Use → Release

9. Characterization of Deadlock

Four necessary conditions are:

  • Mutual Exclusion
  • Hold and Wait
  • No Preemption
  • Circular Wait

10. Deadlock Prevention

Deadlock prevention ensures that at least one necessary condition for deadlock cannot occur.

11. Deadlock Avoidance

Deadlock avoidance checks resource allocation before granting a request.

Example: Banker's Algorithm.

12. Deadlock Detection

The system checks whether deadlock has occurred by analyzing processes and resources.

13. Recovery from Deadlock

  • Terminate one or more processes.
  • Preempt resources.
  • Rollback processes when appropriate.

Quick Revision

Critical section accesses shared resources.
Semaphore is used for synchronization.
Deadlock means processes wait indefinitely.
Four deadlock conditions: Mutual Exclusion, Hold and Wait, No Preemption, Circular Wait.
Banker's Algorithm is used for deadlock avoidance.
