Operating System - Unit 5

Paper: NBCA-203 – Operating System

1. File System

Definition: A file system is a method used by an operating system to organize, store and manage files on storage devices.

2. File Concept

A file is a named collection of related information stored on secondary storage.

File Attributes

  • Name
  • Type
  • Size
  • Location
  • Protection
  • Date and time

3. Secondary Storage Structure

Secondary storage provides permanent storage for programs and data.

Examples: Hard disk, SSD, optical disk.

4. File Access Methods

Sequential Access

Data is accessed in a sequential order.

Direct Access

Any required location can be accessed directly.

5. Directory Implementation

A directory stores information about files and helps users organize and locate them.

Common Directory Structures

  • Single-Level Directory
  • Two-Level Directory
  • Tree-Structured Directory

6. Disk Structure

A magnetic disk contains platters, tracks and sectors.

Disk → Tracks → Sectors

7. Disk Scheduling

Disk scheduling determines the order in which disk I/O requests are serviced.

Disk Scheduling Algorithms

  • FCFS: Requests are served in arrival order.
  • SSTF: Request closest to current head position is served first.
  • SCAN: Disk arm moves in one direction and then reverses.
  • C-SCAN: Services requests in one direction and returns to beginning.

8. Disk Management

  • Disk formatting
  • Boot block management
  • Bad-block management
  • Free-space management

9. Disk Recovery

Disk recovery involves restoring data and disk operation after failures.

  • Backup
  • Error detection
  • Data recovery
  • Recovery from damaged blocks

Quick Revision

File is a named collection of information.
File systems manage files and directories.
Sequential access reads data in order.
Direct access can access a particular location.
FCFS, SSTF, SCAN and C-SCAN are disk scheduling algorithms.
Disk management handles formatting, free space and bad blocks.
