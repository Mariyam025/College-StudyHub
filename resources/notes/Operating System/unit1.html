Operating System - Unit 1

Paper: NBCA-203 – Operating System

1. Operating System

Definition: An Operating System (OS) is system software that manages computer hardware and provides services to application programs and users.

Examples: Windows, Linux, macOS, Android.

2. Functions of Operating System

  • Process management
  • Memory management
  • File management
  • Device management
  • Security and protection
  • User interface
  • Resource allocation

4. Batch Operating System

Similar jobs are grouped together and processed without direct interaction during execution.

Example: Payroll processing.

5. Interactive Operating System

Allows users to interact directly with the computer and receive responses.

Example: Using a Windows application.

6. Time Sharing System

CPU time is divided into small time slices and given to different users or processes.

Example: Multiple users working on a Unix system.

7. Real-Time System

A real-time OS processes tasks within a specified time limit.

Example: Airbag control system.

8. Multiprocessor System

A system having two or more processors that can execute tasks simultaneously.

9. Multiuser System

An operating system that allows multiple users to access system resources.

10. Multithreaded System

A system where a process can contain multiple threads executing different tasks.

11. Operating System Structure

OS structure defines how different components of the operating system are organized.

Layered Structure

The operating system is divided into different layers. Each layer performs specific functions and uses services of the layer below it.

Hardware → Kernel → System Services → Application Programs → User
