Operating System - Unit 2

Paper: NBCA-203 – Operating System

1. Process Concept

Definition: A process is a program that is currently in execution.

Example: When a music application is running, it becomes a process.

Process States

  • New
  • Ready
  • Running
  • Waiting/Blocked
  • Terminated
New → Ready → Running → Terminated
Running → Waiting → Ready

2. Process Scheduling

Process scheduling is the method used by the operating system to select a process for CPU execution.

3. CPU Scheduling

CPU scheduling decides which ready process gets the CPU next.

4. CPU Scheduling Criteria

  • CPU Utilization: Keep CPU busy.
  • Throughput: Number of completed processes.
  • Turnaround Time: Completion time - Arrival time.
  • Waiting Time: Time spent waiting in ready queue.
  • Response Time: Time until first response.

5. Scheduling Algorithms

FCFS

First Come First Serve executes processes in the order they arrive.

Example: P1, P2, P3 → P1 executes first.

SJF

Shortest Job First selects the process with the smallest CPU burst time.

Priority Scheduling

The process with the highest priority is selected first.

Round Robin

Each process gets a fixed time called a time quantum.

Example: Time quantum = 2 ms → P1 → P2 → P3 → P1 ...

6. Cooperating Processes

Cooperating processes can affect or share data with other processes.

Example: Producer and Consumer processes.

7. Threads

Definition: A thread is the smallest unit of CPU execution within a process.

Advantages

  • Better responsiveness
  • Resource sharing
  • Lower overhead
  • Improved parallelism

8. Inter-Process Communication (IPC)

IPC allows processes to communicate and exchange data.

Methods of IPC

  • Shared Memory
  • Message Passing

Quick Revision

Process = program in execution.
FCFS = First Come First Serve.
SJF = Shortest Job First.
Round Robin uses time quantum.
Thread = smallest execution unit.
IPC allows processes to communicate.
