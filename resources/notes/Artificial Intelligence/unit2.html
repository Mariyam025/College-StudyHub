Artificial Intelligence - Unit 2

1. Problem Solving in AI

Problem solving in AI involves finding a sequence of actions that transforms an initial state into a desired goal state.

Example: Finding a route from one city to another can be treated as an AI search problem.

2. State

A state represents a particular situation or configuration of a problem.

3. Initial State

The initial state is the starting point of a problem.

4. Goal State

The goal state represents the desired final condition.

5. Operators / Actions

Operators are actions that can change one state into another.

6. State Space

A state space is the collection of possible states that can be reached while solving a problem.

7. Search

Search is the process of exploring possible states and actions to find a solution to a problem.

8. Components of an AI Search Problem

  • Initial state
  • Actions/operators
  • Transition model
  • Goal test
  • Path cost

9. Search Strategies

Search strategies determine the order in which possible states are explored.

Major categories include:

  • Uninformed search
  • Informed search

10. Uninformed Search

Uninformed search methods do not use problem-specific heuristic information to estimate which state is closer to the goal.

Important methods include:

  • Breadth First Search
  • Depth First Search
  • Uniform Cost Search
  • Depth Limited Search
  • Iterative Deepening Search

11. Breadth First Search

Breadth First Search (BFS) explores nodes level by level. It generally uses a queue data structure.

Working of BFS

  1. Start from the initial node.
  2. Visit the node.
  3. Add its unvisited successors to the queue.
  4. Remove the next node from the queue.
  5. Continue until the goal is found or the queue becomes empty.

Advantages of BFS

  • Complete under standard finite-branching assumptions.
  • Finds a shallowest solution.
  • Useful when solution depth is small.

Disadvantages of BFS

  • Can require a large amount of memory.
  • Can be slow when the solution is deep.

12. Depth First Search

Depth First Search (DFS) explores one branch as deeply as possible before backtracking.

Working of DFS

  1. Start from the initial node.
  2. Move to an unvisited child.
  3. Continue deeper.
  4. Backtrack when no unvisited child remains.

Advantages of DFS

  • Requires less memory than BFS in many cases.
  • Useful for deep search spaces.
  • Simple to implement.

Disadvantages of DFS

  • May follow an unproductive deep path.
  • May not find the shallowest solution.
  • Basic DFS can get stuck in infinite-depth spaces without safeguards.

13. BFS vs DFS

Feature BFS DFS
Strategy Level by level Depth first
Data Structure Queue Stack / recursion
Memory Usually higher Usually lower
Shallowest solution Finds it under standard conditions Not guaranteed

14. Uniform Cost Search

Uniform Cost Search expands the node with the lowest path cost.

It is useful when different actions have different costs.

15. Depth Limited Search

Depth Limited Search is DFS with a specified depth limit.

It prevents the search from going beyond the chosen depth.

16. Iterative Deepening Search

Iterative Deepening Search repeatedly performs depth-limited searches with increasing depth limits.

For example:

  • Depth 0
  • Depth 1
  • Depth 2
  • Depth 3
  • Continue until the goal is found

17. Informed Search

Informed search uses additional problem-specific information called a heuristic to guide the search.

18. Heuristic Function

A heuristic function, commonly represented as h(n), estimates the cost or distance from a node to the goal.

Example: In route finding, straight-line distance can be used as a heuristic for estimating distance to a destination.

19. Best First Search

Best First Search selects the most promising node according to an evaluation function.

20. Greedy Best First Search

Greedy Best First Search selects a node using the heuristic value:

f(n) = h(n)

It focuses on estimated distance to the goal and does not directly include the path cost already travelled.

21. A* Search

A* Search combines the cost already travelled with the estimated cost to the goal.

f(n) = g(n) + h(n)
  • g(n): Cost from the initial state to node n.
  • h(n): Estimated cost from node n to the goal.
  • f(n): Estimated total solution cost through node n.

22. Advantages of A*

  • Uses both actual and estimated costs.
  • Can efficiently find good paths with a suitable heuristic.
  • With an appropriate admissible heuristic and standard conditions, A* can find an optimal solution.

23. Greedy Best First vs A*

Feature Greedy Best First A*
Evaluation f(n) = h(n) f(n) = g(n) + h(n)
Uses path cost No Yes
Uses heuristic Yes Yes

24. Game Playing in AI

Game-playing programs use search and evaluation techniques to select actions in competitive environments.

Examples include chess, tic-tac-toe and other board games.

25. Game Tree

A game tree represents possible moves and resulting game states from the current position.

26. Minimax Algorithm

Minimax is a decision-making algorithm commonly used for two-player, zero-sum games.

It assumes that one player tries to maximize the score while the opponent tries to minimize it.

Basic Steps

  1. Generate possible moves.
  2. Build the game tree to a suitable depth.
  3. Evaluate terminal or cutoff positions.
  4. Choose maximum values for MAX nodes.
  5. Choose minimum values for MIN nodes.

27. Alpha-Beta Pruning

Alpha-beta pruning improves minimax search by eliminating branches that cannot affect the final decision.

Alpha

Alpha represents the best value that MAX can guarantee so far.

Beta

Beta represents the best value that MIN can guarantee so far.

Important: Alpha-beta pruning does not change the minimax result; it reduces the amount of unnecessary search.

28. Knowledge in AI

Knowledge is information about objects, facts, relationships, rules and situations that an AI system can use for reasoning.

29. Knowledge Representation

Knowledge representation is the process of representing knowledge in a form that an AI system can use to reason and solve problems.

30. Types of Knowledge

  • Factual knowledge: Facts about objects or situations.
  • Procedural knowledge: Knowledge of how to perform tasks.
  • Heuristic knowledge: Experience-based rules or strategies.
  • Meta-knowledge: Knowledge about knowledge.

31. Knowledge Representation Techniques

  • Logical representation
  • Semantic networks
  • Frames
  • Production rules

32. Semantic Network

A semantic network represents knowledge using nodes and links. Nodes represent concepts or objects, while links represent relationships.

Example:
Dog → is-a → Animal
Dog → has → Tail

33. Production Rules

Production rules represent knowledge using IF-THEN statements.

Example:
IF temperature is high
THEN turn on cooling system.

34. Expert System

An expert system is an AI system designed to provide solutions or advice in a specific domain using a knowledge base and an inference mechanism.

35. Components of Expert System

  • Knowledge base
  • Inference engine
  • User interface
  • Explanation facility
  • Knowledge acquisition component

36. Knowledge Base

The knowledge base stores facts, rules and domain-specific knowledge.

37. Inference Engine

The inference engine applies rules to known facts to derive conclusions.
