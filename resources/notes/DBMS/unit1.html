Database Management System

Unit 1 - Introduction

1. Database Management System

Definition: A Database Management System (DBMS) is software used to create, store, manage and retrieve data from a database.

Advantages of Database System

  • Reduces data redundancy
  • Improves data security
  • Provides data sharing
  • Maintains data consistency
  • Provides backup and recovery

2. Database System vs File System

File SystemDatabase System
Data redundancy can be highRedundancy can be controlled
Less securityBetter security
Data sharing is limitedEasy data sharing
Backup may be manualBackup and recovery supported

3. Database System Concept and Architecture

A database system consists of the database, DBMS software, users and applications that work together to manage data.

Three-Level Architecture

  • External Level: User view of data.
  • Conceptual Level: Overall logical structure of database.
  • Internal Level: Physical storage of data.

4. Data Model

A data model defines how data is organized, related and represented in a database.

Examples: Relational model, ER model.

5. Schema and Instance

Schema: Overall design or structure of a database.

Instance: Actual data stored in the database at a particular time.

6. Data Independence

Data independence means changing one level of database structure without requiring changes at the higher level.

  • Physical Data Independence
  • Logical Data Independence

7. Database Languages

  • DDL: Defines database structure.
  • DML: Manipulates data.
  • DCL: Controls access.
  • TCL: Manages transactions.

8. Database Interfaces

Users can interact with a DBMS using command-line interfaces, graphical interfaces, forms and application programs.

9. Overall Database Structure

The overall structure contains users/applications, DBMS, database, storage system and related components.

Quick Revision:
  • DBMS manages databases.
  • Schema = database structure.
  • Instance = actual data.
  • External, conceptual and internal levels form database architecture.
  • DDL, DML, DCL and TCL are database languages.
