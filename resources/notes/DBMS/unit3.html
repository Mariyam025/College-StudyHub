Database Management System

Unit 3 - Relational Model and SQL

1. Relational Data Model

The relational model represents data using tables consisting of rows and columns.
  • Relation: Table
  • Tuple: Row
  • Attribute: Column
  • Domain: Set of allowed values

2. Integrity Constraints

  • Entity Integrity: Primary key cannot contain NULL values.
  • Referential Integrity: Foreign key should refer to a valid record.
  • Key Constraint: Keys identify records uniquely.
  • Domain Constraint: Values must belong to the specified domain.

3. Relational Algebra

Relational algebra is a procedural query language used to perform operations on relations.

Common operations: Selection, Projection, Union, Intersection, Difference and Join.

4. Relational Calculus

Relational calculus is a non-procedural query language that describes what data is required rather than how to obtain it.

Tuple Calculus

Uses tuple variables to describe required records.

Domain Calculus

Uses domain variables to describe required attribute values.

5. SQL

Definition: SQL (Structured Query Language) is used to create, manage and retrieve data from relational databases.

Types of SQL Commands

TypePurposeExample
DDLStructureCREATE, ALTER, DROP
DMLData manipulationINSERT, UPDATE, DELETE
DCLAccess controlGRANT, REVOKE
TCLTransactionsCOMMIT, ROLLBACK

6. SQL Examples

CREATE TABLE Student(
    id INT PRIMARY KEY,
    name VARCHAR(50),
    marks INT
);

INSERT INTO Student VALUES(1,'Rahul',85);

SELECT * FROM Student;

UPDATE Student
SET marks=90
WHERE id=1;

DELETE FROM Student
WHERE id=1;

7. SQL Data Types and Literals

  • INT
  • VARCHAR
  • CHAR
  • DATE
  • DECIMAL

8. SQL Operators

Arithmetic, comparison, logical and other operators can be used in SQL queries.

9. Tables, Views and Indexes

Table: Stores actual data.

View: Virtual table based on a query.

Index: Helps improve data retrieval performance.

10. Queries and Subqueries

SELECT name
FROM Student
WHERE marks > 80;

SELECT name
FROM Student
WHERE marks >
(SELECT AVG(marks) FROM Student);

11. Aggregate Functions

  • COUNT()
  • SUM()
  • AVG()
  • MAX()
  • MIN()

12. Joins

Joins combine data from two or more tables based on related columns.

Types: INNER JOIN, LEFT JOIN, RIGHT JOIN.

13. Union, Intersection and Minus

These operations are used to combine or compare results of compatible queries.

14. Cursors

A cursor allows processing of query results row by row.

15. Triggers

A trigger is automatically executed when a specified database event occurs.

Quick Revision:
  • Relation = table.
  • Tuple = row.
  • Attribute = column.
  • DDL manages structure.
  • DML manages data.
  • TCL manages transactions.
  • DCL controls access.
  • SQL is used to interact with relational databases.
