Design and Analysis of Algorithm - Unit 1

1. Introduction to Algorithm

An algorithm is a finite sequence of well-defined steps used to solve a problem.

Characteristics of an Algorithm

  • Input
  • Output
  • Definiteness
  • Finiteness
  • Effectiveness

2. Algorithm Design

Algorithm design is the process of developing a step-by-step solution for a particular problem.

Basic steps:

  1. Understand the problem
  2. Identify input and output
  3. Design the algorithm
  4. Analyze the algorithm
  5. Implement the solution
  6. Test the solution

3. Pseudocode

Pseudocode is an informal way of writing the steps of an algorithm using simple English-like statements. 

START
Input A and B
SUM = A + B
Display SUM
STOP

4. Time Complexity

Time complexity describes how the running time of an algorithm changes as the input size increases.

Common complexities:

  • O(1) - Constant
  • O(log n) - Logarithmic
  • O(n) - Linear
  • O(n log n) - Linearithmic
  • O(n²) - Quadratic
  • O(2ⁿ) - Exponential

5. Space Complexity

Space complexity represents the amount of memory required by an algorithm.

It includes memory required for variables, data structures and additional temporary storage.

6. Asymptotic Notations

Asymptotic notation is used to describe the growth rate of an algorithm.

Big O - O()

Represents an upper bound of growth.

Omega - Ω()

Represents a lower bound of growth.

Theta - Θ()

Represents a tight bound.

7. Best, Average and Worst Case

  • Best Case: Minimum time required.
  • Average Case: Expected time for normal input.
  • Worst Case: Maximum time required.

9. Binary Search

Binary search works on a sorted array. It repeatedly divides the search area into two halves.

Time Complexity: O(log n)

low = 0
high = n - 1

while low <= high:
    mid = (low + high) / 2

    if array[mid] == key:
        return mid

    else if key < array[mid]:
        high = mid - 1

    else:
        low = mid + 1
