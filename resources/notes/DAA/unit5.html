Design and Analysis of Algorithm - Unit 5

1. Graph Algorithms

A graph consists of vertices and edges. Graph algorithms are used to solve problems involving connections between objects.

Applications include:

  • Computer networks
  • Maps and navigation
  • Social networks
  • Routing

2. Graph Coloring

Graph coloring assigns colors to vertices so that adjacent vertices do not have the same color.

The minimum number of colors required is called the chromatic number of the graph.

3. Hamiltonian Cycle

A Hamiltonian cycle is a cycle in a graph that visits every vertex exactly once and returns to the starting vertex.

Backtracking can be used to solve the Hamiltonian cycle problem.

4. Travelling Salesman Problem

The Travelling Salesman Problem (TSP) asks for a minimum-cost tour that visits every city exactly once and returns to the starting city.

TSP is a well-known computationally difficult optimization problem.

5. Branch and Bound

Branch and Bound divides a problem into smaller subproblems and uses bounds to eliminate subproblems that cannot produce a better solution.

It can be applied to problems such as:

  • Travelling Salesman Problem
  • 0/1 Knapsack
  • Scheduling problems

6. String Matching

String matching is the process of finding a pattern inside a text.

Important algorithms:

  • Naive String Matching
  • Rabin-Karp
  • KMP Algorithm

7. Naive String Matching

The naive method compares the pattern with every possible position in the text.

It is simple but can require many comparisons. 

Text:    ABCABC
Pattern: ABC

Compare pattern
at each possible position.

8. Rabin-Karp Algorithm

Rabin-Karp uses hashing to compare the pattern with sections of text.

Instead of directly comparing every character first, hash values can be compared.

9. KMP Algorithm

KMP stands for Knuth-Morris-Pratt. It improves pattern searching by avoiding unnecessary comparisons.

It uses a preprocessing table commonly called the LPS (Longest Proper Prefix which is also Suffix) array.

10. NP, NP-Hard and NP-Complete

P

Problems that can be solved in polynomial time by a deterministic algorithm.

NP

Problems whose solutions can be verified in polynomial time.

NP-Hard

Problems at least as difficult as the problems in NP, under the standard polynomial-time reduction framework.

NP-Complete

Problems that are both in NP and NP-Hard.

11. Approximation Algorithms

Approximation algorithms are designed to find solutions that are close to optimal for difficult optimization problems.

12. Importance of Algorithm Analysis

  • Helps compare algorithms.
  • Helps estimate resource requirements.
  • Helps select suitable solutions.
  • Helps improve program efficiency.
