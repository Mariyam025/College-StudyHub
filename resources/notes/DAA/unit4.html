Design and Analysis of Algorithm - Unit 4

1. Sorting

Sorting means arranging data in a particular order, usually ascending or descending.

Common sorting algorithms:

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort
  • Heap Sort
  • Counting Sort
  • Radix Sort

2. Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

Time Complexity: O(n²)

for i = 0 to n-1:

    for j = 0 to n-i-2:

        if A[j] > A[j+1]:
            swap A[j] and A[j+1]

3. Selection Sort

Selection Sort repeatedly selects the smallest element from the unsorted portion and places it at the correct position.

Time Complexity: O(n²)

4. Insertion Sort

Insertion Sort builds the sorted array one element at a time.

Time Complexity: O(n²) in the average/worst case.

It performs well for small or nearly sorted datasets.

5. Heap Sort

Heap Sort uses a heap data structure to sort elements.

Time Complexity: O(n log n)

It is based on the binary heap concept.

6. Counting Sort

Counting Sort counts occurrences of elements and uses these counts to produce the sorted output.

It is useful when the range of integer values is relatively small.

7. Radix Sort

Radix Sort sorts numbers digit by digit. It commonly processes digits from the least significant digit to the most significant digit.

8. Searching

Searching means finding a required element from a collection of data.

  • Linear Search
  • Binary Search

9. Comparison of Sorting Algorithms

Algorithm Average Time
Bubble Sort O(n²)
Selection Sort O(n²)
Insertion Sort O(n²)
Merge Sort O(n log n)
Quick Sort O(n log n)
Heap Sort O(n log n)

10. Order Statistics

Order statistics are values arranged according to their position in sorted order.

Examples:

  • Minimum
  • Maximum
  • Median
  • k-th smallest element
  • k-th largest element
