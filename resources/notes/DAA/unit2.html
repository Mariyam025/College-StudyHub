Design and Analysis of Algorithm - Unit 2

1. Divide and Conquer

Divide and Conquer is an algorithm design technique in which a problem is divided into smaller subproblems.

Three Steps

  1. Divide
  2. Conquer
  3. Combine

Examples:

  • Merge Sort
  • Quick Sort
  • Binary Search

2. Merge Sort

Merge Sort divides an array into smaller parts, sorts them and then merges the sorted parts.

Time Complexity: O(n log n)

MergeSort(array)

if array has more than one element:

    divide array into two halves

    MergeSort(left half)
    MergeSort(right half)

    merge both sorted halves

3. Quick Sort

Quick Sort selects an element called a pivot and divides the array around the pivot.

Average Time Complexity: O(n log n)

Worst Time Complexity: O(n²)

QuickSort(array)

select pivot

place smaller elements
before pivot

place larger elements
after pivot

repeat for both parts

4. Binary Search

Binary Search repeatedly divides a sorted array into two parts.

Time Complexity: O(log n)

Search middle element

if key == middle:
    found

if key < middle:
    search left half

else:
    search right half

5. Greedy Approach

A Greedy algorithm makes the best available choice at each step with the aim of obtaining an overall solution.

Examples:

  • Activity Selection
  • Huffman Coding
  • Fractional Knapsack
  • Minimum Spanning Tree algorithms

6. Fractional Knapsack

In Fractional Knapsack, an item can be divided into fractions. Items are generally selected according to their value-to-weight ratio.

Approach:

  1. Calculate value/weight ratio.
  2. Sort items by ratio.
  3. Select highest ratio items first.
  4. Take a fraction if necessary.

7. Activity Selection Problem

The activity selection problem selects the maximum number of non-overlapping activities.

A common greedy strategy is to select the activity that finishes earliest.

8. Huffman Coding

Huffman Coding is a greedy algorithm used for lossless data compression.

Basic process:

  1. Find two nodes with lowest frequency.
  2. Combine them.
  3. Repeat until one tree remains.
  4. Assign binary codes to the characters.

9. Minimum Spanning Tree

A Minimum Spanning Tree connects all vertices of a weighted graph with minimum total edge weight and without cycles.

Important algorithms:

  • Kruskal's Algorithm
  • Prim's Algorithm

10. Kruskal's Algorithm

Kruskal's algorithm sorts edges according to their weights and adds the smallest edge that does not create a cycle.
