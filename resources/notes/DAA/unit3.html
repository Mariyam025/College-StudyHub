Design and Analysis of Algorithm - Unit 3

1. Dynamic Programming

Dynamic Programming is an algorithm design technique used to solve problems by breaking them into overlapping subproblems.

The results of solved subproblems are stored so that they do not need to be calculated again.

2. Properties of Dynamic Programming

  • Overlapping subproblems
  • Optimal substructure
  • Storage of previously calculated results

3. Fibonacci Using Dynamic Programming

fib[0] = 0
fib[1] = 1

for i = 2 to n:
    fib[i] = fib[i-1] + fib[i-2]

This avoids repeatedly calculating the same Fibonacci values.

4. Matrix Chain Multiplication

Matrix Chain Multiplication finds the most efficient order in which a sequence of matrices should be multiplied.

The goal is to minimize the number of scalar multiplications.

5. Longest Common Subsequence

Longest Common Subsequence (LCS) finds the longest sequence that appears in two sequences in the same order, but not necessarily continuously.

Example:

String 1: ABCD
String 2: ACBD

One LCS: ABD

6. 0/1 Knapsack Problem

In the 0/1 Knapsack problem, each item can either be selected completely or not selected.

Unlike Fractional Knapsack, fractions of items are not allowed.

7. Shortest Path

Shortest path algorithms find the minimum-cost path between vertices in a graph.

Examples:

  • Dijkstra's Algorithm
  • Floyd-Warshall Algorithm

8. Dijkstra's Algorithm

Dijkstra's algorithm finds shortest paths from one source vertex to other vertices in a weighted graph with non-negative edge weights.

Basic Steps

  1. Choose the source vertex.
  2. Set source distance to zero.
  3. Select the unvisited vertex with smallest distance.
  4. Update distances of neighboring vertices.
  5. Repeat until required vertices are processed.

9. Backtracking

Backtracking builds a solution step by step and goes back when the current choice cannot lead to a valid solution.

Examples:

  • N-Queens Problem
  • Graph Coloring
  • Hamiltonian Cycle
  • Subset Sum

10. N-Queens Problem

The N-Queens problem places N queens on an N × N chessboard so that no two queens attack each other.

Backtracking is commonly used to solve this problem.
