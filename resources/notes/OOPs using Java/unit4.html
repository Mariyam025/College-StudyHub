1. Interface

An interface in Java is a blueprint that defines a contract for classes that implement it.

Interfaces are commonly used to achieve abstraction and multiple inheritance of type in Java. 

interface Animal {

    void sound();
}

class Dog implements Animal {

    public void sound() {

        System.out.println("Dog barks");
    }
}

2. implements Keyword

The implements keyword is used by a class to implement an interface. 

interface Vehicle {

    void start();
}

class Car implements Vehicle {

    public void start() {

        System.out.println("Car starts");
    }
}

3. Multiple Inheritance using Interfaces

Java does not support multiple inheritance through classes, but a class can implement multiple interfaces. 

interface A {

    void showA();
}

interface B {

    void showB();
}

class Demo implements A, B {

    public void showA() {

        System.out.println("A");
    }

    public void showB() {

        System.out.println("B");
    }
}

4. Default and Static Methods in Interface

Modern Java interfaces can contain default and static methods with implementations. 

interface Test {

    default void display() {

        System.out.println("Default method");
    }

    static void show() {

        System.out.println("Static method");
    }
}

5. Exception

An exception is an abnormal condition that occurs during program execution and can disrupt the normal flow of the program.

Examples:

  • ArithmeticException
  • NullPointerException
  • ArrayIndexOutOfBoundsException
  • NumberFormatException
  • IOException

6. Exception Handling

Exception handling is used to handle runtime problems so that the program can respond properly instead of terminating unexpectedly.

Java provides:

  • try
  • catch
  • finally
  • throw
  • throws

7. try-catch Block

The try block contains code that may cause an exception. The catch block handles the exception. 

class Demo {

    public static void main(String[] args) {

        try {

            int result = 10 / 0;

            System.out.println(result);

        } catch (ArithmeticException e) {

            System.out.println("Cannot divide by zero");
        }
    }
}

Output:

Cannot divide by zero

8. Multiple Catch Blocks

Multiple catch blocks can be used to handle different types of exceptions. 

try {

    int a = 10 / 0;

}
catch (ArithmeticException e) {

    System.out.println("Arithmetic Error");

}
catch (Exception e) {

    System.out.println("Other Error");
}

9. finally Block

The finally block is used for code that should normally execute after try/catch processing. 

try {

    int a = 10 / 2;

    System.out.println(a);

}
catch (Exception e) {

    System.out.println("Error");

}
finally {

    System.out.println("Program completed");
}

Output:

5
Program completed

10. throw Keyword

The throw keyword is used to explicitly throw an exception. 

class Demo {

    public static void main(String[] args) {

        int age = 15;

        if (age < 18) {

            throw new ArithmeticException("Not eligible");
        }
    }
}

11. throws Keyword

The throws keyword is used in a method declaration to indicate exceptions that may be propagated to the caller. 

import java.io.*;

class Demo {

    static void readFile() throws IOException {

        FileInputStream f =
            new FileInputStream("data.txt");
    }
}

12. Checked and Unchecked Exceptions

Checked Exception Unchecked Exception
Checked by compiler Occurs during runtime
Usually subclasses of Exception other than RuntimeException Usually subclasses of RuntimeException
Example: IOException Example: ArithmeticException

13. User-Defined Exception

A programmer can create a custom exception class by extending an appropriate exception class. 

class MyException extends Exception {

    MyException(String message) {

        super(message);
    }
}

class Demo {

    public static void main(String[] args) {

        try {

            throw new MyException("Custom Exception");

        }
        catch (MyException e) {

            System.out.println(e.getMessage());
        }
    }
}

14. Multithreading

Multithreading is the process of executing multiple threads concurrently within a program.

A thread is a lightweight unit of execution.

Multithreading can improve responsiveness and allow independent tasks to execute concurrently.

15. Creating a Thread by Extending Thread

class MyThread extends Thread {

    public void run() {

        System.out.println("Thread is running");
    }

    public static void main(String[] args) {

        MyThread t = new MyThread();

        t.start();
    }
}

16. Creating Thread using Runnable

Another common way to create a thread is by implementing the Runnable interface. 

class MyTask implements Runnable {

    public void run() {

        System.out.println("Task is running");
    }

    public static void main(String[] args) {

        MyTask task = new MyTask();

        Thread t = new Thread(task);

        t.start();
    }
}

17. Thread Life Cycle

A thread passes through different states during its lifetime.

  • New
  • Runnable
  • Running
  • Blocked / Waiting
  • Terminated

18. Important Thread Methods

Method Purpose
start() Starts a new thread
run() Contains the task performed by the thread
sleep() Pauses the current thread for a specified time
join() Waits for another thread to finish
isAlive() Checks whether a thread is alive

19. Synchronization

Synchronization is used to control access to shared resources when multiple threads are executing concurrently.

It helps prevent inconsistent results caused by simultaneous access to shared data. 

class Counter {

    synchronized void increment() {

        System.out.println("Counter updated");
    }
}
