1. Java I/O

I/O stands for Input/Output. Java provides classes and interfaces to read data from different sources and write data to different destinations.

Java I/O classes are mainly available in the java.io package.

2. Stream

A stream represents a flow of data between a source and a destination.

Two major types:

  • Byte Stream
  • Character Stream

3. Byte Stream

Byte streams are used to handle data in the form of bytes.

Common classes include:

  • FileInputStream
  • FileOutputStream
import java.io.FileInputStream;

class ReadFile {

    public static void main(String[] args) throws Exception {

        FileInputStream fis =
            new FileInputStream("data.txt");

        int data;

        while ((data = fis.read()) != -1) {

            System.out.print((char)data);
        }

        fis.close();
    }
}

4. Character Stream

Character streams are used for character-based data.

Common classes include:

  • FileReader
  • FileWriter
import java.io.FileReader;

class ReadFile {

    public static void main(String[] args) throws Exception {

        FileReader fr =
            new FileReader("data.txt");

        int data;

        while ((data = fr.read()) != -1) {

            System.out.print((char)data);
        }

        fr.close();
    }
}

5. Writing Data to a File

FileWriter can be used to write character data into a file. 

import java.io.FileWriter;

class WriteFile {

    public static void main(String[] args) throws Exception {

        FileWriter fw =
            new FileWriter("data.txt");

        fw.write("Welcome to College StudyHub");

        fw.close();

        System.out.println("Data written successfully");
    }
}

6. BufferedReader

BufferedReader is used to efficiently read character data, including complete lines of text. 

import java.io.*;

class InputDemo {

    public static void main(String[] args) throws Exception {

        BufferedReader br =
            new BufferedReader(
                new InputStreamReader(System.in)
            );

        System.out.print("Enter your name: ");

        String name = br.readLine();

        System.out.println("Hello " + name);
    }
}

7. Serialization

Serialization is the process of converting an object's state into a byte stream so that it can be stored or transmitted.

A class generally implements the Serializable interface to support serialization. 

import java.io.Serializable;

class Student implements Serializable {

    String name;
    int age;
}

8. Collection Framework

The Java Collection Framework provides interfaces and classes for storing and manipulating groups of objects.

Important interfaces:

  • List
  • Set
  • Queue
  • Map

9. ArrayList

ArrayList is a resizable array implementation of the List interface. 

import java.util.ArrayList;

class Demo {

    public static void main(String[] args) {

        ArrayList names =
            new ArrayList<>();

        names.add("Rahul");
        names.add("Priya");
        names.add("Aman");

        System.out.println(names);
    }
}

Output:

[Rahul, Priya, Aman]

10. LinkedList

LinkedList is a list implementation based on linked nodes. 

import java.util.LinkedList;

        list.add("Java");

        list.add("HTML");

11. HashSet

HashSet is a Set implementation that does not allow duplicate elements. 

import java.util.HashSet;

class Demo {

    public static void main(String[] args) {

        HashSet numbers =
            new HashSet<>();

        numbers.add(10);
        numbers.add(20);
        numbers.add(10);

        System.out.println(numbers);
    }
}
HashSet does not allow duplicate elements.

12. HashMap

HashMap stores data in the form of key-value pairs. 

import java.util.HashMap;

    public static void main(String[] args) {

        students.put(1, "Rahul");
        students.put(2, "Priya");
        students.put(3, "Aman");

    }
}

13. Generics

Generics allow classes and collections to work with a specified data type. 

ArrayList names =
    new ArrayList<>();

14. Iterator

Iterator is used to traverse elements of a collection. 

import java.util.*;

class Demo {

    public static void main(String[] args) {

        ArrayList list =
            new ArrayList<>();

        list.add("Java");
        list.add("Python");
        list.add("C++");

        Iterator itr =
            list.iterator();

        while (itr.hasNext()) {

            System.out.println(itr.next());
        }
    }
}

15. JDBC

JDBC stands for Java Database Connectivity.

JDBC allows Java applications to connect with databases, execute SQL statements and process results.

16. Steps of JDBC

  1. Import JDBC packages.
  2. Load/register the JDBC driver when required.
  3. Establish a database connection.
  4. Create a Statement or PreparedStatement.
  5. Execute SQL query.
  6. Process the result.
  7. Close database resources.

17. Simple JDBC Example

import java.sql.*;

class DatabaseDemo {

    public static void main(String[] args) {

        try {

            Class.forName("com.mysql.cj.jdbc.Driver");

            Connection con =
                DriverManager.getConnection(
                    "jdbc:mysql://localhost:3306/testdb",
                    "root",
                    "password"
                );

            System.out.println(
                "Database Connected"
            );

            con.close();

        } catch (Exception e) {

            System.out.println(e);
        }
    }
}

18. Statement

Statement is used to execute SQL statements against a database. 

Statement st = con.createStatement();

ResultSet rs =
    st.executeQuery("SELECT * FROM students");

19. PreparedStatement

PreparedStatement is used to execute parameterized SQL statements. 

PreparedStatement ps =
    con.prepareStatement(
        "SELECT * FROM students WHERE id = ?"
    );

ps.setInt(1, 1);

ResultSet rs =
    ps.executeQuery();
PreparedStatement is commonly preferred for parameterized queries because it helps separate SQL structure from values.

20. ResultSet

ResultSet represents the data returned by a database query. 

while (rs.next()) {

    System.out.println(
        rs.getString("name")
    );
}

21. Important JDBC Interfaces and Classes

Class / Interface Purpose
DriverManager Manages database drivers and connections
Connection Represents a database connection
Statement Executes SQL statements
PreparedStatement Executes parameterized SQL statements
ResultSet Stores query results

22. Java GUI

GUI stands for Graphical User Interface.

Java provides libraries such as AWT and Swing for creating graphical user interfaces.

Common Swing Components:

  • JFrame
  • JLabel
  • JButton
  • JTextField
  • JTextArea
  • JCheckBox

23. Simple Swing Program

import javax.swing.*;

class MyFrame {

    public static void main(String[] args) {

        JFrame frame =
            new JFrame("My Application");

        JLabel label =
            new JLabel("Welcome to Java");

        frame.add(label);

        frame.setSize(400, 300);

        frame.setVisible(true);

        frame.setDefaultCloseOperation(
            JFrame.EXIT_ON_CLOSE
        );
    }
}

24. JButton

JButton is a Swing component used to create a clickable button. 

import javax.swing.*;

class ButtonDemo {

    public static void main(String[] args) {

        JFrame frame =
            new JFrame("Button Example");

        JButton button =
            new JButton("Click Me");

        button.setBounds(
            100, 100, 120, 40
        );

        frame.add(button);

        frame.setSize(400, 300);

        frame.setLayout(null);

        frame.setVisible(true);

        frame.setDefaultCloseOperation(
            JFrame.EXIT_ON_CLOSE
        );
    }
}
