1. Class in Java

A class is a blueprint or template from which objects are created. A class contains data members and methods. 

class Student {

    String name;
    int age;

    void display() {
        System.out.println(name);
        System.out.println(age);
    }
}

Here, Student is a class.

2. Object in Java

An object is an instance of a class. It represents a real-world entity. 

class Student {

    String name;

    void display() {
        System.out.println(name);
    }

    public static void main(String[] args) {

        Student s1 = new Student();

        s1.name = "Rahul";

        s1.display();
    }
}

Output:

Rahul

3. Creating an Object

In Java, an object is generally created using the new keyword.

Syntax:

ClassName objectName = new ClassName();

Example:

Student s1 = new Student();

4. Reference Variable

A reference variable stores the reference of an object. 

Student s1 = new Student();

Here s1 is a reference variable that refers to the Student object.

5. Methods in Java

A method is a block of code that performs a particular task.

Syntax:

returnType methodName(parameters) {

    // statements

}

Example:

class Calculator {

    int add(int a, int b) {

        return a + b;
    }

    public static void main(String[] args) {

        Calculator c = new Calculator();

        int result = c.add(10, 20);

        System.out.println(result);
    }
}

Output:

30

6. Method Parameters

Parameters are variables passed to a method. 

void display(String name) {

    System.out.println(name);
}

Here name is a parameter.

7. Return Type

A method can return a value using the return keyword. 

int square(int n) {

    return n * n;
}

The return type of this method is int.

8. Constructor

A constructor is a special method-like member used to initialize objects.

A constructor has the same name as the class and does not have a return type. 

class Student {

    String name;

    Student() {

        name = "Rahul";
    }

    void display() {

        System.out.println(name);
    }

    public static void main(String[] args) {

        Student s = new Student();

        s.display();
    }
}

Output:

Rahul

9. Types of Constructors

Commonly discussed constructors are:

  1. Default Constructor
  2. Parameterized Constructor
  3. Copy Constructor concept

10. Default Constructor

A constructor with no parameters is called a no-argument constructor. 

class Student {

    Student() {

        System.out.println("Student object created");
    }

    public static void main(String[] args) {

        Student s = new Student();
    }
}

11. Parameterized Constructor

A constructor that accepts parameters is called a parameterized constructor. 

class Student {

    String name;
    int age;

    Student(String n, int a) {

        name = n;
        age = a;
    }

    void display() {

        System.out.println(name);
        System.out.println(age);
    }

    public static void main(String[] args) {

        Student s1 = new Student("Rahul", 20);

        s1.display();
    }
}

Output:

Rahul
20

12. this Keyword

The this keyword refers to the current object. 

class Student {

    String name;

    Student(String name) {

        this.name = name;
    }

    void display() {

        System.out.println(this.name);
    }
}
Remember: this refers to the current object.

13. static Keyword

The static keyword is used for members that belong to the class rather than a particular object. 

class Student {

    static String college = "ABC College";

    String name;

    Student(String name) {

        this.name = name;
    }

    void display() {

        System.out.println(name);
        System.out.println(college);
    }
}

14. Access Modifiers

Access modifiers control the accessibility of classes, variables and methods.

Modifier Accessibility
private Only within the same class
default Within the same package
protected Same package and subclasses
public Accessible from anywhere

15. Encapsulation using Getter and Setter

Private variables can be accessed through public getter and setter methods. 

class Student {

    private int marks;

    public void setMarks(int marks) {

        this.marks = marks;
    }

    public int getMarks() {

        return marks;
    }

    public static void main(String[] args) {

        Student s = new Student();

        s.setMarks(85);

        System.out.println(s.getMarks());
    }
}

Output:

85

16. Method Overloading

When multiple methods have the same name but different parameters, it is called method overloading. 

class Calculator {

    int add(int a, int b) {

        return a + b;
    }

    int add(int a, int b, int c) {

        return a + b + c;
    }

    public static void main(String[] args) {

        Calculator c = new Calculator();

        System.out.println(c.add(10, 20));

        System.out.println(c.add(10, 20, 30));
    }
}

Output:

30
60

17. Command Line Arguments

Command line arguments are values passed to a Java program when it is executed. 

class Demo {

    public static void main(String[] args) {

        System.out.println(args[0]);
    }
}

The values are stored inside the args array.
