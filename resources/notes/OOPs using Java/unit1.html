1. Introduction to Object Oriented Programming

Object Oriented Programming (OOP) is a programming approach in which a program is designed using objects and classes.

Java is an object-oriented programming language that strongly supports OOP concepts.

Simple Definition: OOP is a programming method where data and functions are combined together into objects.

2. Object

An object is a real-world entity that has state and behavior.

Examples:

  • Car
  • Student
  • Mobile Phone
  • Bank Account
  • Book

Example:

A Student object can have:

  • Name
  • Roll Number
  • Age
  • Marks

And its behaviors can be:

  • Study()
  • AttendClass()
  • GiveExam()

3. Class

A class is a blueprint or template used to create objects.

Example:

class Student {

    String name;
    int age;

    void study() {
        System.out.println("Student is studying");
    }
}

Here, Student is a class.

4. Creating an Object in Java

Objects in Java are created using the new keyword. 

class Student {

    String name;

    void display() {
        System.out.println(name);
    }

    public static void main(String[] args) {

        Student s1 = new Student();

        s1.name = "Rahul";

        s1.display();
    }
}

Output:

Rahul

5. Features of OOP

The major features of Object Oriented Programming are:

  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

6. Encapsulation

Encapsulation means wrapping data and methods into a single unit.

In Java, encapsulation can be achieved using a class and access modifiers such as private. 

class Student {

    private int marks;

    public void setMarks(int m) {
        marks = m;
    }

    public int getMarks() {
        return marks;
    }
}
Remember: Encapsulation = Data hiding + Data binding

7. Inheritance

Inheritance is a mechanism in which one class acquires the properties and methods of another class.

It helps in code reusability. 

class Animal {

    void eat() {
        System.out.println("Animal eats");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Dog barks");
    }
}

Here, Dog inherits the properties and methods of Animal.

8. Polymorphism

Polymorphism means one name, many forms.

Java supports two main types of polymorphism:

  • Compile-time Polymorphism
  • Run-time Polymorphism

Example – Method Overloading

class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}

9. Abstraction

Abstraction means hiding unnecessary implementation details and showing only important information to the user.

In Java, abstraction can be achieved using:

  • Abstract Classes
  • Interfaces

10. Advantages of OOP

  • Code reusability
  • Data security
  • Easy maintenance
  • Easy debugging
  • Modularity
  • Flexibility
  • Better code organization

11. Introduction to Java

Java was developed by Sun Microsystems. It was originally developed under the leadership of James Gosling.

13. JVM

JVM stands for Java Virtual Machine.

JVM executes Java bytecode and makes Java platform independent.

Java source code → Compiler → Bytecode → JVM → Machine Code

14. JDK

JDK stands for Java Development Kit.

It provides tools required to develop and run Java programs.

15. JRE

JRE stands for Java Runtime Environment.

It provides the environment required to run Java applications.

16. JDK vs JRE vs JVM

JDK JRE JVM
Used for development Used to run Java programs Executes bytecode
Contains JRE Contains JVM Part of JRE
