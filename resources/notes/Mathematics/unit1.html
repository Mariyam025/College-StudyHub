1. Matrix

A matrix is a rectangular arrangement of numbers or elements in rows and columns. Matrices are generally represented by capital letters such as A, B and C.

Example:

A = [ [1, 2], [3, 4] ]

This is a 2 × 2 matrix.

2. Types of Matrices

Row Matrix

A matrix having only one row is called a row matrix.

[ 2 4 6 ]

Column Matrix

A matrix having only one column is called a column matrix.

[ 2 ]
[ 4 ]
[ 6 ]

Square Matrix

A matrix having equal number of rows and columns is called a square matrix.

[ 1 2 ]
[ 3 4 ]

Zero Matrix

A matrix in which all elements are zero is called a zero matrix.

[ 0 0 ]
[ 0 0 ]

Diagonal Matrix

A square matrix in which all non-diagonal elements are zero is called a diagonal matrix.

[ 2 0 ]
[ 0 5 ]

Identity Matrix

A square matrix having 1 on the main diagonal and 0 elsewhere is called an identity matrix.

[ 1 0 ]
[ 0 1 ]
Identity matrix is represented by I.

Symmetric Matrix

A square matrix is symmetric if its transpose is equal to the original matrix.

AT = A

Upper Triangular Matrix

A square matrix in which all elements below the main diagonal are zero is called an upper triangular matrix.

Lower Triangular Matrix

A square matrix in which all elements above the main diagonal are zero is called a lower triangular matrix.

3. Inverse of a Matrix

The inverse of a square matrix A is a matrix A-1 such that:

A × A-1 = I

The inverse can be found using elementary transformations.

Elementary Row Transformations

  • Interchange two rows.
  • Multiply a row by a non-zero number.
  • Add or subtract a multiple of one row from another row.
Basic Method:

Write the augmented matrix:

[ A | I ]

Apply elementary row operations until:

[ I | A-1 ]

4. Rank of a Matrix

The rank of a matrix is the maximum number of linearly independent rows or columns of the matrix.

Rank(A) = Number of non-zero rows in row echelon form.
For a matrix:

[ 1 2 ]
[ 2 4 ]

The second row is a multiple of the first row. Therefore, Rank(A) = 1.

5. Linear System of Equations

A system of linear equations contains two or more linear equations involving variables.

x + y = 5
x - y = 1

Consistency

A system is called consistent if it has at least one solution. It is inconsistent if it has no solution.

For AX = B:

Consistent if Rank(A) = Rank([A|B])
Cases:
  • Rank(A) = Rank([A|B]) = Number of unknowns → Unique solution
  • Rank(A) = Rank([A|B]) < Number of unknowns → Infinite solutions
  • Rank(A) ≠ Rank([A|B]) → No solution

6. Characteristic Equation

The characteristic equation of a square matrix A is obtained from:

|A - λI| = 0

Here, λ (lambda) represents the eigenvalue and I represents the identity matrix.

For a 2 × 2 matrix, calculate:

|A - λI| = 0

The resulting polynomial is called the characteristic equation.

7. Eigen Values

Eigenvalues are the values of λ for which:

|A - λI| = 0

The roots of the characteristic equation are the eigenvalues of the matrix.

8. Eigen Vectors

For an eigenvalue λ, a non-zero vector X is called an eigenvector if:

AX = λX

It can also be written as:

(A - λI)X = 0
Steps to find Eigenvalues and Eigenvectors:
  1. Write the matrix A.
  2. Find |A - λI|.
  3. Put |A - λI| = 0.
  4. Solve the characteristic equation.
  5. Find the eigenvalues.
  6. Use (A - λI)X = 0 to find eigenvectors.

9. Cayley-Hamilton Theorem

Cayley-Hamilton theorem states that every square matrix satisfies its own characteristic equation.

If the characteristic equation is:

p(λ) = 0

then:

p(A) = 0
Use of Cayley-Hamilton Theorem:
  • It can be used to calculate higher powers of a matrix.
  • It can be used to find the inverse of a matrix.
