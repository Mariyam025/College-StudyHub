1. Successive Differentiation

Successive differentiation means differentiating a function repeatedly.

First derivative = dy/dx
Second derivative = d²y/dx²
Third derivative = d³y/dx³
Example:

y = x³

First derivative:
dy/dx = 3x²

Second derivative:
d²y/dx² = 6x

Third derivative:
d³y/dx³ = 6

2. Partial Derivatives

When a function contains two or more independent variables, differentiation with respect to one variable while keeping other variables constant is called partial differentiation.

Partial derivative with respect to x: ∂f/∂x

Partial derivative with respect to y: ∂f/∂y
Example:

z = x² + 3xy + y²

∂z/∂x = 2x + 3y

∂z/∂y = 3x + 2y

3. Second Order Partial Derivatives

Partial differentiation can also be performed more than once.

∂²z/∂x², ∂²z/∂y², ∂²z/∂x∂y
For:

z = x²y + y³

∂z/∂x = 2xy

∂²z/∂x² = 2y

4. Homogeneous Function

A function is called homogeneous if all its terms have the same total degree.

Example:

f(x,y) = x² + 2xy + y²

Each term has degree 2. Therefore, it is a homogeneous function of degree 2.

5. Euler's Theorem for Homogeneous Functions

If f(x,y) is a homogeneous function of degree n, then:

x(∂f/∂x) + y(∂f/∂y) = nf
Example:

f(x,y) = x² + y²

Degree = 2

∂f/∂x = 2x
∂f/∂y = 2y

x(2x) + y(2y) = 2x² + 2y² = 2f

Hence Euler's theorem is verified.

6. Total Derivative

Total derivative is used when a dependent variable depends on more than one variable and those variables themselves depend on another variable.

If z = f(x,y), x = x(t), y = y(t), then

dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt)
Example:

z = x² + y²
x = t, y = t²

dz/dt = 2x(dx/dt) + 2y(dy/dt)

7. Taylor's Theorem

Taylor's theorem is used to express a function as an infinite series around a particular point.

f(x) = f(a) + (x-a)f'(a) + ((x-a)²/2!)f''(a) + ...
Taylor expansion is useful for approximating functions near a particular value.

8. Maclaurin's Theorem

Maclaurin's theorem is a special case of Taylor's theorem where a = 0.

f(x) = f(0) + xf'(0) + (x²/2!)f''(0) + (x³/3!)f'''(0) + ...

Important Maclaurin Expansions

Function Expansion
eˣ 1 + x + x²/2! + x³/3! + ...
sin x x - x³/3! + x⁵/5! - ...
cos x 1 - x²/2! + x⁴/4! - ...
log(1+x) x - x²/2 + x³/3 - ...

9. Expansion of Function of Several Variables

Taylor's theorem can also be used for functions containing more than one variable.

f(x,y) can be expanded using partial derivatives around a specified point.
For a function f(x,y), expansion involves terms such as:

f(a,b),
(x-a)fx,
(y-b)fy,
second order partial derivatives, etc.

10. Indefinite Integration

Indefinite integration is the reverse process of differentiation.

∫ f(x) dx = F(x) + C

Here C is the constant of integration.

Example:

∫ x² dx

= x³/3 + C

Basic Integration Formulas

Function Integral
xⁿ xⁿ⁺¹/(n+1) + C
1/x log|x| + C
eˣ eˣ + C
sin x -cos x + C
cos x sin x + C

11. Definite Integration

Definite integration has fixed lower and upper limits.

∫ab f(x) dx

The result of a definite integral is a constant value.

Example:

∫02 x dx

= [x²/2]02

= 2

Viva Questions

Q1. What is successive differentiation?
Ans: Repeated differentiation of a function.
Q2. What is a partial derivative?
Ans: Differentiation of a multivariable function with respect to one variable while keeping other variables constant.
Q3. What is Euler's theorem?
Ans: For a homogeneous function of degree n, xfx + yfy = nf.
Q4. What is Maclaurin's theorem?
Ans: It is Taylor's theorem about the point x = 0.
Q5. What is indefinite integration?
Ans: Integration without fixed limits, including a constant of integration C.
