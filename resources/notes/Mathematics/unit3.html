1. Differential Equation

A differential equation is an equation which contains derivatives or differentials of a dependent variable with respect to one or more independent variables.

Example:

dy/dx = 2x

This is a differential equation because it contains the derivative dy/dx.

2. Ordinary Differential Equation

An ordinary differential equation (ODE) contains derivatives with respect to only one independent variable.

Example:

dy/dx + y = x

3. Order of Differential Equation

The order of a differential equation is the order of the highest derivative present in the equation.

Example:

d²y/dx² + dy/dx + y = 0

Highest derivative = d²y/dx²
Therefore, Order = 2.

4. Degree of Differential Equation

The degree is the highest power of the highest order derivative when the differential equation is free from radicals and fractions involving derivatives.

Example:

(d²y/dx²)³ + dy/dx + y = 0

Highest derivative = d²y/dx²
Its power = 3

Therefore, Degree = 3.

5. First Order First Degree Differential Equation

A differential equation having order 1 and degree 1 is called a first order first degree differential equation.

Example:

dy/dx + y = x

6. Variable Separable Differential Equation

A differential equation is called variable separable when variables can be separated so that one variable and its differential are placed on one side and the other variable on the other side.

dy/dx = f(x)g(y)

dy/g(y) = f(x) dx
Example:

dy/dx = xy

dy/y = x dx

Integrating:

∫dy/y = ∫x dx

log|y| = x²/2 + C

7. Equations Reducible to Variable Separable

Some differential equations are not directly separable but can be converted into a separable form by substitution or rearrangement.

Example:

dy/dx = (x + y)/(x - y)

Put:
y = vx

Then:
dy/dx = v + x dv/dx

The equation can then be reduced to a variable separable form.

8. Linear Differential Equation

A first-order linear differential equation is generally written as:

dy/dx + Py = Q

Here P and Q are functions of x.

Integrating Factor

I.F. = e∫P dx

Solution

y × I.F. = ∫(Q × I.F.)dx + C
Example:

dy/dx + y = x

Here:
P = 1
Q = x

I.F. = e∫1dx = ex

9. Bernoulli's Differential Equation

Bernoulli's differential equation is a first-order differential equation of the form:

dy/dx + Py = Qyn

It can be converted into a linear differential equation using substitution.

Put:

v = y1-n
Steps:
  1. Write the equation in Bernoulli form.
  2. Divide by yn.
  3. Put v = y1-n.
  4. Convert it into a linear differential equation.
  5. Solve using integrating factor.

10. Linear Differential Equation of nth Order

A linear differential equation of nth order with constant coefficients can be written as:

anDny + an-1Dn-1y + ... + a1Dy + a0y = X

Here D represents differentiation with respect to x.

11. Auxiliary Equation

To solve a linear differential equation with constant coefficients, we form an auxiliary equation by replacing D with m.

For:

(D² - 5D + 6)y = 0

Auxiliary equation:

m² - 5m + 6 = 0

(m - 2)(m - 3) = 0

Therefore:
m = 2, 3

12. Complementary Function (CF)

The complementary function is the solution of the corresponding homogeneous differential equation.

CF depends on the roots of the auxiliary equation.

For Distinct Real Roots

If roots are m₁ and m₂:

CF = C₁em₁x + C₂em₂x
If roots are 2 and 3:

CF = C₁e2x + C₂e3x

13. Particular Integral (PI)

Particular Integral is the particular solution of a non-homogeneous differential equation.

Complete Solution = CF + PI
For:

F(D)y = X

General solution:

y = CF + PI

14. Complete Solution

Complete Solution = Complementary Function + Particular Integral
