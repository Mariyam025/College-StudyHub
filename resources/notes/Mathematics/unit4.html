1. Partial Differential Equation

A Partial Differential Equation (PDE) is an equation containing partial derivatives of a dependent variable with respect to two or more independent variables.

Example:

∂z/∂x + ∂z/∂y = 0

This is a PDE because z depends on more than one variable.

2. Origin of First Order PDE

First order PDEs contain partial derivatives of first order only.

p = ∂z/∂x

q = ∂z/∂y

Therefore, a first-order PDE may be written in terms of x, y, z, p and q.

3. First Order First Degree PDE

A PDE having first order and degree one is called a first-order first-degree PDE.

Example:

p + q = x + y

where
p = ∂z/∂x
q = ∂z/∂y

4. Lagrange's Linear PDE

Lagrange's linear partial differential equation is generally written as:

Pp + Qq = R

where:

  • p = ∂z/∂x
  • q = ∂z/∂y
  • P, Q and R are functions of x, y and z.

5. Lagrange's Auxiliary Equations

For the equation:

Pp + Qq = R

The auxiliary equations are:

dx/P = dy/Q = dz/R

Two independent solutions are obtained from these auxiliary equations.

Example:

p + q = 0

Here:
P = 1, Q = 1, R = 0

Auxiliary equations:

dx/1 = dy/1 = dz/0

6. PDE of First Order and Degree Greater Than One

A first-order PDE may have degree greater than one when the highest-order partial derivative has a power greater than one.

Example:

p² + q² = 1

Here the order is 1 and degree is 2.

7. Complete Integral

A complete integral is a solution of a first-order PDE containing the required number of arbitrary constants.

Example:

z = ax + by

where a and b are arbitrary constants.

8. Second Order Linear PDE

A second-order linear PDE contains second-order partial derivatives and is linear in the dependent variable and its derivatives.

A zxx + B zxy + C zyy + D zx + E zy + Fz = G

9. Second Order PDE with Constant Coefficients

When the coefficients of the derivatives are constants, it is called a second-order linear PDE with constant coefficients.

(D² + 2DD' + D'²)z = 0

Here D and D' represent differentiation with respect to x and y respectively.

10. Important Forms

D = ∂/∂x

D' = ∂/∂y
D² = ∂²/∂x²

D'² = ∂²/∂y²

DD' = ∂²/∂x∂y
