1. Components of C Language

Components of C language are the basic elements used to write a C program.

Component Meaning Example
Keywords Reserved words int, if, return
Identifiers Names given to variables, functions etc. age, marks
Constants Fixed values 10, 3.14
Operators Perform operations +, -, *
Special Symbols Symbols used in program syntax ; , { } ( )

2. Structure of a C Program

A C program follows a particular structure. A simple program generally contains header files, the main function, statements and a return statement.

Example

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Main Parts

Part Purpose
#include <stdio.h> Includes the standard input/output header.
main() Starting function of the program.
printf() Displays output.
return 0; Returns control from main.
Output:
Hello World

3. Writing and Executing a C Program

A C program is written in a source file and then compiled and executed.

Basic Steps

  1. Write the C program.
  2. Save the file with .c extension.
  3. Compile the program.
  4. Correct errors if present.
  5. Run the program.
  6. Check the output.
Example: 
#include <stdio.h>

int main()
{
    printf("College StudyHub");

    return 0;
}
Output:
College StudyHub

4. Standard Input and Output in C

Standard I/O functions are used to take input from the user and display output.

printf()

printf() is used to display output. 

printf("Hello");

scanf()

scanf() is used to take input from the user.

Example Program

#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}
Sample Output:
Enter your age: 19
Your age is 19

Common Format Specifiers

Specifier Used For
%d Integer
%f Floating-point value
%c Character
%s String

5. Operator Precedence and Associativity

Operator precedence determines which operator is evaluated first in an expression.

Associativity determines the direction in which operators having the same precedence are evaluated.

Example

int result;

result = 10 + 5 * 2;

Multiplication has higher precedence than addition. Therefore, multiplication is performed first. 

5 * 2 = 10

10 + 10 = 20
Result: 20

Simple Precedence Table

Operators Priority
() Higher
*, /, % High
+, - Medium
= Lower

6. Storage Classes

Storage classes define important properties of variables, such as their scope, lifetime and storage behavior.

Storage Class Keyword
Automatic auto
Register register
Static static
External extern

7. Automatic Storage Class

The auto storage class is used for local variables. Local variables are automatic by default.

Example

#include <stdio.h>

int main()
{
    auto int x = 10;

    printf("%d", x);

    return 0;
}
Output:
10

8. Register Storage Class

The register keyword can be used to request that a frequently used variable be stored in a CPU register when possible.

Example

#include <stdio.h>

int main()
{
    register int i;

    for(i = 1; i <= 5; i++)
    {
        printf("%d ", i);
    }

    return 0;
}
Output:
1 2 3 4 5

9. Static Storage Class

A static local variable retains its stored value between function calls.

Example Program

#include <stdio.h>

void count()
{
    static int x = 0;

    x++;

    printf("%d ", x);
}

int main()
{
    count();
    count();
    count();

    return 0;
}
Output:
1 2 3

The value of x is retained between calls because it is declared as static.

10. Extern Storage Class

The extern keyword is used to declare a variable that is defined elsewhere, allowing it to be referred to from another scope or source file.

Example

#include <stdio.h>

int number = 50;

int main()
{
    extern int number;

    printf("%d", number);

    return 0;
}
Output:
50
