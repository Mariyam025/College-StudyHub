1. C Language Fundamentals

What is C?

C is a general-purpose programming language used to write computer programs. It was designed to provide a simple and efficient way to write programs.

Simple Definition:

C is a programming language used to give instructions to a computer and develop different types of software.

Why do we learn C?

  • It helps us understand programming fundamentals.
  • It teaches variables, operators and control of programs.
  • It helps in understanding memory and data handling.
  • Many programming concepts become easier after learning C.

Basic idea of a C program

A C program contains instructions that are written according to the rules of the C language. 

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

In this program, printf() displays a message on the screen.

Output:
Hello World

2. Character Set

A character set is a collection of characters that can be used while writing a C program.

Main categories of characters

Category Examples
Alphabets A-Z, a-z
Digits 0-9
Special Characters +, -, *, /, %, ;, { }, ( )
White Space Space, Tab, New Line

Example

int age = 19;

printf("Age = %d", age);

Here letters, digits and special symbols are used to create the C program.

3. Keywords

Keywords are reserved words of the C language. They have predefined meanings and cannot normally be used as variable names.

Example:

int, float, if, else and return are examples of C keywords.

Common C Keywords

Keyword Purpose
int Integer data type
char Character data type
float Floating-point data type
double Double precision floating-point type
if Used for decision making
else Alternative part of a condition
for Looping
while Looping
return Returns a value from a function
void Represents no value/type

Example

int age = 19;

if(age >= 18)
{
    printf("Adult");
}

Here int and if are keywords.

4. Variables

A variable is a named memory location used to store a value. The value of a variable can change during program execution.

Example: 
int age = 19;

Here age is a variable and 19 is the value stored in it.

Why are variables required?

  • To store data.
  • To use data in calculations.
  • To change values during program execution.
  • To make programs easier to manage.

Example Program

#include <stdio.h>

int main()
{
    int age = 19;

    printf("Age = %d", age);

    return 0;
}
Output:
Age = 19

5. Declaration of Variables

Declaration tells the compiler the name and data type of a variable.

Syntax

data_type variable_name;

Examples

int age;
float salary;
char grade;
Statement Meaning
int age; Declares an integer variable named age.
float salary; Declares a floating-point variable.
char grade; Declares a character variable.

6. Initialization of Variables

Initialization means assigning an initial value to a variable.

Example

int age = 19;
float marks = 85.5;
char grade = 'A';

Declaration vs Initialization

Declaration Initialization
Creates/declares a variable with a type. Gives an initial value to the variable.
Example: int age; Example: int age = 19;

Simple Program

#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;

    printf("A = %d\n", a);
    printf("B = %d", b);

    return 0;
}
Output:
A = 10
B = 20

7. Rules for Naming Variables

Variable names should follow the rules of the C language.

  • A variable name can contain letters, digits and underscore.
  • It should not start with a digit.
  • Spaces should not be used in variable names.
  • Keywords should not be used as variable names.
  • C is case-sensitive.

Valid Examples

age
studentAge
marks1
total_marks
salary

Invalid Examples

1age
student age
int
total-marks
Remember:

age, Age and AGE can be treated as different identifiers because C is case-sensitive.

8. Scope of Variables

Scope means the part of a program where a variable can be accessed or used.

Local Variable

A variable declared inside a function or block is generally accessible only within that function or block. 

#include <stdio.h>

int main()
{
    int age = 19;

    printf("%d", age);

    return 0;
}

Here age is declared inside main().

Global Variable

A variable declared outside functions can have a wider scope and can be accessed by functions according to C's scope rules. 

#include <stdio.h>

int number = 10;

int main()
{
    printf("%d", number);

    return 0;
}
Output:
10

Local vs Global Variable

Local Variable Global Variable
Declared inside a function/block. Declared outside functions.
Its scope is limited. It can have a wider scope.
Used mainly inside the function/block. Can be used by multiple functions according to scope rules.

Block Scope – Simple Example

#include <stdio.h>

int main()
{
    int a = 10;

    {
        int b = 20;

        printf("A = %d\n", a);
        printf("B = %d", b);
    }

    return 0;
}
Output:
A = 10
B = 20

The variable b is declared inside the inner block, so its scope is limited to that block.

9. Constants

A constant is a value that does not change during the execution of a program.

Simple Definition: A constant is a fixed value used in a C program.

Examples

10
25
3.14
'A'
"Hello"

Types of Constants

Type Example
Integer Constant 10, 25, -50
Floating-point Constant 3.14, 25.5
Character Constant 'A', 'b', '5'
String Constant "Hello", "College"

Integer Constants

Integer constants are whole numbers without a decimal point. 

10
100
-25
0

Floating-point Constants

Floating-point constants contain a decimal value. 

3.14
25.50
-10.75

Character Constants

A character constant represents a single character and is written inside single quotation marks. 

'A'
'B'
'7'
'@'

String Constants

A string constant is a sequence of characters written inside double quotation marks. 

"Hello"
"College StudyHub"
"Welcome"

Using const

The const keyword can be used when a variable should not be changed through that variable after initialization. 

#include <stdio.h>

int main()
{
    const int age = 19;

    printf("Age = %d", age);

    return 0;
}
Output:
Age = 19

10. Data Types

A data type tells the compiler what type of data a variable can store.

Example:

If we want to store a whole number, we can use int. 

int age = 19;

Common Basic Data Types

Data Type Used For Example
int Whole numbers int age = 19;
char Single character char grade = 'A';
float Decimal values float price = 25.5;
double Decimal values with greater precision double value = 25.5678;

1. int

int is used to store integer or whole-number values. 

int age = 19;
int marks = 85;

2. char

char is used to store a single character. 

char grade = 'A';
char section = 'B';

3. float

float is used to store decimal numbers. 

float percentage = 85.5;

4. double

double is used for floating-point values with more precision than a typical float. 

double distance = 125.6789;

Example Program

#include <stdio.h>

int main()
{
    int age = 19;
    char grade = 'A';
    float marks = 85.5;

    printf("Age = %d\n", age);
    printf("Grade = %c\n", grade);
    printf("Marks = %.1f", marks);

    return 0;
}
Output:
Age = 19
Grade = A
Marks = 85.5

11. Operators

Operators are symbols used to perform operations on values and variables.

Example: 
int a = 10;
int b = 5;

int sum = a + b;

Here + is an operator.

Types Based on Number of Operands

Type Meaning Example
Unary Works on one operand ++a
Binary Works on two operands a + b
Ternary Works with three parts a > b ? a : b

Unary Operator

A unary operator works on one operand.

Common examples include increment and decrement operators. 

int a = 5;

a++;

printf("%d", a);
Output:
6

Binary Operator

A binary operator works on two operands. 

int a = 10;
int b = 20;

int result = a + b;

printf("%d", result);
Output:
30

Ternary Operator

The ternary operator uses three parts and is commonly used for a simple conditional expression.

Syntax

condition ? value_if_true : value_if_false;

Example

#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;

    int largest;

    largest = (a > b) ? a : b;

    printf("Largest = %d", largest);

    return 0;
}
Output:
Largest = 20

12. Bitwise Operators

Bitwise operators perform operations on the individual bits of integer values.

Operator Name
& Bitwise AND
| Bitwise OR
^ Bitwise XOR
~ Bitwise NOT
<< Left Shift
>> Right Shift

Bitwise AND (&)

AND gives 1 only when both corresponding bits are 1. 

5 = 0101
3 = 0011

5 & 3 = 0001

Result = 1

Bitwise OR (|)

OR gives 1 when at least one corresponding bit is 1. 

5 = 0101
3 = 0011

5 | 3 = 0111

Result = 7

Bitwise XOR (^)

XOR gives 1 when the corresponding bits are different. 

5 = 0101
3 = 0011

5 ^ 3 = 0110

Result = 6

Bitwise NOT (~)

NOT changes 1 to 0 and 0 to 1 at the bit level. 

~5

The exact displayed decimal result depends on the integer representation used by the C implementation.

Left Shift (<<)

The left-shift operator shifts bits towards the left. 

int a = 5;

int result = a << 1;

For this simple positive integer example, the result is 10.

Right Shift (>>)

The right-shift operator shifts bits towards the right. 

int a = 8;

int result = a >> 1;

For this simple positive integer example, the result is 4.

Bitwise Operator Program

#include <stdio.h>

int main()
{
    int a = 5;
    int b = 3;

    printf("AND = %d\n", a & b);
    printf("OR = %d\n", a | b);
    printf("XOR = %d", a ^ b);

    return 0;
}
Output:
AND = 1
OR = 7
XOR = 6

13. Type Conversion

Type conversion means converting a value from one data type to another data type.

Implicit Type Conversion

In implicit conversion, the compiler automatically converts one data type into another when required.

Example

#include <stdio.h>

int main()
{
    int a = 10;
    float b;

    b = a;

    printf("%.1f", b);

    return 0;
}
Output:
10.0

Here the integer value is automatically converted to a floating value for assignment to b.

14. Type Casting

Type casting means explicitly converting a value from one data type to another using a cast.

Syntax

(data_type) value

Example

#include <stdio.h>

int main()
{
    int a = 5;
    int b = 2;

    float result;

    result = (float)a / b;

    printf("%.2f", result);

    return 0;
}
Output:
2.50

Why do we use type casting?

  • To explicitly convert a value to another type.
  • To control the type used in an expression.
  • It can be useful when performing calculations involving different data types.

Type Conversion vs Type Casting

Type Conversion Type Casting
Conversion may happen automatically. Conversion is explicitly requested by the programmer.
Example: int to float in an assignment. Example: (float)a
