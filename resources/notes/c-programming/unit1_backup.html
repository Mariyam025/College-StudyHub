1. Introduction to C Language

C is a general-purpose programming language used to develop system software, application software and many other types of programs.

Simple Example:

A C program can be used to calculate the sum of two numbers.

2. Character Set

A character set is a collection of characters that can be used in a C program.

Main types of characters:

  • Alphabets – A to Z and a to z
  • Digits – 0 to 9
  • Special characters – +, -, *, /, %, =, etc.
  • White space characters – space, tab and newline
Example:

In the statement int age = 19; the characters used include alphabets, digits and symbols.

3. Keywords

Keywords are reserved words of the C language. They have predefined meanings and cannot normally be used as variable names.

Examples of keywords:

Keyword Purpose
int Declares an integer data type
float Declares a floating-point data type
char Declares a character data type
if Used for decision making
else Used with if
return Returns a value from a function

4. Variables

A variable is a named memory location used to store a value. The value of a variable can change during program execution.

Declaration

Declaration tells the compiler the name and data type of a variable. 

int age;
float marks;
char grade;

Initialization

Initialization means assigning an initial value to a variable. 

int age = 19;
float marks = 85.5;
char grade = 'A';
Example: 
#include <stdio.h>

int main()
{
    int age = 19;

    printf("Age = %d", age);

    return 0;
}
Output:
Age = 19

5. Scope of Variables

Scope means the area of a program where a variable can be accessed or used.

Local Variable

A variable declared inside a function or block is generally accessible only within that area. 

#include <stdio.h>

int main()
{
    int number = 10;

    printf("%d", number);

    return 0;
}

Global Variable

A variable declared outside all functions is called a global variable and can be accessed by functions according to its visibility. 

#include <stdio.h>

int number = 10;

int main()
{
    printf("%d", number);

    return 0;
}

6. Constants

A constant is a value that does not change during the execution of a program.

Types of Constants

Type Example
Integer constant 10, 25, -5
Floating constant 10.5, 3.14
Character constant 'A', 'b', '5'
String constant "Hello"

Using const

const int DAYS = 7;

Here, DAYS is intended to remain unchanged through normal assignment.

7. Data Types

Data types specify what type of value a variable can store.

Data Type Example Use
int 10 Integer values
float 10.5 Decimal values
double 25.6789 More precision for decimal values
char 'A' Character values
Remember:

The exact size and range of C data types can depend on the compiler and platform.

8. Operators

Operators are symbols used to perform operations on values and variables.

Unary Operator

A unary operator works with one operand. 

int a = 5;

a++;

Here ++ is a unary operator.

Binary Operator

A binary operator works with two operands. 

int a = 10;
int b = 5;

int sum = a + b;

Ternary Operator

The ternary operator works with three operands. Its basic form is: 

condition ? value1 : value2;
Example: 
int a = 10;
int b = 20;

int max = (a > b) ? a : b;
Result:
max = 20

9. Bitwise Operators

Bitwise operators perform operations on the individual bits of integer values.

Operator Name
& Bitwise AND
| Bitwise OR
^ Bitwise XOR
~ Bitwise NOT
<< Left Shift
>> Right Shift

Example

int a = 5;
int b = 3;

printf("%d", a & b);
Output:
1

10. Type Conversion

Type conversion means converting a value from one data type to another data type.

Example

int a = 10;
float b;

b = a;

Here, the integer value is converted to a floating-point value.

11. Type Casting

Type casting is the explicit conversion of a value into another data type by specifying the required type.

Syntax

(data_type) value;

Example

#include <stdio.h>

int main()
{
    int a = 5;
    int b = 2;

    float result;

    result = (float)a / b;

    printf("%.2f", result);

    return 0;
}
Output:
2.50
Important Difference:

Type conversion can happen automatically in suitable expressions, while type casting is explicitly specified by the programmer.

⭐ Quick Revision

  • Character Set: Characters used in C programs.
  • Keyword: Reserved word with a predefined meaning.
  • Variable: Named memory location used to store a value.
  • Scope: Area where a variable can be accessed.
  • Constant: A value intended not to change during program execution.
  • Data Type: Specifies the kind of value a variable can store.
  • Unary: Works with one operand.
  • Binary: Works with two operands.
  • Ternary: Uses three operands.
  • Bitwise Operators: Work at the bit level.
  • Type Conversion: Conversion of one data type to another.
  • Type Casting: Explicit conversion using a specified data type.
