1. Structure

A structure is a user-defined data type that allows us to store different types of data under one name.

Syntax

struct Student
{
    int roll;
    char name[20];
    float marks;
};

Example Program

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main()
{
    struct Student s;

    s.roll = 101;
    s.marks = 85.5;

    printf("Roll = %d\n", s.roll);
    printf("Marks = %.2f", s.marks);

    return 0;
}
Output:
Roll = 101
Marks = 85.50

2. Union

A union is a user-defined data type in which all members share the same memory location.

Syntax

union Data
{
    int number;
    float value;
};
Important: In a union, only one member can hold a meaningful value at a time because members share memory.

3. Structure vs Union

Structure Union
Members have separate memory. Members share the same memory.
Multiple members can contain values at the same time. Normally one member is used at a time.
Generally requires more memory. Generally requires less memory.

4. Enumeration

Enumeration or enum is a user-defined data type used to assign names to integral constants.

Example

enum Week
{
    Monday,
    Tuesday,
    Wednesday,
    Thursday,
    Friday
};

By default, the first value starts from 0.

5. Pointers

A pointer is a variable that stores the memory address of another variable.

Example

#include <stdio.h>

int main()
{
    int number = 10;
    int *ptr;

    ptr = &number;

    printf("Value = %d\n", number);
    printf("Value using pointer = %d", *ptr);

    return 0;
}
Output:
Value = 10
Value using pointer = 10
Remember:
& → address of a variable
* → value stored at an address

6. Array of Pointers

An array of pointers is an array whose elements are pointers.

Example

#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;
    int c = 30;

    int *ptr[3];

    ptr[0] = &a;
    ptr[1] = &b;
    ptr[2] = &c;

    printf("%d %d %d",
           *ptr[0],
           *ptr[1],
           *ptr[2]);

    return 0;
}
Output:
10 20 30

7. Preprocessor

The preprocessor processes certain instructions before the actual compilation of a C program.

Preprocessor directives begin with the # symbol.

Example

#include <stdio.h>

Here #include is a preprocessor directive.

8. Standard C Preprocessor Directives

Directive Purpose
#include Includes a header file.
#define Defines a macro.
#ifdef Checks whether a macro is defined.
#ifndef Checks whether a macro is not defined.
#endif Ends a conditional preprocessing section.

9. Macros

A macro is a name or expression defined using #define.

Example

#include <stdio.h>

#define PI 3.14

int main()
{
    printf("PI = %.2f", PI);

    return 0;
}
Output:
PI = 3.14

10. Dynamic Memory Allocation

Dynamic memory allocation means allocating memory during program execution.

C provides functions such as malloc(), calloc(), realloc() and free().

11. malloc()

malloc() allocates a block of memory of the specified size.

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = (int*)malloc(sizeof(int));

    *ptr = 50;

    printf("Value = %d", *ptr);

    free(ptr);

    return 0;
}
Output:
Value = 50

12. calloc()

calloc() allocates memory for multiple elements and initializes the allocated memory to zero.

Syntax

ptr = (type*)calloc(number, size);

13. realloc()

realloc() is used to change the size of previously allocated memory.

Syntax

ptr = realloc(ptr, new_size);

14. free()

free() releases dynamically allocated memory.

Example

free(ptr);
Important: Memory allocated dynamically should be released when it is no longer required.

  • Enum: Names for integral constants.
  • Pointer: Stores the address of another variable.
  • Array of Pointers: Array containing pointer elements.
  • Preprocessor: Processes directives before compilation.
  • Macro: Defined using #define.
  • malloc(): Allocates memory.
  • calloc(): Allocates and initializes memory to zero.
  • realloc(): Changes allocated memory size.
  • free(): Releases allocated memory.
