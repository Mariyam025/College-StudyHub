1. Functions

A function is a block of statements that performs a particular task.

Example:

A function can be created to calculate the sum of two numbers.

Basic Syntax

return_type function_name(parameters)
{
    statements;
}

2. Types of Functions

Functions in C can broadly be divided into two types.

Type Meaning
Library Function Provided by the C library.
User-defined Function Created by the programmer.

Library Function Example

printf("Hello");

printf() is a commonly used library function.

User-defined Function Example

#include <stdio.h>

void greet()
{
    printf("Welcome to College StudyHub");
}

int main()
{
    greet();

    return 0;
}
Output:
Welcome to College StudyHub

3. Passing Values to Functions

Values can be passed to a function through parameters. In C, arguments are commonly passed by value.

Example

#include <stdio.h>

void add(int a, int b)
{
    printf("Sum = %d", a + b);
}

int main()
{
    add(10, 20);

    return 0;
}
Output:
Sum = 30

4. Recursive Functions

A recursive function is a function that calls itself.

Example: Factorial

#include <stdio.h>

int factorial(int n)
{
    if(n == 0)
    {
        return 1;
    }

    return n * factorial(n - 1);
}

int main()
{
    int result;

    result = factorial(5);

    printf("Factorial = %d", result);

    return 0;
}
Output:
Factorial = 120

5. Arrays

An array is a collection of elements of the same data type stored under one name.

Syntax

data_type array_name[size];

Example

int marks[5];

Here marks can store five integer values.

Array Initialization

int marks[5] = {80, 75, 90, 85, 70};

Accessing Array Elements

Array indexing starts from 0. 

marks[0]
marks[1]
marks[2]

Example Program

#include <stdio.h>

int main()
{
    int marks[5] = {80, 75, 90, 85, 70};
    int i;

    for(i = 0; i < 5; i++)
    {
        printf("%d ", marks[i]);
    }

    return 0;
}
Output:
80 75 90 85 70

6. Program: Sum of Array Elements

#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int i;
    int sum = 0;

    for(i = 0; i < 5; i++)
    {
        sum = sum + a[i];
    }

    printf("Sum = %d", sum);

    return 0;
}
Output:
Sum = 150

7. Multidimensional Arrays

A multidimensional array contains data in more than one dimension. A two-dimensional array is commonly represented in rows and columns.

Syntax

data_type array_name[rows][columns];

Example

int matrix[2][2] = {
    {1, 2},
    {3, 4}
};

Program to Display a 2D Array

#include <stdio.h>

int main()
{
    int matrix[2][2] = {
        {1, 2},
        {3, 4}
    };

    int i, j;

    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}
Output:
1 2
3 4

8. Sparse Matrix

A sparse matrix is a matrix in which most of the elements are zero.

Example

0  0  5
0  0  0
7  0  0

In this matrix, most elements are zero, so it is a sparse matrix.

Representation of Sparse Matrix

One common representation stores only the non-zero elements along with their row and column positions.

Row Column Value
0 2 5
2 0 7
Important: Sparse representation can save storage by avoiding storage of many zero values.

⚡ Quick Revision

  • Function: Block of statements performing a task.
  • Library Function: Function provided by C libraries.
  • User-defined Function: Function created by programmer.
  • Recursion: Function calling itself.
  • Array: Collection of same-type elements.
  • 2D Array: Array arranged in rows and columns.
  • Sparse Matrix: Matrix containing mostly zero elements.
